# Argument Type Mismatch

Title: varies

## Explanation

An argument's type differs from the type of the parameter it is passed to. This applies to calls of functions, methods, constructors and function values. The message gives the position of the argument, the type the parameter expects and the type it got.

Doria performs no implicit conversions, so a `string` cannot be passed for an `int` parameter, and a nullable value cannot be passed for a parameter that is not nullable.

## Fix

Pass a value of the parameter's type. To convert text to a number, use the companion of the target type and supply a fallback, as in `Int::parse($text) ?? 0`. To convert a number to text, use interpolation: `"{$count}"`.

If the function should accept the value as it is, change the type of the parameter.

## Example

```doria
function square(int $value): int
{
    return $value * $value;
}

function main(): void
{
    echo square("four");
}
```
