# Collection Fill Count Cannot Be Negative

Title: fixed
Family: runtime

## Explanation

The repeat form `[value; count]` builds a list or a typed array that holds `count` copies of `value`. This panic means `count` was negative when the program ran. A count of `0` is valid and gives an empty sequence.

The usual cause is a subtraction that goes below zero, such as a width minus the space already used.

## Fix

Test the values before the literal and return an empty sequence when nothing is needed: `if ($used >= $width) { return []; }`.

## Example

```doria
function blanks(int $width, int $used): List<string>
{
    return [" "; $width - $used];
}

function main(): void
{
    let $padding = blanks(3, 5);
    echo $padding->count;
}
```
