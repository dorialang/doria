# Foreign Aggregate Field Is Not Valid

Title: varies
Family: unsafe

## Explanation

A foreign struct or union, or a use of one, does not follow the rules for foreign layouts. A foreign aggregate has fields only, each declared once; a struct field may have a constant default, and a union member has none, because the members overlap. An aggregate declared with fields has at least one. It has no methods, and its only constants are `SIZE` and `ALIGNMENT`, its C size and alignment in bytes. Reading or writing a field names one the aggregate declares.

## Fix

Do what the message names: remove the repeated field, give a struct field a constant default such as `255` or `null`, remove a union member's default, or use a field the aggregate declares. Write behavior as free functions that take the aggregate as a parameter.

## Example

```doria
extern "C" struct Color
{
    uint8 $red;
    uint8 $red;
}

function main(): void
{
}
```
