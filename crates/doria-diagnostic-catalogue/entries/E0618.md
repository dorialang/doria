# Throws Type Must Implement Error

Title: fixed
Family: errors

## Explanation

A `throws` clause lists the checked errors a function may throw. Each entry is `Error` or a class that implements `Error`.

This error means an entry names another type, such as `int`, `mixed`, a collection, or a class that does not declare `implements Error`.

## Fix

Name an error class in the clause, or remove the clause when the function throws nothing.

If the class is meant to be thrown, declare it `implements Error` and give it a readonly `string $message` property.

## Example

```doria
class Report
{
    function __construct(string $title)
    {
    }
}

function publish(Report $report): void throws Report
{
    echo $report->title;
}

function main(): void
{
    publish(new Report("Weekly"));
}
```
