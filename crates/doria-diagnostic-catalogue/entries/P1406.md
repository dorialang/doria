# File Text Is Not Valid UTF-8

Title: fixed
Family: runtime

## Explanation

This code names a text file whose contents were not valid UTF-8 and ended the program as a panic. It is a historical identity. A `string` is always valid UTF-8, so `read_file` reports such a file as a checked `Doria\Std\Io\InvalidUtf8Error`, which the program can catch.

An `InvalidUtf8Error` that nothing catches ends the program with R1000 under the title `Unhandled Doria\Std\Io\InvalidUtf8Error`.

## Fix

Catch the error where the program can recover: wrap the read in `try` and add `catch (Doria\Std\Io\InvalidUtf8Error $error)`. `$error->validByteCount` is the number of bytes that were valid before the first bad one.

To read a file in any encoding, use `read_file_bytes`, which returns `Bytes` and performs no UTF-8 validation.

## Example

No program raises this code on demand: a file that is not valid UTF-8 reaches the program as a `Doria\Std\Io\InvalidUtf8Error`, so no read ends with this panic. A programmer meets the same failure as R1000 when the error is not caught.
