# Wrong Backing Value Type

Title: fixed
Family: enums

## Explanation

A backed enum declares `int` or `string` as its backing type, and every case value is a constant of exactly that type. This error means a case value has another type, or is an expression whose value is not known during compilation, such as a function call.

Doria performs no implicit conversions, so a `string` cannot back a case of an `int` enum.

## Fix

Write a literal or a constant expression of the backing type: `case Low = 1;` in an enum backed by `int`, `case Low = "low";` in an enum backed by `string`. A top-level constant may be used, as in `case High = BASE * 2;`.

If the cases are meant to hold text, change the backing type to `string` and give every case a `string` value.

## Example

```doria
enum Priority: int
{
    case Low = "low";
    case High = 10;
}

function main(): void
{
    echo Priority::High->value;
}
```
