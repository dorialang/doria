# Backend Error

Title: fixed
Family: compiler

## Explanation

The compiler asked one of its targets for text and received another kind of output. Two targets produce text: `php` produces PHP source, and `debug` produces a record of the program's exit status and output. A tool that embeds the compiler and asks for either text as a string receives this code when the target hands back something else.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project with the program and the name of the tool that was running. The compiler's description of the failure says which target returned the wrong kind of output.

To keep working, compile the program with `doriac compile` and the same `--target`, which writes the output to a file.

## Example

No program raises this code on demand: it appears only when a target returns output of the wrong kind, which a correct compiler never does. A user meets it through a tool built on the compiler that requests generated PHP or the debug record as text; the `doriac` command does not take that path.
