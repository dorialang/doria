# Repeated Or Conflicting Interface

Title: varies
Family: interfaces

## Explanation

A class conforms to an interface once, and an interface extends each parent once. This error means the same interface is named a second time: twice in one `implements` or `extends` list, or after `implements` in a class whose parent class already implements it.

The code is also reported when a generic interface is reached with two different type arguments, such as `Source<int>` and `Source<string>`. A class or interface takes one specialization of a generic interface.

## Fix

Remove the repeated name from the list. When a parent class already implements the interface, the subclass conforms through its parent and does not name the interface again.

For two specializations of one generic interface, keep one, or implement each in its own class.

## Example

```doria
interface Renderable
{
    function render(): string;
}

class Report implements Renderable, Renderable
{
    function render(): string
    {
        return "report";
    }
}

function main(): void
{
    let $report = new Report();
    echo $report->render();
}
```
