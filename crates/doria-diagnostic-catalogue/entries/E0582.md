# Enum Layout Is Too Large

Title: fixed
Family: enums

## Explanation

An enum value stores the payload fields of its active case inside itself, so it is as large as its largest case. A payload field whose type is another payload enum is stored whole. This error means the size of the enum is larger than a value may be.

It arises when payload enums are nested many times and each level has many fields, most often through a generic enum applied to itself.

## Fix

Store the large payload in a collection or a class. Both live outside the enum value, so the enum stays small. For example, replace many fields of the same type with one `List<T>` field.

## Example

```doria
enum Block<T>
{
    case Fill(T $a, T $b, T $c, T $d, T $e, T $f, T $g, T $h, T $i, T $j, T $k, T $l, T $m, T $n, T $o, T $p);
}

function describe(Block<Block<Block<Block<Block<Block<Block<Block<int>>>>>>>> $block): string
{
    return "block";
}

function main(): void
{
    echo "ready";
}
```
