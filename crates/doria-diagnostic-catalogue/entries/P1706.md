# C Called Doria From Another Thread

Title: fixed
Family: runtime

## Explanation

An `extern "C" function` is a Doria function that C calls through its address, such as a callback a C library stores. Doria code runs on one thread, and its values are not shared between threads. When C calls the function on any other thread, for example a thread a C library starts for its own work, the call panics before the function's body runs.

## Fix

Have the C library call the function on the thread that runs the program, as a library does when it calls back during a call the program made. When a library delivers its callbacks on its own threads, keep the work on the C side of the boundary, or use the library's option to deliver them to the calling thread.

## Example

```doria
use Doria\Std\Ffi\{CSize, OperatingSystem, Opaque, Platform, Pointer, WritablePointer};

extern "C"
{
    /** @safety `$thread` addresses a writable `pthread_t`, and `$start` is C-callable. */
    function pthread_create(
        WritablePointer<uint64> $thread,
        ?Pointer<Opaque> $attributes,
        extern "C" function(?WritablePointer<Opaque>): ?WritablePointer<Opaque> $start,
        ?WritablePointer<Opaque> $argument,
    ): int32;

    /** @safety `$thread` is a thread that `pthread_create` started. */
    function pthread_join(uint64 $thread, ?WritablePointer<Opaque> $result): int32;

    /** @safety `$start` is C-callable. */
    function CreateThread(
        ?WritablePointer<Opaque> $attributes,
        CSize $stackSize,
        extern "C" function(?WritablePointer<Opaque>): uint32 $start,
        ?WritablePointer<Opaque> $parameter,
        uint32 $flags,
        ?WritablePointer<uint32> $threadId,
    ): ?WritablePointer<Opaque>;

    /** @safety `$handle` is a thread handle. */
    function WaitForSingleObject(?WritablePointer<Opaque> $handle, uint32 $milliseconds): uint32;
}

extern "C" function work(?WritablePointer<Opaque> $context): ?WritablePointer<Opaque>
{
    return null;
}

extern "C" function windowsWork(?WritablePointer<Opaque> $context): uint32
{
    return 0;
}

function main(): void
{
    if (Platform::operatingSystem == OperatingSystem::Windows) {
        unsafe {
            let $thread = CreateThread(null, CSize::from(0), windowsWork, null, 0, null);
            WaitForSingleObject($thread, 4294967295);
        }
    } else {
        writable uint64 $thread = 0;
        unsafe {
            pthread_create(WritablePointer::to($thread), null, work, null);
            pthread_join($thread, null);
        }
    }
}
```
