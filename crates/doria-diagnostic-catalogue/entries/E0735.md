# Parent Constructor Is Not Accessible

Title: fixed
Family: classes

## Explanation

Constructing a subclass runs the parent constructor. This error means the parent constructor is declared `internal`. An `internal` member is accessible only inside the class that declares it, so a subclass cannot run that constructor and cannot extend the class.

## Fix

Remove `internal` from the parent constructor if the class is meant to have subclasses.

If the constructor is meant to stay `internal`, remove `extends` from the subclass.

## Example

```doria
open class Shape
{
    internal function __construct()
    {
    }
}

class Square extends Shape
{
}

function main(): void
{
    echo "shapes";
}
```
