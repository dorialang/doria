# Null-Coalescing Operands Are Incompatible

Title: varies

## Explanation

The fallback of `??` has a type that cannot stand in for the left operand. `$count ?? "none"` with `?int $count` would be an `int` in one case and a `string` in the other, and an expression has one type.

## Fix

Give the fallback the same type as the nullable value, for example `$count ?? 0`. To show different text when the value is missing, test for `null` with `if` and build the text in each branch.

## Example

```doria
function describe(?int $count): void
{
    let $shown = $count ?? "none";
    echo $shown;
}

function main(): void
{
    describe(null);
}
```
