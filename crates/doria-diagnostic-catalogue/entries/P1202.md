# String Padding Length Cannot Be Negative

Title: fixed
Family: runtime

## Explanation

The second argument of `String::padStart` and `String::padEnd` is the length of the whole result in graphemes. It cannot be negative. This panic means a negative length reached the call when the program ran.

## Fix

Pass a length of zero or more. A length no greater than the length of the text returns the text unchanged, so zero is always safe.

When the length is calculated, for example from a column width minus a margin, test it before the call.

## Example

```doria
function main(): void
{
    let $width = 4 - 6;
    echo String::padStart("42", $width, "0");
}
```
