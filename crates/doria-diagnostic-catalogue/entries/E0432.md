# The `resource` Type Is Not Available Yet

Title: varies
Family: types
Availability: planned

## Explanation

Doria keeps the type name `resource` for the PHP bridge, which lets PHP code call a Doria library. The bridge is part of Doria. This compiler does not implement it yet, so `resource` cannot be written as a type today, in a declaration, a parameter, a return type or a type argument.

A Doria program holds a file, a connection or any other handle in a class. The class acquires the handle in its constructor and releases it in `__destruct`, which runs when the value is destroyed.

## Fix

Declare the value with the class that owns the handle. An open file from `File::openRead` has the type `ReadableFile`. For a handle of your own, write a class that acquires it in `__construct` and releases it in `__destruct`, and use that class as the type.

For a value whose type is known only when the program runs, declare it `mixed` and narrow it with `is` before using it.

## Example

```doria
function main(): void
{
    resource $handle = null;
}
```
