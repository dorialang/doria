# `print` Is Not A Doria Statement

Title: varies
Family: syntax

## Explanation

A statement begins with `print`. Doria writes output with `echo` and has no `print` statement.

## Fix

Replace `print` with `echo`. `echo` is a statement and produces no value. It adds no newline, so put `\n` in the text where a line ends.

For formatted output, call `printf` with a literal format string, as in `printf("%d items\n", $count);`.

## Example

```doria
function main(): void
{
    print "Hello";
}
```
