# Availability Subject Must Be A Type Parameter

Title: fixed
Family: generics

## Explanation

Each bound in a `where (...)` clause has the form `T implements Interface`, where `T` is a type parameter of the enclosing class or trait, or of the method itself. This error means the name before `implements` is something else: a class, an interface, or a name that is not declared.

## Fix

Name the type parameter that the member depends on, as in `where (T implements Describable)`. If no type parameter stands for that type, add one to the class or to the method.

A concrete class either implements an interface or does not, so a condition on one has no use. Remove the clause.

## Example

```doria
interface Describable
{
    function describe(): string;
}

class Box<T>
{
    function __construct(take T $item) {}

    function kind(): string where (Item implements Describable)
    {
        return "a box of describable items";
    }
}

function main(): void
{
    let $box = new Box<int>(4);
    echo $box->item;
}
```
