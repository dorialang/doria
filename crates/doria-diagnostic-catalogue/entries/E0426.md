# Range Used Outside A Foreach

Title: varies
Family: control-flow

## Explanation

A range such as `0..10` or `0..<10` is written directly as the iterable of a `foreach`. A range has no value of its own, so it cannot be stored in a variable, passed as an argument or returned.

## Fix

Write the range in the `foreach` header: `foreach (0..10 as int $index)`. To reuse the bounds, keep the start and the end in `int` variables and write `foreach ($start..$end as int $index)`.

To keep the numbers, add each one to a `List<int>` inside the loop.

## Example

```doria
function main(): void
{
    let $steps = 0..10;
    foreach ($steps as int $index) {
        echo $index;
    }
}
```
