# Writable Method Called Through A Readonly Value

Title: varies

## Explanation

A method declared `writable function` may change its object, so the call needs a writable receiver. This error means the call goes through a readonly variable, parameter or property, or through `$this` in a method that is not writable.

## Fix

Declare the variable that holds the object `writable`, as in `let writable $counter = new Counter();`. For a parameter, write `writable` before its type. When the call is on `$this`, declare the calling method `writable function`.

If the called method changes nothing, remove `writable` from its declaration.

## Example

```doria
class Counter
{
    writable int $count = 0;

    writable function increment(): void
    {
        $this->count += 1;
    }
}

function main(): void
{
    let $counter = new Counter();
    $counter->increment();
    echo $counter->count;
}
```
