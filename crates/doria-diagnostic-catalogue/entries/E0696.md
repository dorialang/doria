# Attribute Default Is Not Const Evaluable

Title: fixed
Family: projects

## Explanation

Applying an attribute runs no code. The values of an attribute are recorded as metadata when the program is compiled, and that includes the default of a constructor parameter of the attribute class. The default must be a constant expression: a literal, a constant, an enum case, or an expression built from these.

This error means a constructor parameter of a class marked `#[Attribute]` has a default that needs the running program to produce its value, such as a function call, or a default whose evaluation fails, such as an integer overflow or a division by zero.

## Fix

Write the default as a literal, or declare the value with `const` and name the constant, as in `const DEFAULT_PATH = "/";` and `string $path = DEFAULT_PATH`.

Or remove the default, so that each application of the attribute states the value.

## Example

No program shows this code on its own: a parameter default that is not a constant expression is reported first as E0498 at the same expression, in an attribute class as in any other, and this code follows it.
