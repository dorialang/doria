# Conflicting Declarations Of A Foreign Symbol

Title: fixed
Family: unsafe

## Explanation

One foreign symbol is declared twice in a program with different signatures, and at least one declaration takes its symbol from its Doria name. A symbol bound under several signatures, such as `objc_msgSend`, must give every binding its own Doria name and name the symbol with `#[LinkName]`, so each call states which signature it uses.

## Fix

Give each binding its own Doria name and `#[LinkName("symbol")]`, or make the declarations agree.

## Example

```doria
use Doria\Std\Ffi\LinkName;

extern "C"
{
    /** @safety Any value is valid. */
    function abs(int32 $value): int32;

    /** @safety Any value is valid. */
    #[LinkName("abs")]
    function absolute(int64 $value): int64;
}

function main(): void
{
}
```
