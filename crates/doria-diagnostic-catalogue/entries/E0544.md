# Writable Shared Reference Takes One Value

Title: varies
Family: ownership

## Explanation

`new WritableSharedReference(...)` takes exactly one argument: the value it will own. The constructor takes ownership of that value through a parameter named `value`. This error means the construction passes no argument, or more than one.

## Fix

Pass the one value to share: `new WritableSharedReference(new Node())`, or with the parameter name, `new WritableSharedReference(value: new Node())`.

To share several values, give each its own `WritableSharedReference`, or put them in one class or collection and share that.

## Example

```doria
class Node
{
    string $name = "root";
}

function main(): void
{
    let $node = new WritableSharedReference(new Node(), new Node());
    let $access = $node->acquireReadonlyAccess();
    echo $access->name;
}
```
