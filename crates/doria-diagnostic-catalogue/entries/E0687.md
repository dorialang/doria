# Class Is Not Marked As An Attribute

Title: fixed
Family: projects

## Explanation

Only a class marked with `#[Attribute]` can be applied as an attribute. The marker declares that the class describes metadata and that its constructor parameters are the values an application supplies.

This error means the name inside `#[...]` is an ordinary class.

## Fix

Write `#[Attribute]` on the line before the class declaration. An attribute class cannot be generic, and its constructor parameters are readonly values of metadata types such as `string`, `int`, `bool` and enums.

If the class was never meant to be an attribute, remove the application.

## Example

```doria
class Route
{
    function __construct(string $path)
    {
    }
}

#[Route("/posts")]
function listPosts(): void
{
    echo "posts";
}

function main(): void
{
    listPosts();
}
```
