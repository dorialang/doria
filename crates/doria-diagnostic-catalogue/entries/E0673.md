# Unknown Doria Edition

Title: fixed
Family: projects

## Explanation

An edition names the version of the Doria language that a package is written in. A package states its edition in `Baton.toml`. Each edition has its own prelude, the short list of names that every source file may use without a `use` statement.

This error means the compiler was given an edition it does not know. This compiler knows one edition, `2026`.

## Fix

Name the edition `2026`. In a project that is `edition = "2026"` under `[package]` in `Baton.toml`.

An edition that this compiler does not know means the package was written for a different release of the compiler. `baton doctor` reports the Baton version and the `doriac` version in use.

## Example

No program raises this code on demand: Baton checks the edition in `Baton.toml` and reports a mistake there under its own code, and a build plan that names an edition the compiler does not know is reported as E0676. This code is reported only to a tool that uses the compiler as a library and names an edition to it directly.
