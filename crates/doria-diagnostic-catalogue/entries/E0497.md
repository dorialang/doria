# Receiver Modifier Requires An Instance Method

Title: varies
Family: classes

## Explanation

`writable function` and `consuming function` say how a method uses `$this`: a `writable` method may change the object, and a `consuming` method takes ownership of it. A static method and a top-level function have no `$this`, so neither modifier applies.

This error means a `static function` is declared `writable` or `consuming`, or a top-level function is declared `consuming`.

## Fix

Remove the modifier. A static method assigns `writable` static properties without it, through `Counter::total` or `self::total`.

If the method is meant to work on an object, remove `static`.

## Example

```doria
class Counter
{
    static writable int $total = 0;

    static writable function reset(): void
    {
        Counter::total = 0;
    }
}

function main(): void
{
    Counter::reset();
    echo Counter::total;
}
```
