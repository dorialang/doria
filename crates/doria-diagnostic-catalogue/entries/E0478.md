# Borrowed Result Where An Owned Value Is Required

Title: varies
Family: ownership

## Explanation

A method that returns one of its object's properties returns a borrow: the value still belongs to the object. A function that returns one of its parameters does the same. This error means the program puts such a result in a place that owns its value: a variable declared with its type, a property, or a collection.

The same error is raised when the borrow would outlive its owner, as in `let $engine = (new Car(new Engine(90)))->getEngine();`, where the `Car` is destroyed at the end of the statement.

## Fix

To go on using the borrowed value, declare the variable with `let`, which holds the borrow and leaves ownership with the object: `let $engine = $car->getEngine();`. Keep the owner in a variable of its own for as long as the borrow is used.

Where an owner is required, supply a value that nothing else owns, such as a new object.

## Example

```doria
class Engine
{
    function __construct(int $power)
    {
    }
}

class Car
{
    function __construct(take Engine $engine)
    {
    }

    function getEngine(): Engine
    {
        return $this->engine;
    }
}

function main(): void
{
    let $car = new Car(new Engine(90));
    Engine $engine = $car->getEngine();
    echo $engine->power;
}
```
