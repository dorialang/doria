# Integer Literal Out Of Range

Title: varies

## Explanation

An integer literal is outside the range of its type. The type comes from the place the literal is used. An `int8` declaration, for example, holds values from -128 to 127. A literal with no such context is an `int`.

## Fix

Use a type wide enough for the value, such as `int16` for 200, or correct the literal. A value above the `int` range needs a `uint64` context, such as a `uint64` declaration.

## Example

```doria
function main(): void
{
    int8 $level = 200;
    echo $level;
}
```
