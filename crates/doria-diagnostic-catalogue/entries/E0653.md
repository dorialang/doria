# Captured Environment Borrow Cannot Be Returned

Title: fixed
Family: functions

## Explanation

A closure that captures with `with ($value)` or `with (writable $value)` borrows the variable. The enclosing scope still owns the value.

This error means the closure returns a class value or collection that it reached through such a capture: the captured variable itself, or a property or element of it. Returning it would hand the caller a value the closure does not own.

## Fix

Capture the variable with `take`, as in `with (take $report)`. The closure then owns the value and can return it. Such a closure gives its value away when it is called, so it can be called once.

To keep the value in the enclosing scope, return something the closure creates, or a Copy value read from the capture such as a `string` or `int` property.

## Example

```doria
class Report
{
    string $title = "Totals";
}

function main(): void
{
    let $report = new Report();
    let $release = function (): Report with ($report) {
        return $report;
    };
    let $released = $release();
    echo $released->title;
}
```
