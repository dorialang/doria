# Writable Shared Reference Has No Direct Member Access

Title: varies
Family: ownership

## Explanation

A `WritableSharedReference<T>` never forwards a property, a method call or an index to the `T` it holds. Every use of the value goes through an access object, because the reference counts its accesses: it allows any number of readonly accesses or one writable access at a time.

This error means a member of the held value is used directly on the reference.

## Fix

Acquire access first, then use the member on the access object. `$reference->acquireReadonlyAccess()` gives readonly access to the value, and `$reference->acquireWritableAccess()` gives writable access.

## Example

```doria
class Node
{
    string $name = "root";
}

function main(): void
{
    let $node = new WritableSharedReference(new Node());
    echo $node->name;
}
```
