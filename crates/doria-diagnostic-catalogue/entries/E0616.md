# Error Message Property Must Be Externally Accessible

Title: fixed
Family: errors

## Explanation

The `Error` interface requires the `message` property to be readable from outside the class, so that a `catch` body can read `$error->message`.

This error means the class declares the property `internal`, which limits access to the methods and constructors of the class.

## Fix

Remove `internal` from the `message` property. The property stays readonly, so code outside the class can read it and cannot change it.

## Example

```doria
class ParseError implements Error
{
    internal string $message = "unexpected token";

    function describe(): string
    {
        return $this->message;
    }
}

function main(): void
{
    let $error = new ParseError();
    echo $error->describe();
}
```
