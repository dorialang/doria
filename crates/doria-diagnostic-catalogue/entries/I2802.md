# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

The compiler could not turn a `given` prelude that passed checking into executable code. A `given` prelude prepares values for an `if`, `when` or `while` and can gate it with predicates. This code means that the compiler's record of which statements of the prelude are predicates was missing, or that the record points at a statement that is not an expression.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the `given` prelude or the statement inside it, so keep that prelude with the `if`, `when` or `while` it belongs to, and remove the code around them.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that uses `given`.
