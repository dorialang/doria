# `self` Used Outside A Class

Title: varies
Family: classes

## Explanation

`self` names the class whose body it is written in. `self::MAX_DEPTH` reads a member of that class, and `self` in a type position means that class. In a trait, `self` names the composing class.

This error means `self` appears where there is no such class, for example in a top-level function.

## Fix

Name the class: `Limits::MAX_DEPTH`. For a top-level constant, write the bare name: `MAX_DEPTH`. In a type position, write the name of the class.

## Example

```doria
const MAX_DEPTH = 8;

function main(): void
{
    echo self::MAX_DEPTH;
}
```
