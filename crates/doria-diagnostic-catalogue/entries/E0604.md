# Writable Payload Pattern Is Not Supported

Title: fixed
Family: enums

## Explanation

Bindings in a match pattern are readonly and local to their arm. `writable` before a payload binding, or before a pattern, asks for a binding that can change the matched value, and Doria rejects that form: a guard that fails must leave the value unchanged for the arms after it.

## Fix

Remove `writable` from the pattern. To change the data, produce the new value as the result of the match and assign it to a `writable` variable.

When the payload is a move value and the arm needs to own it, consume the enum with `match (take $value)`.

## Example

```doria
enum Reading
{
    case Value(int $amount);
    case Missing;
}

function main(): void
{
    Reading $reading = Reading::Value(4);
    int $amount = match ($reading) {
        Reading::Value(writable $amount) => $amount,
        Reading::Missing => 0,
    };
    echo $amount;
}
```
