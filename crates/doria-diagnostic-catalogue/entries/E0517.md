# Argument Supplied More Than Once

Title: varies
Family: functions

## Explanation

Each parameter receives one argument. This error means a call or an attribute gives the same parameter two: the same name is written twice, or a named argument repeats a parameter that a positional argument has already filled.

## Fix

Remove one of the two arguments. In `save("notes", 12, name: "draft")` the first positional argument already fills `$name`, so keep whichever value is meant and delete the other.

## Example

```doria
function save(string $name, int $size): void
{
    echo "{$name}: {$size}";
}

function main(): void
{
    save("notes", 12, name: "draft");
}
```
