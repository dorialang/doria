# Foreign Signature Is Not Valid

Title: varies
Family: unsafe

## Explanation

A foreign declaration, a C-callable function or a C function pointer type has a part a C function cannot have. A C function has no type parameters and cannot throw a checked error; its parameters take their values by copy, so they have no `writable` or `take` mode; a C function pointer type has no invocation mode; and a C-callable function, which C calls through its address, takes no `unsafe` modifier.

## Fix

Remove the part the message names. Report a foreign failure through the return value, and handle every checked error inside a C-callable function's body. Pass a `WritablePointer<T>` for a value C writes through. Declare one binding per concrete type in place of a type parameter.

## Example

```doria
class Failure implements Error
{
    function __construct(string $message) {}
}

extern "C"
{
    /** @safety Any value is valid. */
    function abs(int32 $value): int32 throws Failure;
}

function main(): void
{
}
```
