# Compiler-Known Test Identity Is Reserved

Title: fixed
Family: testing

## Explanation

The testing module that ships with the toolchain is the namespace `Doria\Std\Test`. Its names are `describe`, `it`, `test`, `expect`, `fail` and `AssertionError`, and the compiler provides each of them.

This error means the program declares a function, class, interface, trait, enum or constant under one of those full names, by placing the declaration in the `Doria\Std\Test` namespace.

## Fix

Move the declaration to a namespace of your own, such as `namespace App\Checks;`, or give it a different name. A function named `expect` in another namespace is allowed.

To use the testing module, import its names in a development source: `use Doria\Std\Test\{describe, it, expect};`.

## Example

```doria
namespace Doria\Std\Test;

function expect(int $actual, int $wanted): bool
{
    return $actual == $wanted;
}

function main(): void
{
    echo expect(2, 2);
}
```
