# Member Cannot Be Open

Title: varies
Family: classes

## Explanation

`open` on a method, or on a property with hooks, lets a subclass replace it with `override`. Only an externally accessible instance member of an `open class` can be open.

This error means `open` is on a member that no subclass can replace: a member of a closed class, a `static` method, an `internal` member, or a constructor or destructor.

## Fix

If subclasses are meant to replace the member, declare its class `open class`, and remove `static` or `internal` from the member.

Otherwise remove `open` from the member. A method without `open` is still inherited and callable on a subclass.

## Example

```doria
class Model
{
    open function table(): string
    {
        return "models";
    }
}

function main(): void
{
    let $model = new Model();
    echo $model->table();
}
```
