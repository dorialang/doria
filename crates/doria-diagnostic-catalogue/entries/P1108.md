# Integer Shift Count Is Out Of Range

Title: fixed
Family: runtime

## Explanation

The right operand of `<<` or `>>` is the number of bit positions to shift. It must be zero or more and smaller than the bit width of the left operand's type: 0 through 7 for `uint8` or `int8`, 0 through 63 for `int`. This panic means the count was negative or too large when the program ran. `<<=` and `>>=` are checked the same way.

## Fix

Test the count before shifting when it comes from input or from a calculation.

If the shifted value needs more bits, convert both operands to a wider type and shift there: `Int::from($flag) << Int::from($position)`.

## Example

```doria
function main(): void
{
    uint8 $flag = 1;
    uint8 $position = 8;
    echo $flag << $position;
}
```
