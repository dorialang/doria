# Backend Error

Title: fixed
Family: compiler

## Explanation

The program is valid, and the `php` target cannot reproduce one of its string operations exactly, so the compiler stops before it writes any PHP. Doria measures and edits text by grapheme cluster. PHP can do that only with optional extensions, and the generated PHP does not depend on them.

The compiler raises this code for the string properties `length`, `byteLength`, `isEmpty`, `bytes` and `byteRegion`, and for a `String::` companion call other than `String::fromBytes`.

The report marks the operation. Its text, which names the property or the companion member, is in the developer details.

## Fix

Compile for the native target, which is the default, or for `--target debug`. Both keep Doria string behavior exactly.

To read which operation was refused, run the command again with `--diagnostic-format json` and read the `developerDetails` field, or set `DORIA_DIAGNOSTIC_DEBUG=1`.

## Example

No program raises this code on demand: checking never reports it, because the program is valid Doria. A user meets it only when compiling with `--target php` a program that reads a string property such as `length` or calls a `String::` companion member.
