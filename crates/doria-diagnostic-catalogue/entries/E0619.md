# Throws Type Cannot Be Nullable

Title: fixed
Family: errors

## Explanation

A `throws` clause lists the checked errors a function may throw. A function may complete without throwing an error it lists, so an entry has no optional form.

This error means an entry is written with `?`, as in `throws ?ParseError`.

## Fix

Remove the `?` from the entry: `throws ParseError`.

## Example

```doria
class ParseError implements Error
{
    function __construct(string $message)
    {
    }
}

function parse(string $text): int throws ?ParseError
{
    if ($text == "") {
        throw new ParseError("empty input");
    }
    return $text->length;
}

function main(): void
{
    try {
        echo parse("abc");
    } catch (ParseError $error) {
        echo $error->message;
    }
}
```
