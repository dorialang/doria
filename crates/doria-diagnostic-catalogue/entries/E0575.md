# Invalid Use Of An Enum Member

Title: varies
Family: enums

## Explanation

An enum member is written in a form it does not have. The usual cause is a pair of parentheses.

A unit case is a case declared without payload fields. It is a value and takes no arguments, so `Status::Draft()` is rejected. The `value` property of a backed enum is a property, so `$priority->value()` is rejected.

This code is also reported when a `match` pattern names a case that the matched enum does not declare.

## Fix

Remove the parentheses. Write `Status::Draft` to select a unit case and `$priority->value` to read a backing value. An editor offers the removal as a quick fix.

In a `match` pattern, write the name of a case the enum declares.

## Example

```doria
enum Status
{
    case Draft;
    case Published;
}

function main(): void
{
    Status $status = Status::Draft();
    echo match ($status) {
        Status::Draft => "draft",
        Status::Published => "published",
    };
}
```
