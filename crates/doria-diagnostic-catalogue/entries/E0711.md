# Compiler-Generated Test Identity Is Reserved

Title: fixed
Family: testing

## Explanation

The compiler turns each `it` and `test` declaration from `Doria\Std\Test` into a function of its own. The name of that function begins with `__doria_test_` and ends with a fingerprint of the test, and the function belongs to the namespace of the file that declares the test.

This error means another declaration in that namespace already has exactly that name. Names that begin with `__doria_` are reserved for the compiler, so a program reaches this only by declaring one of them.

## Fix

Rename or remove the declaration whose name begins with `__doria_test_`. The error marks the `it` or `test` declaration and points to the conflicting declaration.

Choose names that do not begin with `__doria_`.

## Example

No program shows this code on its own: it is raised only when a declaration has exactly the name of the function that the compiler generates for a test, and that declaration is reported first as a duplicate at the same `it` or `test` declaration, with E0308 when it is a function and E0669 otherwise. A function with such a name is also reported with E0310, because names that begin with `__doria_` are reserved.
