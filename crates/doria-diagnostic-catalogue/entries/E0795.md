# Foreign Attribute Cannot Be Applied Here

Title: varies
Family: unsafe

## Explanation

A `Doria\Std\Ffi` attribute is applied where it has no meaning, or twice to one declaration. `#[Library]` names the library of an `extern "C"` block. `#[LinkName]`, `#[Variadic]`, `#[CaptureSystemCode]` and `#[NonBlocking]` describe one declaration inside an `extern "C"` block, and each applies to it once.

## Fix

Move the attribute to the target the message names, or remove the repeated application.

## Example

```doria
use Doria\Std\Ffi\Library;

#[Library("zlib")]
function main(): void
{
}
```
