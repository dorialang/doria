# Superseded Shared-Ownership Type Name

Title: varies
Family: ownership

## Explanation

`Shared`, `Weak` and `SharedMut` are earlier spellings of the shared-ownership types. Doria spells these types with complete words, and the earlier names are not kept as aliases.

## Fix

Write `SharedReference<T>` for `Shared<T>`, `WeakReference<T>` for `Weak<T>`, and `WritableSharedReference<T>` for `SharedMut<T>`.

## Example

```doria
class Node
{
    string $name = "root";
}

function main(): void
{
    Shared<Node> $node = shared new Node();
    echo $node->name;
}
```
