# Panic Message Is Not A String

Title: varies
Family: types

## Explanation

The argument to `panic` is the message shown when the program stops, and its type is `string`. This error means the argument has another type, such as `int` or `?string`.

## Fix

Pass a `string`. To report a number, interpolate it into the message: `panic("request failed with status {$code}");`. For a nullable string, supply a fallback with `??`.

## Example

```doria
function main(): void
{
    let $code = 404;
    panic($code);
}
```
