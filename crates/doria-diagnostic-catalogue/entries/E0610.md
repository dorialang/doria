# When Result Is Missing Or Cannot Be Inferred

Title: varies
Family: control-flow

## Explanation

Every path that reaches the end of a `when` branch must produce the result with `return expression;`. This error means a branch can finish without returning a value: it ends with a statement such as `echo`, or a nested `if` returns on one path only.

The same code is raised when every branch returns `null` and nothing else gives the `when` a type. `null` alone does not determine a result type.

## Fix

Add `return value;` on each path that reaches the end of the branch.

For a `when` whose branches all return `null`, write a nullable result type on the head, as in `when ($ready): ?string`, or assign the `when` to a nullable declaration such as `?string $label`.

## Example

```doria
function main(): void
{
    int $count = 3;
    let $label = when ($count > 1) {
        echo "many";
    } else {
        return "one";
    };
    echo $label;
}
```
