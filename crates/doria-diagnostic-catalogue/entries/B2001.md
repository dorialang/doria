# Backend Error

Title: fixed
Family: compiler

## Explanation

The program is valid, and the `php` target cannot keep one of its class constants, so the compiler stops before it writes any PHP. The constant is named `class`, in any letter case. PHP reserves that name after `::` for fetching the name of a class, so a PHP class cannot declare a constant with it.

The report marks the constant declaration. Its text is in the developer details.

## Fix

Rename the constant, for example from `CLASS` to `KIND`, and update the places that read it.

To keep the name, compile for the native target, which is the default, or for `--target debug`. Neither has this restriction.

## Example

No program raises this code on demand: checking never reports it, because a class constant named `CLASS` is valid Doria. A user meets it only when compiling with `--target php` a program that declares such a constant.
