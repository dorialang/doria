# Describe Body May Contain Only Test Declarations

Title: fixed
Family: testing

Example source: development

## Explanation

`describe` from `Doria\Std\Test` groups tests under a name. Its body is a list of declarations: `it`, `test` and nested `describe`. The body is never run, so it has no place for a statement such as a variable declaration, an `echo` or a call to one of your own functions.

This error means the body of a `describe` contains a statement that is not one of those declarations.

## Fix

Move the statement into the body of each `it` or `test` that needs it.

For setup that several tests share, write a function and call it at the start of each test.

## Example

```doria
use Doria\Std\Test\{describe, it, expect};

describe("Addition", function (): void {
    let $sum = 1 + 1;

    it("adds two numbers", function (): void {
        expect(1 + 1)->toEqual(2);
    });
});
```
