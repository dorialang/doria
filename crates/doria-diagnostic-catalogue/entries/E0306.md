# Property Is Internal

Title: varies

## Explanation

The program reads or writes a property that its class marks `internal`. An internal property is part of the class's implementation and can be used only from inside that class.

## Fix

Use the class's externally accessible members, or add a method or a computed property to the class that exposes what the caller needs. Remove `internal` from the property only if it is meant to be part of the class's surface.

## Example

```doria
class Account
{
    internal writable int $balance = 0;
}

function main(): void
{
    let $account = new Account();
    echo $account->balance;
}
```
