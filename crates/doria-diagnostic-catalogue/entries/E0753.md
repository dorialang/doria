# Duplicate Or Conflicting Requirement

Title: varies
Family: interfaces

## Explanation

Within an interface, each requirement name stands for one contract. This error means an interface declares the same method or property twice, declares one name as both a method and a property, or extends two interfaces whose requirements of the same name have different signatures.

The code is also reported where a member is used on a generic type parameter and two of the parameter's `implements` constraints declare that member with different contracts.

## Fix

Remove the duplicate declaration.

When two parent interfaces disagree, rename one of the requirements, or redeclare the requirement in the child interface with a signature that satisfies every parent.

## Example

```doria
interface Renderable
{
    function render(): string;
    function render(): string;
}

class Report implements Renderable
{
    function render(): string
    {
        return "report";
    }
}

function main(): void
{
    let $report = new Report();
    echo $report->render();
}
```
