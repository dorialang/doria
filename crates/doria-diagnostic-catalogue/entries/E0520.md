# Collection Does Not Support Indexed Access

Title: varies

## Explanation

The program reads `$collection[$index]` on a collection that has no positions or keys to index by. Sets and priority queues are in this group: a `Set` answers whether it contains a value, and a `PriorityQueue` hands out its next element.

## Fix

Ask a `Set` with `contains`, or visit its elements with `foreach`. Use `peek` or `pop` on a `PriorityQueue`. If the program needs positions, hold the values in a `List` or a typed array.

## Example

```doria
function main(): void
{
    Set<string> $tags = Set::from(["a", "b"]);
    echo $tags[0];
}
```
