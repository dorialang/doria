# Override Parameter Has No Property Target

Title: fixed
Family: classes

## Explanation

`override` before a constructor parameter says that the parameter supplies an instance property inherited from a parent class, so no second property is created. This error means no such property exists: the class has no parent, no parent declares a member with the parameter's name, or the inherited member with that name is something other than an externally accessible instance property.

## Fix

Remove `override` to make the parameter a new property of this class.

To reuse an inherited property, give the parameter that property's exact name and type.

## Example

```doria
class Person
{
    function __construct(override string $name)
    {
    }
}

function main(): void
{
    let $person = new Person("Ada");
}
```
