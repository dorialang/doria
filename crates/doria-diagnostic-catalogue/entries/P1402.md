# File Write Failed

Title: fixed
Family: runtime

## Explanation

This code names a file write that failed and ended the program as a panic. It is a historical identity. `write_file`, `append_file`, `write_file_bytes` and `append_file_bytes` report a failed write as a checked `Doria\Std\Io\IoError`, which the program can catch.

An `IoError` that nothing catches ends the program with R1000 under the title `Unhandled Doria\Std\Io\IoError`.

## Fix

Catch the error where the program can recover: wrap the write in `try` and add `catch (Doria\Std\Io\IoError $error)`. `$error->message` describes the failure, and `$error->reason` gives its cause as an `IoErrorReason` case, such as `IoErrorReason::NotFound` when the directory does not exist or `IoErrorReason::PermissionDenied` when the file cannot be written.

## Example

No program raises this code on demand: a failed file write reaches the program as a `Doria\Std\Io\IoError`, so no write ends with this panic. A programmer meets the same failure as R1000 when the error is not caught.
