# Backed Case Requires A Value

Title: fixed
Family: enums

## Explanation

An enum declared with a backing type, such as `enum Priority: int`, is a backed enum. Every case of a backed enum has a backing value, read through its `value` property. This error means a case of a backed enum is declared without `=` and a value.

## Fix

Give the case a constant value of the backing type, as in `case High = 10;`. Each value is used by one case.

If the cases need no values, remove the backing type from the enum and the values from the other cases.

## Example

```doria
enum Priority: int
{
    case Low = 1;
    case High;
}

function main(): void
{
    echo Priority::Low->value;
}
```
