# Override Modifier Is Required

Title: fixed
Family: classes

## Explanation

A subclass replaces an inherited `open` method or `open` property only by declaring its own with `override`. This error means the subclass declares a member with the name of an inherited open member and leaves `override` out.

## Fix

Add `override` before `function`: `override function table(): string`. For a property with hooks, add `override` before the property type: `override int $value { get => 2; }`.

If the member is unrelated to the inherited one, give it a different name.

## Example

```doria
open class Model
{
    open function table(): string
    {
        return "models";
    }
}

class Post extends Model
{
    function table(): string
    {
        return "posts";
    }
}

function main(): void
{
    let $post = new Post();
    echo $post->table();
}
```
