# Given Block Needs `if`, `when` Or `while`

Title: varies
Family: syntax

## Explanation

A `given` block holds setup declarations and bool predicates for the control statement that follows it. That statement is `if`, `when` or `while`, and it begins directly after the closing `}` of the block. This error means something else follows the block, such as `foreach`, `for`, `match` or an ordinary statement.

## Fix

Attach the block to `if`, `when` or `while`.

For any other statement, remove `given` and declare the variables as ordinary statements before it.

## Example

```doria
function main(): void
{
    given {
        let $limit = 3;
    } foreach (0..$limit as int $step) {
        echo $step;
    }
}
```
