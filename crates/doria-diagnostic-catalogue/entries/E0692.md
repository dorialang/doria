# Attribute Schema Type Is Not Metadata Compatible

Title: fixed
Family: projects

## Explanation

The constructor parameters of a class marked with `#[Attribute]` hold metadata values that are fixed when the program is compiled. The types that can hold such a value are the numeric types, `bool`, `string`, enums, and the nullable forms of these.

This error means a constructor parameter has another type. Objects, collections such as `List` and `Dictionary`, typed arrays, `Bytes`, `mixed`, closures and shared handles cannot be metadata.

## Fix

Give the parameter a metadata type. To carry several values, declare one parameter for each, or use an enum whose cases name the allowed choices.

## Example

```doria
#[Attribute]
class Tags
{
    function __construct(parameter List<string> $names)
    {
    }
}

function main(): void
{
    echo "ready";
}
```
