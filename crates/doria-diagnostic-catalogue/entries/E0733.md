# Parent Constructor Call Must Be First

Title: fixed
Family: classes

## Explanation

Construction runs from the root class to the derived class, so the parent part of an object is initialized before the subclass constructor does anything else. This error means the subclass constructor calls `parent::__construct(...)` after another statement.

## Fix

Move `parent::__construct(...)` to the first line of the constructor body. Build its arguments inside the call, from the constructor's parameters, because no statement may come before it.

## Example

```doria
open class Shape
{
    function __construct(string $name)
    {
    }
}

class Square extends Shape
{
    function __construct(int $side)
    {
        echo $side;
        parent::__construct("square");
    }
}

function main(): void
{
    let $square = new Square(2);
    echo $square->name;
}
```
