# Finally Is Not Available On This Construct

Title: fixed
Family: syntax

## Explanation

A control-flow `finally` block attaches to `if`, `when`, `while` and `do ... while`, and runs once when that statement is left. This error means `finally` follows something else: `for`, `foreach`, `match` or a bare block.

## Fix

Move the statements out of the `finally` block and place them after the loop or block.

If they must also run when the loop is left early by `return` or a thrown `Error`, put the loop in a `try` block and the statements in its `finally` clause: `try { ... } finally { ... }`.

## Example

```doria
function main(): void
{
    foreach (0..3 as int $step) {
        echo $step;
    } finally {
        echo "done";
    }
}
```
