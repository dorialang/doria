# Duplicate Global Declaration

Title: fixed
Family: names

## Explanation

Functions, constants, classes, enums, interfaces and traits declared at the top level of a namespace share one set of names. This error means two declarations of different kinds use the same name, such as a class and a function, or a constant and a function.

The message names the full name, and a second label marks the first declaration.

## Fix

Rename one of the two declarations and update the places that use it. If the two belong to different parts of the program, put them in different namespaces.

## Example

```doria
class Report
{
}

function Report(): void
{
}

function main(): void
{
    Report();
}
```
