# Nested Control Flow Is Not Allowed In Given

Title: fixed
Family: control-flow

## Explanation

A `given` block accepts three kinds of statement: variable declarations, calls that return `void`, and `bool` predicates. This error means the block contains another kind of statement, such as an `if`, a loop, a `return`, a `break`, or an assignment.

## Fix

Move the statement into the body of the attached `if`, `when` or `while`, or place it before the `given`.

To make the attached construct depend on a condition, write the condition as a predicate line: `$limit > 5;`.

## Example

```doria
function main(): void
{
    int $limit = 10;
    given {
        if ($limit > 5) {
            echo "large";
        }
    } if ($limit > 2) {
        echo $limit;
    }
}
```
