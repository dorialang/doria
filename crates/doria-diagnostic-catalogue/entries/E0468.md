# Promoted Parameter Must Take Ownership

Title: varies
Family: ownership

## Explanation

A constructor parameter becomes a property of the class. When its type is a move type, such as a class or a collection, the value has one owner. The new property is that owner, so the caller has to give the value up, and `take` on the parameter says so. Without `take`, the caller and the property would both own the value.

## Fix

Write `take` before the parameter's type: `function __construct(take Person $manager)`. The call stays as it is, and the caller cannot use the value after passing it. To make the property writable as well, write `take writable`: `function __construct(take writable Person $manager)`.

If the parameter is only an input to the constructor and should not become a property, mark it with `parameter`.

## Example

```doria
class Person
{
    function __construct(string $name)
    {
    }
}

class Team
{
    function __construct(Person $manager)
    {
    }
}

function main(): void
{
    let $team = new Team(new Person("Ada"));
    echo $team->manager->name;
}
```
