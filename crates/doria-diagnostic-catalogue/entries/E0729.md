# Override Contract Does Not Match

Title: fixed
Family: classes

## Explanation

An `override` replaces an open method or property of a parent class and keeps its contract, so code written against the parent works with the subclass. This error means the override changes something that the inherited declaration fixes.

For a method, the parameter names, types and ownership modes and the generic parameters are the same as in the inherited method. Default values belong to the first `open` declaration, and an override declares none. The override may return a subclass of the inherited return class, may drop `writable` from the receiver, and may declare fewer errors after `throws`.

An overriding property keeps the inherited type and the contract of each inherited accessor.

## Fix

Copy the parameter list of the inherited method into the override, with the same names, types and modes, and remove any default values. Give the override the inherited return type, or a subclass of it.

If the subclass needs a different signature, declare a new method under another name and leave the inherited one as it is.

## Example

```doria
open class Shape
{
    open function scale(int $factor): int
    {
        return $factor;
    }
}

class Square extends Shape
{
    override function scale(string $factor): int
    {
        return 1;
    }
}

function main(): void
{
    let $square = new Square();
    echo $square->scale("2");
}
```
