# Function Value Is No Longer Available

Title: varies
Family: functions

## Explanation

A function value is a move value. Assigning it to another variable, passing it to a `take` parameter, or capturing it with `take` moves it, and the variable it came from cannot be used afterward. Calling a `function once(...)` value uses it up in the same way.

This error means the program uses a function value after it was moved or consumed, or on a path where it may have been. It is also reported when a `take` capture names a value that was already moved, for example into an earlier closure.

## Fix

Keep the function value in one variable and call it through that variable. To have two function values, write the closure twice.

Call a `function once(...)` value one time and keep its result in a variable. Move a value into one closure only.

## Example

```doria
function main(): void
{
    let $double = fn(int $value) => $value * 2;
    let $copy = $double;
    echo $double(21);
    echo $copy(21);
}
```
