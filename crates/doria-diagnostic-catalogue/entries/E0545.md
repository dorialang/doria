# Shared Reference Requires A Class Payload

Title: varies
Family: ownership

## Explanation

`SharedReference<T>` and `WeakReference<T>` hold a class. This error means a type is written as `SharedReference<T>` or `WeakReference<T>` with a `T` that is not a class, such as `SharedReference<List<int>>` or `SharedReference<int>`, or `shared new` names a type that is not an ordinary class, such as `Bytes`.

## Fix

Put the value in a property of a class and share the class with `shared new`.

To share a collection or `Bytes` directly, use the writable family: `new WritableSharedReference(["Ada"])`. Its access objects, from `acquireReadonlyAccess()` and `acquireWritableAccess()`, forward member and indexed operations to the value.

If the value has one owner, keep it as an ordinary value and remove `shared`.

## Example

```doria
function total(SharedReference<List<int>> $scores): int
{
    return $scores->count;
}

function main(): void
{
}
```
