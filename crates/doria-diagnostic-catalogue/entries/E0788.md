# Unknown Foreign ABI

Title: fixed
Family: unsafe

## Explanation

An `extern` form names an ABI Doria does not have. `extern "C"` is the only one: it means the target's C calling convention on every tier-1 platform, so one binding works unchanged on Linux, macOS and Windows.

## Fix

Write `extern "C"`. The fix replaces the ABI string.

## Example

```doria
extern "system"
{
    /** @safety Any value is valid. */
    function abs(int32 $value): int32;
}

function main(): void
{
}
```
