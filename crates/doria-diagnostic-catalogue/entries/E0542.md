# `shared new` Cannot Construct A Shared-Ownership Type

Title: varies
Family: ownership

## Explanation

`shared new T(...)` constructs a `SharedReference<T>` that holds an ordinary class `T`. This error means the type after `shared new` is itself one of the six shared-ownership types: `SharedReference`, `WeakReference`, `WritableSharedReference`, `WritableWeakReference`, `ReadonlySharedReferenceAccess` or `WritableSharedReferenceAccess`.

## Fix

For a shared value that will be changed, remove `shared` and construct it with `new WritableSharedReference(new T(...))`. For a readonly shared value, name the class itself: `shared new T(...)`.

A weak reference comes from `createWeakReference()`, and an access object comes from `acquireReadonlyAccess()` or `acquireWritableAccess()`.

## Example

```doria
class Node
{
    string $name = "root";
}

function main(): void
{
    let $node = shared new WritableSharedReference(new Node());
    let $access = $node->acquireReadonlyAccess();
    echo $access->name;
}
```
