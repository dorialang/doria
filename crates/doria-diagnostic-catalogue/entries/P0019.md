# Given Block Before Do-While

Title: varies
Family: syntax

## Explanation

A `given` block holds setup declarations and bool predicates for the control statement that follows it. It attaches to `if`, `when` and `while`. It does not attach to `do ... while`.

## Fix

Remove `given` and declare the variables as ordinary statements before `do`. They stay in scope for the body and the condition of the loop.

If the block held a predicate, test it with an `if` around the loop.

## Example

```doria
function main(): void
{
    let writable $count = 0;
    given {
        let $limit = 3;
    } do {
        $count = $count + 1;
    } while ($count < $limit);
    echo $count;
}
```
