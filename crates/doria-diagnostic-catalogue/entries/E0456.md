# Format Arguments Do Not Match The Format

Title: varies
Family: strings

## Explanation

`printf` and `sprintf` take one argument after the format for each conversion in it. `%%` takes no argument. This error means the number of arguments after the format differs from the number of conversions.

## Fix

Pass one value for each conversion, in the order the conversions appear. Remove a conversion that has no value, or remove a value that has no conversion.

## Example

```doria
function main(): void
{
    printf("%s has %d items", "cart");
}
```
