# Unknown Static Member

Title: varies
Family: names

## Explanation

The program names `ClassName::member`, and the class declares no constant and no static property with that name. A property declared without `static` belongs to each object, so it cannot be reached through the class name.

## Fix

Check the spelling and the case of the name. Constants are written in `SCREAMING_SNAKE_CASE`, and a static property is accessed without `$`. If the member is missing, declare it in the class with `const` or `static`.

To read a property of an object, use the object: `$limits->depth`.

## Example

```doria
class Limits
{
    const MAX_DEPTH = 8;
}

function main(): void
{
    echo Limits::MAX_WIDTH;
}
```
