# Region Owner Is Not A Place

Title: fixed
Family: unsafe

## Explanation

`ByteRegion::fromPointer`, `WritableByteRegion::fromPointer`, `ArrayRegion::fromPointer` and `WritableArrayRegion::fromPointer` view memory a foreign library allocated. The region borrows its first argument, the owner: the Doria value whose destructor gives the memory back to the library. The owner must be a place that outlives the region: a local, `$this` or a property. A computed value, such as a call result, would be destroyed at the end of its statement while the region still views the memory it released.

## Fix

Store the owner in a local first and pass the local: `let $image = decodeImage($path);` then `ByteRegion::fromPointer($image, $image->pixels, $image->length)`. Inside the owner class, pass `$this` and return the region from a method, which borrows `$this`.

## Example

```doria
use Doria\Std\Ffi\Pointer;
use Doria\Std\Io\ByteRegion;

class Buffer
{
    function __construct(internal Pointer<uint8> $bytes) {}
}

function main(): void
{
    unsafe {
        uint8 $byte = 1;
        let $region = ByteRegion::fromPointer(new Buffer(Pointer::to($byte)), Pointer::to($byte), 1);
    }
}
```
