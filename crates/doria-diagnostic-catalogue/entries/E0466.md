# Constructor Or Destructor Declared `writable` Or `consuming`

Title: varies
Family: classes

## Explanation

`writable` and `consuming` say how an ordinary method uses `$this`. `__construct` and `__destruct` are called by the language: `new` runs the constructor, and the destructor runs when the object is destroyed. Their access to the object comes from construction and destruction, so neither modifier applies to them.

A constructor declared as plain `function __construct` can already initialize every property and change the `writable` ones.

## Fix

Remove `writable` or `consuming` from the declaration and leave the body as it is: `function __construct()`. An editor offers the removal as a quick fix.

## Example

```doria
class Counter
{
    writable int $count = 0;

    writable function __construct()
    {
        $this->count = 1;
    }
}

function main(): void
{
    let $counter = new Counter();
    echo $counter->count;
}
```
