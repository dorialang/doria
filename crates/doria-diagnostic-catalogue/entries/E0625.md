# Try Requires Catch Or Finally

Title: fixed
Family: errors

## Explanation

A `try` block is followed by one or more `catch` clauses, a `finally` block, or both. This error means the `try` block stands alone, so it handles no error and runs no cleanup.

## Fix

Add a `catch` clause for an error the block can throw, as in `catch (ParseError $error) { ... }`, or add a `finally` block for code that must run when the block is left.

If neither is needed, remove `try` and its braces and keep the statements.

## Example

```doria
function main(): void
{
    try {
        echo "saving";
    }
}
```
