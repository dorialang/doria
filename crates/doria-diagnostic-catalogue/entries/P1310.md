# Collection Index Is Out Of Bounds

Title: fixed
Family: runtime

## Explanation

An index was used on a `List<T>` or a typed array `T[]` that has no element at that position. Valid indexes run from `0` to one less than the number of elements. `$list[$index]` asserts that the element exists and panics when it is missing; it does not produce `null`.

`removeAt` panics with this code for a position that has no element. `insertAt` accepts positions from `0` up to and including `count`, and panics beyond that.

## Fix

To read an element that may be missing, use `get`, which returns `null` when the index is out of range: `$names->get($index) ?? "nobody"`.

To test first, compare the index with `count` on a list or with `length` on a typed array. For the last element of a list, read the `last` property, which is `null` when the list is empty.

## Example

```doria
function main(): void
{
    List<string> $names = ["Ada", "Grace"];
    echo $names[2];
}
```
