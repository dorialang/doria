# Invalid Match Pattern

Title: varies
Family: enums

## Explanation

A pattern can never match a value of the type being matched. Doria applies no conversions to patterns, so a `string` literal does not match an `int`, and a case of one enum does not match a value of another enum.

The `null` pattern is valid only when the matched value is nullable or `mixed`. A type pattern, written `Type $binding`, names one exact type that the matched value can have; it cannot name a nullable type or `mixed`.

In `match (true)` every arm is a `bool` condition or `default`. Other patterns are rejected there.

## Fix

Write a pattern of the matched type: a literal or constant of that type, or a case of the matched enum.

Use `null` for absence only when the matched value is nullable, and `default` for everything the other arms leave over.

## Example

```doria
function label(int $count): string
{
    return match ($count) {
        "one" => "single",
        default => "many",
    };
}

function main(): void
{
    echo label(1);
}
```
