# Undeclared Variable

Title: varies

## Explanation

The program reads or assigns a variable that is not declared in the current scope. Every variable is declared before its first use, and assigning to a new name does not declare it.

A variable declared inside a block, such as the body of an `if` or a loop, ends with that block.

## Fix

Declare the variable with `let`, as in `let $total = 0;`, or with its type, as in `int $total = 0;`. Add `writable` if it will be assigned again: `let writable $total = 0;`.

If the variable exists under another name, check the spelling and the case. If it was declared inside a block, declare it before the block.

## Example

```doria
function main(): void
{
    let $price = 4;
    $total = $price * 2;
}
```
