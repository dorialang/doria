# Owned Static Values Are Reserved For A Later Release

Title: varies
Family: classes
Availability: later

## Explanation

A static property holds a value that is owned, such as a `List`, a `Dictionary` or a class instance. Doria reserves owned static values for a later release. A static property today holds a Copy type, such as a number, a `bool` or a `string`.

The reservation exists because a static is one value for the whole program, and how an owned value is shared safely across the program is decided together with Doria's concurrency rules.

## Fix

Keep the owned value in an object and pass that object to the code that needs it. A class with an ordinary property, as in `internal writable List<string> $names = [];`, created once in `main`, does the work of a registry.

A static property of a Copy type works as before: `static writable int $registered = 0;`.

## Example

```doria
class Registry
{
    static writable List<string> $names = [];
}

function main(): void
{
}
```
