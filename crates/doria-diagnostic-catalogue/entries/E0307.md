# Method Or Static Member Is Internal

Title: varies

## Explanation

The program calls a method, uses a static member, or creates an object through a constructor that its class marks `internal`. An internal member is part of the class's implementation and can be used only from inside that class.

## Fix

Use an externally accessible member of the class that does the same work, or add one. When the constructor is internal, create the object through the static method the class provides for that purpose.

Remove `internal` from the member only if it is meant to be part of the class's surface.

## Example

```doria
class Account
{
    internal function audit(): void
    {
        echo "audited";
    }
}

function main(): void
{
    let $account = new Account();
    $account->audit();
}
```
