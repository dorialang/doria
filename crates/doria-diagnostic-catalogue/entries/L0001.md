# Invalid Token

Title: varies
Family: syntax

## Explanation

The source contains text that does not form a Doria token. The message names the problem: a string literal with no closing quote, an interpolation `{` with no closing `}`, a `$` with no variable name after it, `?-` without the `>` that completes `?->`, or a character that begins nothing in Doria.

The operators `===` and `!==` are reported under this code. Doria has one equality operator, `==`, and one inequality operator, `!=`. Both are typed: comparing values of different types, such as `1 == "1"`, is a type error.

## Fix

Write `==` for `===` and `!=` for `!==`.

Close a string literal with the quote that opened it, and close every interpolation `{` with `}`. Inside a string, write its own quote character as `\"` or `\'`. An unclosed string runs to the end of the file, and the error is marked where the string opens.

For an unexpected character, remove it or write the Doria spelling of what was meant.

## Example

```doria
function main(): void
{
    let $count = 3;
    if ($count === 3) {
        echo "three";
    }
}
```
