# Property Value Cannot Be Given Away

Title: varies
Family: ownership

## Explanation

A property whose type is a move type, such as a class or a collection, owns its value, and the object keeps that value for as long as the object exists. This error means the program names such a property where ownership is transferred: as the argument for a `take` parameter, or as the initializer of a new variable, as in `let $engine = $car->engine;`.

## Fix

To read the value, use the property where it is, as in `$car->engine->power`, or pass it to a readonly parameter.

To move the value out for good, add a `consuming function` to the class and return `take $this->engine` from it. Calling that method ends the object: its other properties are destroyed, and the variable that held the object cannot be used afterward.

## Example

```doria
class Engine
{
    function __construct(int $power)
    {
    }
}

class Car
{
    function __construct(take Engine $engine)
    {
    }
}

function scrap(take Engine $engine): void
{
    echo $engine->power;
}

function main(): void
{
    let $car = new Car(new Engine(90));
    scrap($car->engine);
}
```
