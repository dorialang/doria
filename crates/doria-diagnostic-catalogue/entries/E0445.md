# Value Cannot Be Echoed

Title: varies
Family: strings

## Explanation

`echo` writes a `string`, a number, a `bool` or a class value that implements `Displayable`. This error means the value has another type, such as a `List`, a typed array, `null`, or a nullable value that may be `null`.

## Fix

For a collection, write each element in a `foreach`, or join a `List<string>` into one string with `String::join(", ", $names)`.

For a nullable value, supply a fallback with `??`, as in `echo $name ?? "unknown";`, or test for `null` first.

## Example

```doria
function main(): void
{
    List<string> $names = ["Ada", "Grace"];
    echo $names;
}
```
