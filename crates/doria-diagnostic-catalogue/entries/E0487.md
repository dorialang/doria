# Static Or Instance Method Called The Wrong Way

Title: varies
Family: classes

## Explanation

A static method belongs to its class and has no `$this`. It is called on the class with `::`, as in `Temperature::toFahrenheit(21.5)`. An instance method works on an object and is called with `->`. This error means a static method is called through an object with `->`, or an instance method is called on a class name with `::`.

## Fix

Call a static method as `ClassName::method()`, or as `self::method()` inside its class. Call an instance method on an object: `$greeter->greet("Ada")`.

If a method never uses `$this` and should be callable without an object, declare it `static function`.

## Example

```doria
class Temperature
{
    static function toFahrenheit(float $celsius): float
    {
        return $celsius * 1.8 + 32.0;
    }
}

function main(): void
{
    let $temperature = new Temperature();
    echo $temperature->toFahrenheit(21.5);
}
```
