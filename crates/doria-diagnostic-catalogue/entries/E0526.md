# `main` Takes No Parameters Or One `List<string>`

Title: varies
Family: functions

## Explanation

`main` is where the program starts. It takes no parameters, or exactly one `List<string>` that holds the program's arguments. This error means `main` declares more than one parameter, a parameter of another type, or a parameter marked `writable` or `take`.

There is no separate argument count. The list carries its own length in `count`.

## Fix

Declare `function main(): void`, or `function main(List<string> $args): void` to receive the program's arguments. Read the number of arguments from `$args->count`.

## Example

```doria
function main(int $count, List<string> $args): void
{
    echo $count;
}
```
