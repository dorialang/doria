# Variable Is Already Declared

Title: varies

## Explanation

A declaration introduces a variable whose name is already declared in the same scope. A scope holds one variable under each name. The same code is raised when one `match` pattern binds the same name twice.

## Fix

To give the existing variable a new value, declare it `writable` and assign to it without `let` or a type: `let writable $name = "Ada";` and later `$name = "Grace";`.

To keep both values, give the second variable another name.

## Example

```doria
function main(): void
{
    let $name = "Ada";
    let $name = "Grace";
    echo $name;
}
```
