# Attribute Schema Parameter Must Be Readonly

Title: fixed
Family: projects

## Explanation

The constructor parameters of a class marked with `#[Attribute]` describe the values an application supplies. Those values are constants recorded as metadata. Applying an attribute runs no constructor, so there is nothing for a parameter to change or to take ownership of.

This error means a constructor parameter of an attribute class is declared `writable` or `take`.

## Fix

Remove `writable` or `take` from the parameter, leaving its type and name: `function __construct(string $path)`.

## Example

```doria
#[Attribute]
class Route
{
    function __construct(writable string $path)
    {
    }
}

function main(): void
{
    echo "ready";
}
```
