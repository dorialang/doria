# Byte Buffer Length Cannot Be Negative

Title: fixed
Family: runtime

## Explanation

`Bytes::allocate` received a negative length. The length is the number of bytes to allocate, so it must be zero or greater. A length of `0` is valid and gives an empty buffer.

The usual cause is a subtraction that goes below zero, such as a total size minus a header size when the total is the smaller of the two.

## Fix

Test the values before allocating, as in `if ($total >= $header)`, and handle the short case on the other branch.

## Example

```doria
function main(): void
{
    let $header = 16;
    let $total = 10;
    let $body = Bytes::allocate($total - $header);
    echo $body->length;
}
```
