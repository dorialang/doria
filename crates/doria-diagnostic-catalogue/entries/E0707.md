# Test Body Closure Returns Void

Title: varies
Family: testing

Example source: development

## Explanation

The body closure of `describe`, `it` and `test` returns `void`. A test reports its result through its expectations, and a returned value plays no part.

This error means the closure declares another return type, or the expression of an arrow closure has a value, as in `fn() => 1 + 1 == 2`.

## Fix

Declare the closure `function (): void { ... }` and state the check as an expectation: `expect(1 + 1)->toEqual(2);`.

An arrow closure may hold one expectation: `fn() => expect(1 + 1)->toEqual(2)`.

## Example

```doria
use Doria\Std\Test\it;

it("adds two numbers", function (): bool {
    return 1 + 1 == 2;
});
```
