# Field Cannot Be Taken

Title: fixed
Family: ownership

## Explanation

`take $this->field` moves the value of a property out of an object. The object ends at that point: its other properties are destroyed, and its `__destruct` method does not run. This is allowed only inside a `consuming function`, whose caller gives the object up.

This error means the `take` is written where that cannot happen. The method is not `consuming`, the object is not `$this`, or the access uses `?->`. It is also raised when the class is `open`, when an ancestor of the class declares `__destruct`, when the property comes from a `borrow` constructor parameter, and when the property is computed and stores no value.

## Fix

Declare the method `consuming function` and take from `$this`. The caller cannot use the object after the call.

In an `open` class, or a class whose ancestor declares `__destruct`, keep the object whole and return the property without `take`. A `borrow` property belongs to the caller, who already has the value.

## Example

```doria
class Envelope
{
    function __construct(take List<string> $pages) {}

    function unpack(): List<string>
    {
        return take $this->pages;
    }
}

function main(): void
{
    let $envelope = new Envelope(["one", "two"]);
    let $pages = $envelope->unpack();
    echo $pages->count;
}
```
