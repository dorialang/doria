# Control Transfer Cannot Leave Finally

Title: fixed
Family: control-flow

## Explanation

A `finally` block runs when its construct is left, on normal completion and when a `return`, `break` or `continue` in the body leaves it. A transfer inside `finally` may target only control flow that is wholly inside that `finally` block.

This error means the `finally` block contains a `return`, `break` or `continue` that would leave the block.

## Fix

Move the `return`, `break` or `continue` into the body of the construct, or after the construct.

A loop declared inside the `finally` block may use `break` and `continue`, and a `when` inside it may use `return expression;`.

## Example

```doria
function main(): void
{
    int $count = 3;
    if ($count > 1) {
        echo "many";
    } finally {
        return;
    }
}
```
