# Type Argument Cannot Be Inferred

Title: varies
Family: generics

## Explanation

A call to a generic function, method or enum case works out its type arguments from the arguments it is given. This error means the arguments leave a type parameter undetermined. `first([])` says nothing about `T`, because an empty list has no element type.

## Fix

State the type arguments at the call, one for each type parameter in order: `let $value = first<int>([]);`.

Or declare the result with its type, so that the expected type settles the type parameter: `?int $value = first([]);`.

Or pass an argument whose type is known, such as a variable declared `List<int>`.

## Example

```doria
function first<T>(List<T> $items): ?T
{
    return $items->first;
}

function main(): void
{
    let $value = first([]);
}
```
