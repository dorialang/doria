# Byte Index Is Out Of Bounds

Title: fixed
Family: runtime

## Explanation

An indexed read or write on a `Bytes` buffer or a byte region used an index that the buffer does not have. Valid indexes run from `0` to `length - 1`. An index equal to `length` is one past the last byte, and a negative index is never valid.

A `ByteRegion` or `WritableByteRegion` has its own range. Its indexes count from the start of the region, and its own `length` is the limit.

## Fix

Compare the index with `length` before using it: `if ($index < $bytes->length)`. To visit every byte, loop over the exclusive range: `foreach (0..<$bytes->length as int $index)`.

When the index comes from data, such as an offset read from a file header, check it before the first indexed access and handle the case where it is too large.

## Example

```doria
function main(): void
{
    let $bytes = Bytes::allocate(2);
    echo $bytes[2];
}
```
