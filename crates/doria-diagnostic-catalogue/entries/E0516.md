# Unknown Named Argument

Title: fixed
Family: functions

## Explanation

A call or an attribute names an argument, as in `length: 12`, and the function, method, constructor or attribute it addresses has no parameter with that name. A named argument matches a parameter by its declared name, written without the `$`.

## Fix

Use a parameter name from the declaration. The message lists the available names and suggests the closest one when the name looks like a misspelling.

If the declaration is meant to accept the value, add a parameter with that name.

## Example

```doria
function save(string $name, int $size = 0): void
{
    echo "{$name}: {$size}";
}

function main(): void
{
    save("notes", length: 12);
}
```
