# Unused Unsafe Context

Title: fixed
Family: unsafe

## Explanation

This warning means an unsafe context contains nothing that needs one, or is written inside another unsafe context, which already covers everything in it. An unsafe context marks where a program takes responsibility for conditions the compiler cannot check; one that covers nothing makes that boundary harder to read.

## Fix

Remove the `unsafe`. Keep each unsafe context around the operations that need it.

## Example

```doria
function main(): void
{
    unsafe {
        echo "nothing here needs an unsafe context";
    }
}
```
