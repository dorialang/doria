# Class Inheritance Cycle

Title: fixed
Family: classes

## Explanation

A class cannot be its own ancestor. This error means the `extends` clauses form a loop: a class extends itself, or a chain of parents leads back to the class it started from. The message lists the classes in the cycle in order.

## Fix

Remove one `extends` clause from the loop so that the chain ends at a class with no parent. Decide which class is the most general, declare it without `extends`, and have the others extend it.

## Example

```doria
open class Draft extends Post
{
}

open class Post extends Draft
{
}

function main(): void
{
    let $post = new Post();
    echo "created";
}
```
