# Test Body Must Be Written As A Closure

Title: varies
Family: testing

Example source: development

## Explanation

The second argument of `describe`, `it` and `test` is the body. It is a closure written at the declaration: `function (): void { ... }`, or an arrow closure such as `fn() => expect(1 + 1)->toEqual(2)`. The compiler reads the test from that closure.

This error means the second argument is another kind of expression, such as a call that returns a function value, or a value that is not a function.

## Fix

Write the closure in place. To reuse checks that live in a function, call the function from the closure: `it("adds two numbers", function (): void { checkAddition(); });`.

## Example

```doria
use Doria\Std\Test\{it, expect};

function additionCheck(): function(): void
{
    return function (): void {
        expect(1 + 1)->toEqual(2);
    };
}

it("adds two numbers", additionCheck());
```
