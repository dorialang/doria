# Standard Device Write Failed

Title: fixed
Family: runtime

## Explanation

This code names a write to standard output or standard error that failed and ended the program as a panic. It is a historical identity. `echo`, `printf`, `write_stderr`, `write_stdout_bytes` and `write_stderr_bytes` report a failed write as a checked `Doria\Std\Io\IoError`, which the program can catch.

A closed pipe is not a failure: a program that writes to a closed standard output or standard error ends cleanly with status 0. An `IoError` that nothing catches ends the program with R1000 under the title `Unhandled Doria\Std\Io\IoError`.

## Fix

Where the program can recover, wrap the write in `try` and add `catch (Doria\Std\Io\IoError $error)`. `$error->message` describes the failure, and `$error->target` says which device was being written.

## Example

No program raises this code on demand: a failed write to a standard device reaches the program as a `Doria\Std\Io\IoError`, so no write ends with this panic. A programmer meets the same failure as R1000 when the error is not caught.
