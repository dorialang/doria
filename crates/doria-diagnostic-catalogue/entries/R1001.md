# Assertion Failed

Title: fixed
Family: runtime

## Explanation

An expectation in a behavioral test was not met, and nothing caught the failure. `expect($actual)` followed by a matcher such as `toEqual`, `toContain` or `toBeNull` compares a value with what the test requires, and `fail("...")` fails every time it runs. The report names the matcher, the expected and actual values where they apply, and the source location of the expectation.

`expect`, `fail` and `it` belong to `Doria\Std\Test`. Only development source, such as the tests of a project, may import that module.

## Fix

Read the expected and actual values in the report and decide which one is wrong. Correct the code under test when the expectation states the intended behavior. Correct the expectation when the behavior changed on purpose.

To require the opposite of a matcher, put `not` before it: `expect($roles)->not->toContain("guest")`.

## Example

No program raises this code on demand: `expect` and `fail` are accepted only in development source, so a program built from production source cannot reach them. A programmer meets this outcome in the results of `baton test`, where a failing behavioral test is listed as `Assertion Failed`.
