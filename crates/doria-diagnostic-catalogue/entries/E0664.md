# List Algorithm Requires A Repeatable Callback

Title: fixed
Family: collections

## Explanation

`map`, `filter` and `reduce` on a `List<T>` call their callback once for every element. A `function once(...)` value can be called one time only, so it cannot serve as the callback.

A closure is a `function once(...)` value when calling it gives away something it captured with `take`, for example by returning the captured value.

## Fix

Write the callback so that it can run for every element. Create the value it returns inside the callback, or read a captured value without giving it away: capture with `with ($token)` and return a Copy value such as `$token->name`.

## Example

```doria
class Token
{
    string $name = "session";
}

function main(): void
{
    List<int> $values = [1, 2, 3];
    let $token = new Token();
    let $tokens = $values->map(function (int $value): Token with (take $token) {
        return $token;
    });
    echo $tokens->count;
}
```
