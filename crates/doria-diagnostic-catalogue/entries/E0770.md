# Property Hook May Block

Title: fixed
Family: interfaces

## Explanation

A property hook runs whenever the property is read or assigned, so it must finish without waiting. This error means a `get` or `set` hook performs input or output that can wait, such as `echo` or `read_line`.

The rule follows calls. A hook is rejected when a function, a method, another property's hook or a callback that it calls performs such work. Catching the `IoError` does not change this.

## Fix

Do the input or output outside the hook: in the code that reads or assigns the property, or in a method that the caller calls by name.

To report something that the hook observed, have the hook record it in a property, and print it from the calling code after the hook returns.

## Example

```doria
class Order
{
    function __construct(int $quantity, int $unitPrice) {}

    int $total {
        get {
            echo "computing total\n";
            return $this->quantity * $this->unitPrice;
        }
    }
}

function main(): void
{
    let $order = new Order(3, 20);
    echo $order->total;
}
```
