# Constructor Parameter Roles Conflict

Title: fixed
Family: classes

## Explanation

A constructor parameter has one role. `internal` makes it an internal property, `override` ties it to an inherited property, and `parameter` keeps it as an input that does not become a property. With no role word, the parameter becomes an externally accessible property. This error means one parameter carries two different role words.

## Fix

Keep one of `internal`, `override` and `parameter` and remove the other.

## Example

```doria
class Person
{
    function __construct(internal parameter string $name)
    {
        echo $name;
    }
}

function main(): void
{
    let $person = new Person("Ada");
}
```
