# Duplicate Match Pattern

Title: fixed
Family: enums

## Explanation

Arms are tested in order, and the first arm whose pattern matches is chosen. This error means an arm repeats the pattern of an earlier arm that has no guard: the same enum case, literal, constant, `null`, or type pattern. The later arm could never be chosen.

A pattern may repeat after an arm with an `if` guard, because that arm is passed over when its guard is false.

## Fix

Remove the repeated arm, or change its pattern to the value it was meant to match.

To choose between two results for the same pattern, put an `if` guard on the first of the two arms.

## Example

```doria
function label(bool $enabled): string
{
    return match ($enabled) {
        true => "on",
        true => "enabled",
        false => "off",
    };
}

function main(): void
{
    echo label(true);
}
```
