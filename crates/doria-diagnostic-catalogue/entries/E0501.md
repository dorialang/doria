# Property Read Before Initialization

Title: varies
Family: classes

## Explanation

A constructor reads a property of `$this` that has no value yet. The property is unassigned on every path to the read, or it is assigned on only some of them, for example inside one branch of an `if`.

Properties with an initializer and constructor parameters that become properties have their values when the body starts. Every other property gets its value from an assignment in the body, and statements run in order.

## Fix

Move the assignment above the read, and make sure every path to the read assigns the property. If the value is already at hand in a parameter or a local variable, read that.

## Example

```doria
class Token
{
    string $value;
    int $length;

    function __construct(parameter string $text)
    {
        $this->length = $this->value->length;
        $this->value = $text;
    }
}

function main(): void
{
    let $token = new Token("abc");
    echo $token->length;
}
```
