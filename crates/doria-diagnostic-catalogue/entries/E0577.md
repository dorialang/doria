# Unknown Enum Member

Title: varies
Family: enums

## Explanation

The program reads a property or calls a method on an enum value, and the enum has no such member. An enum declares cases only. It has no methods, and its one property is `value`, which exists on backed enums. Unit enums and payload enums have no `value`.

The fields of a payload case are not properties. `$point->x` is rejected even when a case declares a field `$x`.

## Fix

Read payload fields with `match`, binding them in a case pattern: `Coordinate::Point($x, $y) => $x`.

To read `value`, declare the enum with a backing type, as in `enum Status: int`, and give every case a value. For any other behavior, write a function that takes the enum and selects a result with `match`.

## Example

```doria
enum Coordinate
{
    case Point(int $x, int $y);
}

function main(): void
{
    Coordinate $point = Coordinate::Point(1, 2);
    echo $point->x;
}
```
