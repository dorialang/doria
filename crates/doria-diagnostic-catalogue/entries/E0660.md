# Once Function Cannot Be Consumed From Stored Place

Title: fixed
Family: functions

## Explanation

Calling a `function once(...)` value uses it up, so the call needs to own the function value. A property or a collection element stays where it is when it is read. This error means a `function once(...)` value is called directly from a property, as in `$this->callback()`, or from an element, as in `$pending[0]()`.

## Fix

For a list, take the element out with `removeAt`, which returns the owned function value, and call the result: `let $release = $pending->removeAt(0);` and then `$release()`.

A property cannot give its value away. Give a property that is called in place the type `function(...)` or `function writable(...)`, and keep a `function once(...)` value in a local variable or a `take` parameter until it is called.

## Example

```doria
class Report
{
    string $title = "Totals";
}

function main(): void
{
    let $report = new Report();
    writable List<function once(): Report> $pending = [];
    $pending->add(function (): Report with (take $report) {
        return $report;
    });
    let $released = $pending[0]();
    echo $released->title;
}
```
