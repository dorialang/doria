# `void` Used As A Value Type

Title: varies
Family: types

## Explanation

`void` says that a function or method returns nothing. It is valid only as a return type. This error means `void` is written as the type of a variable, a parameter or a property, as a type argument such as `List<void>`, or inside a nullable type such as `?void`.

## Fix

Give the place a value type, such as `int`, `string` or a class. A function that takes no arguments has an empty parameter list.

A `void` function has no result to store. Call it as a statement by itself.

## Example

```doria
function main(): void
{
    void $result = null;
    echo "done";
}
```
