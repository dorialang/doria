# Duplicate Enum

Title: fixed
Family: names

## Explanation

Two enum declarations have the same name. An enum name identifies one type, so it can be declared once.

Case names belong to their enum, so two different enums may both declare a case named `Draft`.

## Fix

Rename one of the enums. If the two declarations describe the same thing, merge their cases into one enum and remove the other.

## Example

```doria
enum Status
{
    case Draft;
    case Published;
}

enum Status
{
    case Open;
    case Closed;
}

function main(): void
{
    Status $status = Status::Draft;
}
```
