# Match Condition Must Be Bool

Title: fixed
Family: enums

## Explanation

`match (true)` tests the condition of each arm in order and chooses the first one that is `true`. This error means a condition has a type other than `bool`. Doria does not treat numbers, strings or `null` as true or false.

## Fix

Write a comparison that produces a `bool`. Test a number with `$count > 0` and a nullable value with `$name != null`.

## Example

```doria
function label(int $count): string
{
    return match (true) {
        $count => "some",
        default => "none",
    };
}

function main(): void
{
    echo label(1);
}
```
