# Inherited Member Cannot Be Hidden

Title: fixed
Family: classes

## Explanation

A subclass inherits the externally accessible members of its parent, and a class has one namespace for all of its members. This error means the subclass declares a member under a name that an inherited member already has, and the inherited member cannot be replaced.

Only a method or property declared `open` can be replaced, and only with `override`. An inherited method without `open`, a plain property, a constant and a static member cannot be declared again in a subclass.

An `internal` member of the parent is not inherited, so a subclass may declare its own member with that name.

## Fix

Give the member in the subclass a different name.

If the subclass is meant to replace an inherited method, declare the parent's method `open function` and the subclass's method `override function`.

## Example

```doria
open class Model
{
    function table(): string
    {
        return "models";
    }
}

class Post extends Model
{
    function table(): string
    {
        return "posts";
    }
}

function main(): void
{
    let $post = new Post();
    echo $post->table();
}
```
