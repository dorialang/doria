# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

A call passed checking, and the compiler then could not match one of its arguments to a parameter of the function or method being called. Checking matches every argument to a parameter, by position or by name, so an accepted call has no argument left over. The developer details name the callable and the position of the argument.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the argument, so keep that call and the declaration it calls, and remove the code around them.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that calls a function or method with arguments.
