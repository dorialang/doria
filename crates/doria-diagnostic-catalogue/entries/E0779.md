# Member Availability Condition Is Not Satisfied

Title: fixed
Family: generics

## Explanation

A method or property declared with `where (...)` exists only for the type arguments that meet its condition. This error means the program uses such a member where the condition is not known to hold.

With concrete type arguments, the type argument does not implement the interface. In the example, `Box<Parcel>` has no `describe` method because `Parcel` does not implement `Describable`.

In generic code, the caller's own type parameter lacks the bound. The condition must follow from the bounds the caller declares. That some later type argument would meet it is not enough.

## Fix

Use a type argument that implements the interface, or make the class implement it, as in `class Parcel implements Describable`.

In generic code, give the caller the same bound: `<T implements Describable>` on a function, or the same `where (...)` clause on the calling method.

## Example

```doria
interface Describable
{
    function describe(): string;
}

class Parcel
{
}

class Box<T>
{
    function __construct(take T $item) {}

    function describe(): string where (T implements Describable)
    {
        return $this->item->describe();
    }
}

function main(): void
{
    let $box = new Box<Parcel>(new Parcel());
    echo $box->describe();
}
```
