# Runtime Symbols Are Reserved

Title: fixed
Family: unsafe

## Explanation

A foreign declaration binds a symbol beginning with `dr_`. Those symbols belong to the Doria runtime: their interface is private and changes between releases. The standard library reaches the runtime through the compiler, never through foreign declarations.

## Fix

Use the standard library API for the behavior instead.

## Example

```doria
extern "C"
{
    /** @safety None. */
    function dr_v1_flush(): void;
}

function main(): void
{
}
```
