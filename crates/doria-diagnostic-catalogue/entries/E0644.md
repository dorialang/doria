# Invalid Closure Capture

Title: varies
Family: functions

## Explanation

A `with` clause captures local variables and parameters of the scopes that enclose the closure, and `$this` inside an instance method. This error means the closure asks for something a `with` clause cannot give.

The entry may name a parameter or local variable of the closure itself, which already belongs to the closure. It may name something that is not an enclosing variable, such as a constant written with `$`. The closure may use `$this` where no instance method encloses it, as in a top-level function or a static method. Or the clause says `take $this`, and a method does not own its receiver.

## Fix

Remove an entry that names the closure's own parameter or local variable. Remove an entry for a constant, a top-level function, a type name or an enum case, and use that name directly in the body.

Capture the receiver as `with ($this)`, or as `with (writable $this)` inside a `writable function`. Outside an instance method, pass the object to the closure as a parameter or capture a local variable that holds it.

## Example

```doria
function main(): void
{
    let $double = fn(int $value) with ($value) => $value * 2;
    echo $double(21);
}
```
