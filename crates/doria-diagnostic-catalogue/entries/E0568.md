# Plain Case Cannot Have A Backing Value

Title: fixed
Family: enums

## Explanation

An enum declared without a backing type is a plain enum, and its cases carry no backing values. This error means a case of a plain enum is written with `= value`.

Backing values belong to a backed enum, which names `int` or `string` after the enum name and gives every case one value.

## Fix

Remove `= value` from the case.

To give the cases backing values, declare the backing type, as in `enum Status: int`, and give every case a unique value of that type.

## Example

```doria
enum Status
{
    case Draft = 1;
    case Published;
}

function main(): void
{
    Status $status = Status::Draft;
    echo match ($status) {
        Status::Draft => "draft",
        Status::Published => "published",
    };
}
```
