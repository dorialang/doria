# String Repetition Count Cannot Be Negative

Title: fixed
Family: runtime

## Explanation

`String::repeat($text, $count)` returns `$count` copies of `$text` joined together. The count cannot be negative. This panic means a negative count reached the call when the program ran.

## Fix

Pass a count of zero or more. Zero gives an empty string.

When the count is calculated, for example an indent depth minus one, test it before the call.

## Example

```doria
function main(): void
{
    let $depth = 1 - 3;
    echo String::repeat("  ", $depth);
}
```
