# Type Mismatch

Title: fixed

## Explanation

A value was used where a different type is required: in a typed declaration, an assignment, an argument, or a return. Doria performs no implicit conversions, including from `int` to `float` or from a number to a `string`.

## Fix

Give the place a value of the type it declares, or change the declared type. To convert, use the companion of the target type, for example `Int::parse($text)` for text to `?int`, or build a string by interpolation: `"{$count}"`.

When the value is nullable and the place is not, supply a fallback with `??` or test for `null` first.

## Example

```doria
function main(): void
{
    int $count = "three";
    echo $count;
}
```
