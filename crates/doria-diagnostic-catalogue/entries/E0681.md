# Declaration Is Not Part Of This Compilation

Title: varies
Family: projects

## Explanation

The program refers to something that none of the source given to the compiler provides. Most often it is a qualified name such as `App\Models\User`, written in a `use` statement or directly in code, that no source in the compilation declares. The same code is raised for an `include` whose file is not part of the compilation.

`use` gives a declaration a short name. It does not load a file or a package. A file checked alone with `doriac check` is the whole compilation: a name declared in another file of the project is not available to it, and an `include` is not followed.

## Fix

Check the spelling of the qualified name against the `namespace` statement and the declaration it should reach. Names are case-sensitive.

When the declaration lives in another file of the project, check the project as a whole with `baton check`, which gives the compiler every source file of the package and its dependencies. When it lives in another package, declare that package as a dependency of the project.

## Example

```doria
use App\Models\User;

function main(): void
{
    let $user = new User("Ada");
    echo $user->name;
}
```
