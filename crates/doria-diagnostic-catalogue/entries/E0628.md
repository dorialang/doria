# Unreachable Catch

Title: varies
Family: errors

## Explanation

The `catch` clauses of a `try` are tested in source order, and the first clause that covers the error handles it. This error means an earlier clause already covers everything this clause names, so this clause can never run.

`catch (Error)` catches every checked error, so no clause can follow it. A clause for a parent class covers the classes that extend it, so a clause for a child class cannot follow its parent's.

## Fix

Put the more specific clause first: a child class before its parent, and `catch (Error)` last.

Remove the clause if the earlier one already does what is needed.

## Example

```doria
class ParseError implements Error
{
    function __construct(string $message)
    {
    }
}

function parse(string $text): int throws ParseError
{
    if ($text == "") {
        throw new ParseError("empty input");
    }
    return $text->length;
}

function main(): void
{
    try {
        echo parse("abc");
    } catch (Error $error) {
        echo "failed";
    } catch (ParseError $error) {
        echo $error->message;
    }
}
```
