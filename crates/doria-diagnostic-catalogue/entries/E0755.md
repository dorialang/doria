# Interface Contract Does Not Match

Title: fixed
Family: interfaces

## Explanation

A class implements an interface requirement with a member that keeps the requirement's contract. This error means the class declares the member, and its signature differs from the one in the interface. The message names what differs: the parameter count, names, types or ownership modes, the receiver access, the return type, the checked errors, or the generic parameters.

The code is also reported when an interface redeclares a requirement of a parent interface with a different contract.

## Fix

Change the member in the class to the signature the interface declares.

If the requirement is the part that is wrong, change it in the interface and update every class that implements it.

## Example

```doria
interface Renderable
{
    function render(): string;
}

class Report implements Renderable
{
    function render(): int
    {
        return 1;
    }
}

function main(): void
{
    let $report = new Report();
    echo $report->render();
}
```
