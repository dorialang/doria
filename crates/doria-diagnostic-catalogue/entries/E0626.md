# Catch Must Name An Error Type

Title: fixed
Family: errors

## Explanation

A `catch` clause names the type of error it handles: a class that implements `Error`, or `Error`, which catches every checked error.

This error means the clause names another type, such as `string` or a class that does not declare `implements Error`.

## Fix

Name the error class that the `try` block can throw, as in `catch (ParseError $error)`. Use `catch (Error $error)` to handle any checked error.

The text of the error is available in the body as `$error->message`.

## Example

```doria
class ParseError implements Error
{
    function __construct(string $message)
    {
    }
}

function parse(string $text): int throws ParseError
{
    if ($text == "") {
        throw new ParseError("empty input");
    }
    return $text->length;
}

function main(): void
{
    try {
        echo parse("abc");
    } catch (string $error) {
        echo "failed";
    }
}
```
