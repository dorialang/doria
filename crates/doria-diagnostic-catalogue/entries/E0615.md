# Error Message Property Must Be Readonly

Title: fixed
Family: errors

## Explanation

The `Error` interface requires the `message` property to be readonly. An error receives its message when it is constructed and keeps it while it is thrown and caught.

This error means the class declares the property `writable`.

## Fix

Remove `writable` from the `message` property. Give the message its value through the constructor or in the property's initializer.

## Example

```doria
class ParseError implements Error
{
    writable string $message = "unexpected token";
}

function main(): void
{
    let $error = new ParseError();
    echo $error->message;
}
```
