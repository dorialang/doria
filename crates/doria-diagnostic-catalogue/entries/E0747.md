# Bytes Does Not Support Foreach

Title: fixed
Family: collections

## Explanation

`Bytes` is a byte buffer that is read and written by position. `foreach` does not accept it as a source.

## Fix

Loop over the positions with an integer range and read each byte by index: `foreach (0..<$data->length as int $index)` with `$data[$index]` in the body.

To loop over a copy of the bytes, call `$data->toArray()`, which gives a `uint8[]`: `foreach ($data->toArray() as uint8 $byte)`.

## Example

```doria
function main(): void
{
    Bytes $data = Bytes::fromArray([1, 2]);
    foreach ($data as int $byte) {
        echo $byte;
    }
}
```
