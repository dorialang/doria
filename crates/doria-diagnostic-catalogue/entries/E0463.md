# Class Does Not Satisfy `Displayable`

Title: varies
Family: strings

## Explanation

A class that declares `implements Displayable` must provide `function toString(): string`. The method takes no parameters, returns `string`, and is an instance method without `internal`, `static`, `writable`, type parameters or `throws`. This error means the method is missing or has another shape.

Doria has no `__toString` magic method, and member names use camelCase, so a method named `__toString` or `to_string` does not satisfy `Displayable`.

## Fix

Declare exactly `function toString(): string` in the class and return the text from it.

## Example

```doria
class Label implements Displayable
{
    function __construct(string $text)
    {
    }
}

function main(): void
{
    let $label = new Label("Doria");
    echo $label;
}
```
