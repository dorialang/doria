# Destructor Cannot Declare Parameters

Title: varies

## Explanation

A `__destruct` method declares parameters. Doria runs the destructor when the object is destroyed, and the program never calls it, so no arguments can reach it.

## Fix

Remove the parameters. Keep whatever the destructor needs in properties of the object, and set them in the constructor.

## Example

```doria
class Session
{
    function __destruct(int $code)
    {
    }
}

function main(): void
{
    let $session = new Session();
}
```
