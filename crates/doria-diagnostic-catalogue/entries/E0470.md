# Value Used After It Was Given Away

Title: varies
Family: ownership

## Explanation

A move value, such as a class instance or a collection, has one owner. Passing it to a `take` parameter, assigning it to another variable, storing it in a property or a collection, or calling a `consuming function` on it gives the value to a new owner. From that point the variable no longer holds a value, and this error means the program uses it again.

A value given away on one branch of an `if` counts as given away after the `if`.

## Fix

Move the last use of the variable before the point where the value is given away. If the receiving function only reads the value, remove `take` from its parameter so that the caller keeps ownership.

To use the variable again afterward, declare it `writable` and assign it a new value first.

## Example

```doria
class Ticket
{
    function __construct(string $holder)
    {
    }
}

function redeem(take Ticket $ticket): void
{
    echo "Redeemed for {$ticket->holder}";
}

function main(): void
{
    let $ticket = new Ticket("Ada");
    redeem($ticket);
    echo $ticket->holder;
}
```
