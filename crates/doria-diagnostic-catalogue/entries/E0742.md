# Override Parameter Type Does Not Match Property

Title: fixed
Family: classes

## Explanation

A constructor parameter marked `override` supplies an inherited property, and the property keeps the type its parent declared. This error means the parameter is declared with a different type.

## Fix

Declare the parameter with the exact type of the inherited property. For a generic parent, that is the property type with the parent's type arguments filled in.

To accept a value of another type, mark the parameter with `parameter` and convert the value in the arguments of `parent::__construct(...)`.

## Example

```doria
open class Document
{
    function __construct(string $title)
    {
    }
}

class Article extends Document
{
    function __construct(override int $title)
    {
        parent::__construct("untitled");
    }
}

function main(): void
{
    let $article = new Article(1);
    echo $article->title;
}
```
