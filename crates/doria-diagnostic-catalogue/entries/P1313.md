# Collection Allocation Failed

Title: fixed
Family: runtime

## Explanation

The runtime could not get the memory to create a collection or to grow one. A typed array, a `List`, a `Dictionary`, a `Set` and the other collection types can all end with this panic.

The usual cause is a count far larger than intended, for example in the repeat form `[value; count]`, or a loop that adds elements and never ends. The panic also occurs when the machine has no memory left for a collection of ordinary size.

## Fix

Check a computed count against a limit the program can justify before building the collection.

When the collection grows inside a loop, make sure the loop ends, and remove elements the program no longer needs.

## Example

```doria
function main(): void
{
    List<int> $cells = [0; 9223372036854775807];
    echo $cells->count;
}
```
