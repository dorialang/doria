# List Callback Has The Wrong Shape

Title: varies
Family: collections

## Explanation

Each `List<T>` algorithm fixes the shape of its callback. `map` takes `function(T): U`, a function of one element that returns a value. `filter` takes `function(T): bool`. `reduce` takes an initial value and `function(writable A, T): void`: the callback changes the accumulator in place through its first parameter and returns nothing.

This error means the argument is not a function value, or its parameters or its return type differ from that shape. The element parameter has exactly the list's element type and no `writable` or `take`.

## Fix

Give the callback the parameters the method expects. For `map` and `filter`, take one parameter of the element type.

For `reduce`, declare the accumulator `writable`, update it in the body, and return nothing: `$values->reduce(0, function (writable int $sum, int $value): void { $sum += $value; })`.

## Example

```doria
function main(): void
{
    List<int> $values = [1, 2, 3];
    let $add = fn(int $sum, int $value) => $sum + $value;
    let $total = $values->reduce(0, $add);
    echo $total;
}
```
