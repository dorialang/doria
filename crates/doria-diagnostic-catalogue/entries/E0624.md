# Throw Requires An Error Value

Title: fixed
Family: errors

## Explanation

`throw` is always followed by the error to throw. Doria has no bare `throw;` that throws the error being handled again.

## Fix

Name the caught error: `throw $error;`. The `catch` clause needs a binding for the body to name, as in `catch (ParseError $error)`.

## Example

```doria
class ParseError implements Error
{
    function __construct(string $message)
    {
    }
}

function parse(string $text): int throws ParseError
{
    if ($text == "") {
        throw new ParseError("empty input");
    }
    return $text->length;
}

function measure(string $text): int throws ParseError
{
    try {
        return parse($text);
    } catch (ParseError $error) {
        throw;
    }
}

function main(): void
{
    try {
        echo measure("abc");
    } catch (ParseError $error) {
        echo $error->message;
    }
}
```
