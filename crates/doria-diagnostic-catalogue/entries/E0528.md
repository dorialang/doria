# Duplicated Elements Must Be Cloneable

Title: varies
Family: collections

## Explanation

Some operations put one value into a collection several times, or copy elements and leave their source unchanged: the repeat form `[value; count]`, factories such as `Set::from`, and `union`, `intersect` and `difference` on sets. Numbers, `bool` and `string` values are duplicated freely. An object of a class has one owner, so it is duplicated only through the `Cloneable` interface.

This error means the element type is a class that does not implement `Cloneable`, or another type with a single owner, such as a `List`.

## Fix

Declare the class `implements Cloneable` and give it `function clone(): self`, which returns a new object that is owned separately.

Or build the collection one element at a time, and construct a new object for each `add`.

## Example

```doria
class Token
{
    function __construct(writable int $id) {}
}

function main(): void
{
    List<Token> $tokens = [new Token(1); 3];
    echo $tokens->count;
}
```
