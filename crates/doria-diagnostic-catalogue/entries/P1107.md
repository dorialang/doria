# Integer Remainder By Zero

Title: fixed
Family: runtime

## Explanation

The right operand of an integer `%` was zero when the program ran. A remainder by zero has no result, so the program panics. `%=` is checked the same way.

## Fix

Test the divisor before taking the remainder, and decide what the program does when it is zero: `if ($columns > 0) { ... }`.

If the divisor comes from input or from a count, such as the `count` of a collection, zero is an ordinary case and needs its own branch.

## Example

```doria
function main(): void
{
    let $index = 7;
    let $columns = 0;
    echo $index % $columns;
}
```
