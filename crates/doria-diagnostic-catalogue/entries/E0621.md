# Error Already Covers This Throws Entry

Title: fixed
Family: errors

## Explanation

`Error` in a `throws` clause covers every checked error. This error means the clause lists `Error` together with a specific error class, in either order. The specific entry adds nothing to the clause.

## Fix

Keep `Error` alone, or keep the specific classes and remove `Error`. An editor offers the removal of the redundant entry as a quick fix.

List the specific classes when callers are meant to catch each error by name.

## Example

```doria
class ParseError implements Error
{
    function __construct(string $message)
    {
    }
}

function parse(string $text): int throws Error, ParseError
{
    if ($text == "") {
        throw new ParseError("empty input");
    }
    return $text->length;
}

function main(): void
{
    try {
        echo parse("abc");
    } catch (Error $error) {
        echo $error->message;
    }
}
```
