# Unused Closure Capture

Title: fixed
Family: functions

## Explanation

This warning means a `with` clause lists an enclosing variable that the closure body never uses. A capture borrows or takes its variable, so an unused entry restricts the enclosing code for no benefit.

## Fix

Remove the entry from the `with` clause. When it is the only entry, remove the whole clause. An editor offers the removal as a quick fix.

If the closure was meant to use the variable, use it in the body.

## Example

```doria
function main(): void
{
    let $minimum = 70;
    let $double = fn(int $score) with ($minimum) => $score * 2;
    echo $double(21);
}
```
