# String Padding Text Cannot Be Empty

Title: fixed
Family: runtime

## Explanation

`String::padStart` and `String::padEnd` repeat the padding text until the result reaches the requested length. This panic means the text was shorter than the requested length and the padding text was `""`, which adds nothing however often it is repeated.

The call does not panic when the text is at least as long as the requested length, because no padding is needed. A program with an empty padding text can therefore run for some inputs and panic for others.

## Fix

Pass padding text with at least one grapheme, such as `" "` or `"0"`.

To pad with spaces, leave the third argument out: `String::padEnd($name, 8)`.

## Example

```doria
function main(): void
{
    let $fill = "";
    echo String::padEnd("Doria", 8, $fill);
}
```
