# Invalid Type Parameter Declaration

Title: varies
Family: generics

## Explanation

A type parameter is declared after the name of a function, method or class, as in `function first<T>(List<T> $items)`. Its name is a single capital letter such as `T`, `K` or `V`. This error means a declaration breaks one of the rules for type parameters: the name is longer than one capital letter, the same name is declared twice, a method reuses the name of a type parameter of its class, a constraint such as `Hashable` is given type arguments it does not take, or `main`, `__construct` or `__destruct` declares type parameters.

The code is also raised for a `foreach` over a `Set` or `SortedSet` with a `writable` value binding. Changing an element in place could break the uniqueness or the order of the set.

## Fix

Rename the type parameter to a single capital letter that is not already in use. Move generic behavior out of `main`, a constructor or a destructor into an ordinary function or method.

For a set, remove `writable` from the binding. To replace an element, call `remove` with the old value and `add` with the new one.

## Example

```doria
function first<Item>(List<Item> $items): ?Item
{
    return $items->first;
}

function main(): void
{
    List<int> $numbers = [4, 5];
    echo first($numbers) ?? 0;
}
```
