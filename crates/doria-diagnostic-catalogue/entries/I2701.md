# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

The compiler found an enum value whose enum type differs from the type that checking recorded for the expression holding it. This code covers an enum case written in the program, an enum constant, a variable or static property of an enum type, and a function, method or static method that returns an enum.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the expression the compiler was working on, so start there, keep the enum declaration it refers to, and remove the code around them.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that declares an enum and passes its cases around as values.
