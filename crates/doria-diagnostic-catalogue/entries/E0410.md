# Required Parameter After Optional Parameter

Title: varies

## Explanation

A parameter with a default value is optional, and optional parameters come last in a parameter list. This error marks a parameter without a default value that follows one with a default value.

## Fix

Move the required parameter ahead of the optional ones, or give it a default value. Update the calls to match the new order.

## Example

```doria
function greet(string $greeting = "Hello", string $name): void
{
    echo "{$greeting}, {$name}";
}

function main(): void
{
    greet("Hi", "Ada");
}
```
