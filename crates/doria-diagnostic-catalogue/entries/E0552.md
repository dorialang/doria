# Grouped Null Declaration Needs An Explicit Type

Title: fixed
Family: names

## Explanation

A grouped declaration without a type takes the type of its initializer. `null` alone names no type, so `let $first, $last = null;` does not say what the variables hold. Doria does not widen such a group to `mixed`.

## Fix

Write the nullable type before the variables: `?string $first, $last = null;`.

Add `writable` to assign the variables later: `writable ?string $first, $last = null;`.

## Example

```doria
function main(): void
{
    let $first, $last = null;
}
```
