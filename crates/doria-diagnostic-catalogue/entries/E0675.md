# Namespace Segment Must Use PascalCase

Title: fixed
Family: names

## Explanation

Every segment of a namespace name is written in PascalCase: it begins with an uppercase letter and contains only letters and digits. An acronym is folded into a single capitalized word, so two uppercase letters never stand side by side. `Http` and `Io` are accepted. `HTTP`, `app` and `Http_Client` are rejected.

The error marks each segment that breaks the rule.

## Fix

Respell the segment in PascalCase, for example `namespace App\Http;`. Update every `use` statement and qualified name that refers to the namespace so that it has the same spelling.

## Example

```doria
namespace App\HTTP;

function main(): void
{
    echo "ready";
}
```
