# Static Initializer Cannot Throw

Title: fixed
Family: errors

## Explanation

The initializer of a static property is evaluated when the program is compiled. Nothing can catch a checked error there, so the initializer may contain no operation that can raise one.

This error means the initializer contains such an operation, most often a call to a function that declares a `throws` clause. The I/O errors of built-in operations such as `echo` count as well, so a call to a function that prints is rejected in the same way.

## Fix

Write the initializer with literals, constants and operators.

When the value depends on an operation that can fail, compute it while the program runs. Put the operation in a function, catch the error there or list it in the function's `throws` clause, and call the function where the value is needed.
