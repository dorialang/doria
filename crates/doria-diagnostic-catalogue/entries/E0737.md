# Constructor Parameter Role Outside A Constructor

Title: varies
Family: classes

## Explanation

In a class constructor, a parameter can carry a role. `internal` makes the parameter an internal property, and `parameter` makes it an input of the constructor that does not become a property. This error means one of these words appears on a parameter of an ordinary function or method, where parameters never become properties.

## Fix

Remove the role word. A parameter of a function or method is already a plain parameter.

## Example

```doria
function greet(parameter string $name): void
{
    echo "Hello, {$name}";
}

function main(): void
{
    greet("Ada");
}
```
