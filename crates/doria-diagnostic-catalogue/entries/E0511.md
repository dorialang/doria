# Null-Safe Access Cannot Be Assigned To

Title: varies
Family: nullability

## Explanation

`?->` skips the access when its receiver is `null`. An assignment needs a place to put its value, and `$counter?->value = 0` has none when `$counter` is `null`. A `?->` access cannot appear on the left of `=` or of a compound assignment such as `+=`.

## Fix

Test the receiver for `null`, then assign through `->` inside the branch: `if ($counter != null) { $counter->value = 0; }`.

To change the object only when it is present, put the change in a `writable function` and call it with `?->`, as in `$counter?->reset()`.

## Example

```doria
class Counter
{
    function __construct(writable int $value) {}
}

function find(bool $present): ?Counter
{
    if ($present) {
        return new Counter(3);
    }
    return null;
}

function main(): void
{
    writable ?Counter $counter = find(true);
    $counter?->value = 0;
}
```
