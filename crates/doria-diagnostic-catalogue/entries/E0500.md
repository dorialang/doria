# Property Is Not Initialized

Title: varies
Family: classes

## Explanation

Every property has a value by the time the constructor completes. A property gets its value from an initializer on its declaration, from a constructor parameter that becomes the property, or from an assignment to `$this->name` in the constructor body. This error means at least one path through the constructor ends, at the end of the body or at a `return`, and leaves the property without a value.

A class with no constructor raises the error for each property that has no initializer. An assignment inside a loop body does not count, because the body may run zero times. A constructor parameter marked `parameter` is an input only and does not initialize a property of the same name.

## Fix

Assign the property on every path, for example by adding the missing `else` branch. When the value depends on a condition, work it out in a local variable and assign the property once.

If the property has a sensible starting value, give it an initializer, as in `string $value = "";`. For a parameter marked `parameter`, write `$this->value = $value;` in the body, or remove `parameter` so that the parameter becomes the property.

## Example

```doria
class Token
{
    string $value;

    function __construct(parameter bool $set)
    {
        if ($set) {
            $this->value = "set";
        }
    }
}

function main(): void
{
    let $token = new Token(true);
    echo $token->value;
}
```
