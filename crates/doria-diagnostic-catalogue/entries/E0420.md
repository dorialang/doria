# Equality Operands Are Incompatible

Title: varies
Family: types

## Explanation

`==` and `!=` are typed. Both operands must have compatible types, and Doria performs no loose comparison, so `1 == "1"` and `false == 0` are errors. Two integers of different types, such as `int` and `uint8`, are incompatible as well, because integer comparisons do not widen.

Function values have no equality. Comparing two closures with `==` or `!=` raises this code.

## Fix

Give both operands the same type. To compare text with a number, parse the text with the companion of the number type, for example `Int::parse($text)`, which gives `?int`, and supply a fallback with `??`. To compare two integer types, convert one with a companion `from` call, for example `Int::from($small)`.

For function values, compare the application state that decides which function is in use.

## Example

```doria
function main(): void
{
    let $count = 3;
    let $answer = "3";
    if ($count == $answer) {
        echo "match";
    }
}
```
