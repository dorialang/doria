# Unknown Type

Title: varies

## Explanation

A type annotation names a type that does not exist. The name is not a built-in type, is not declared in the program, and is not imported with `use`.

Type names from other languages are a common cause. Doria writes fixed-width integers as `int32` and `uint64`, typed arrays as `T[]`, and collections as `List<T>`, `Dictionary<K, V>`, `Set<T>` and `Deque<T>`.

## Fix

Check the spelling and the case of the type name. If the type lives in another namespace, import it with `use`. If it has not been written yet, declare it.

When the message names a replacement, write that spelling: `int32` for `i32`, `Dictionary<K, V>` for `HashMap`, `Deque<T>` for `Queue` or `Stack`.

## Example

```doria
function describe(Shape $shape): void
{
    echo "shape";
}

function main(): void
{
    echo "Doria";
}
```
