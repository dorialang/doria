# Standard Interface Cannot Be Implemented

Title: fixed
Family: io

## Explanation

`Doria\Std\Io\Watchable` marks a source that a transfer plan can watch, such as a terminal `RawMode`. Every watchable source is provided by the standard library.

This error means a class in the program declares `implements Watchable`, or implements an interface that extends `Watchable`.

## Fix

Remove `Watchable` from the `implements` list. To wait for terminal events in a transfer group, pass the `RawMode` itself to `TransferPlan::watch` or `andWatch`.

A class that owns a `RawMode` passes that property, as in `TransferPlan::watch($this->raw)`.

## Example

```doria
use Doria\Std\Io\{Watchable, WatchSource};
use Doria\Std\Term\RawMode;

class Panel implements Watchable
{
    internal RawMode $raw;

    function __construct(parameter take RawMode $raw)
    {
        $this->raw = $raw;
    }

    WatchSource $watchSource {
        get => $this->raw->watchSource;
    }
}

function main(): void
{
}
```
