# `null` Used As A Type

Title: varies
Family: types

## Explanation

`null` is a literal value and has no type name. This error means `null` is written where a type is expected, such as the type of a variable, a parameter or a return.

## Fix

Write a nullable type, `?T`, with a concrete type: `?string $name = null;` or `function find(): ?Person`.

A function that returns nothing has the return type `void`.

## Example

```doria
function main(): void
{
    null $name = null;
    echo "done";
}
```
