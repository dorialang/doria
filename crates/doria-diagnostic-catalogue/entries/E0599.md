# Match True Arm Cannot Have A Guard

Title: fixed
Family: enums

## Explanation

In `match (true)` every arm is a `bool` condition, and the first condition that is `true` chooses its arm. These arms take no `if` guard. This error means an arm of `match (true)` is written with one.

## Fix

Combine the two conditions with `&&`: `$count > 100 && $count < 1000 => "hundreds"`.

## Example

```doria
function label(int $count): string
{
    return match (true) {
        $count > 100 if $count < 1000 => "hundreds",
        default => "other",
    };
}

function main(): void
{
    echo label(250);
}
```
