# Array Region Length Does Not Match The Field

Title: fixed
Family: runtime

## Explanation

A foreign struct or union was built with a fixed-length array field supplied from an `ArrayRegion<T>`, and the region did not have exactly as many elements as the field declares. The field `uint16[3] $tip` takes a region of three `uint16` values; the copy never truncates or pads. When the compiler can see the region's length while it checks the construction, the mismatch is the compile-time error E0803 instead.

## Fix

Take a region of the field's length: `new Tip(text: $source->getRegion(0, 3))`. When the length comes from data, check it against the field's count before building the value, or omit the field, which is zero-filled, and copy the elements in afterwards with `$tip->text->copyFrom($source)`.

## Example

```doria
extern "C" struct Tip
{
    uint16[3] $text;
}

function build(ArrayRegion<uint16> $source): Tip
{
    return new Tip(text: $source);
}

function main(): void
{
    uint16[] $letters = [72, 105];
    let $tip = build($letters->getRegion(0, 2));
}
```
