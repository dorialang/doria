# Foreign Type Is Not Valid Here

Title: fixed
Family: unsafe

## Explanation

A foreign type is written where it cannot be used. `Opaque` has no values: it is only the pointee of `Ptr<Opaque>` and `MutPtr<Opaque>`, C's untyped pointers. A fixed-length array type `T[N]` is only the type of a foreign struct or union field, and its element count is at least one.

## Fix

Write `Ptr<Opaque>` for C's `const void *` and `MutPtr<Opaque>` for `void *`. Outside a foreign field, use a typed array `T[]` or a typed array region for a sequence of values.

## Example

```doria
use Doria\Std\Ffi\Opaque;

function main(): void
{
    Opaque $value = 0;
}
```
