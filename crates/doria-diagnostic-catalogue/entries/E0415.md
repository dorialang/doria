# Value Cannot Be Interpolated

Title: varies

## Explanation

A string interpolation, `"{$value}"`, holds a value that has no text form. Strings, integers, floats and booleans can be interpolated. A nullable value, a `mixed` value, `null`, an enum case and a collection cannot.

## Fix

Give the interpolation a value that has a text form. For a nullable value, supply a fallback with `??`, as in `"{$name ?? "stranger"}"`, or test for `null` first.

Narrow a `mixed` value with `is` before interpolating it. For a collection, interpolate one element or a property such as `count`.

## Example

```doria
function describe(?string $name): void
{
    echo "Hello, {$name}";
}

function main(): void
{
    describe(null);
}
```
