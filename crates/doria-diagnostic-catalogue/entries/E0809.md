# Borrowed Handle Value Leaves Its Unsafe Context

Title: fixed
Family: unsafe

## Explanation

`Handle::borrow`, `SharedReference::borrow` and `WritableSharedReference::borrow` lend the value a handle holds without taking it back from C. The loan lasts for the unsafe context it is formed in, because C may release the value once Doria code stops running inside that context. An `unsafe(<expression>)` whose whole value is the borrow ends before anything uses the value.

## Fix

Use the borrowed value inside the context: `echo unsafe(Handle::borrow($handle)->count);`. To use it several times, bind it inside an `unsafe { ... }` block: `unsafe { Counter $counter = Handle::borrow($handle); echo $counter->count; }`.

## Example

```doria
use Doria\Std\Ffi\{Handle, Opaque, WritablePointer};

class Counter
{
    function __construct(int $count) {}
}

function main(): void
{
    WritablePointer<Opaque> $handle = Handle::create(new Counter(1));
    Counter $counter = unsafe(Handle::borrow($handle));
    echo $counter->count;
}
```
