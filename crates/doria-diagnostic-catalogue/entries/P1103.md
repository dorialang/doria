# Integer Multiplication Overflowed

Title: fixed
Family: runtime

## Explanation

Integer `*` is checked. This panic means the product is outside the range of the integer type of the operands. An `int32` holds values up to 2147483647, and `3000000 * 1000` does not fit. `*=` is checked the same way.

## Fix

Use a type wide enough for the largest product. Convert the operands with the companion of the wider type and multiply there: `Int::from($bytes) * Int::from($scale)`.

If the operands are already `int`, the values are too large for any integer type. Check the inputs before multiplying, or change the unit so the numbers are smaller.

## Example

```doria
function main(): void
{
    int32 $scale = 1000;
    writable int32 $bytes = 3000000;
    $bytes = $bytes * $scale;
    echo $bytes;
}
```
