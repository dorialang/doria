# Invalid Expectation Negation

Title: varies
Family: testing

Example source: development

## Explanation

`not` reverses the matcher that follows it: `expect($roles)->not->toContain("guest");` passes when `$roles` has no `"guest"`. It is a property of the expectation, written without parentheses, and a chain contains it at most once.

This error means `not` is called as a method, `->not()`, or appears twice in one chain.

## Fix

Write `->not` once, without parentheses, directly before the matcher: `expect($total)->not->toEqual(3);`.

When a chain has `->not->not`, remove one of them, or remove both if the positive expectation is what you mean.

## Example

```doria
use Doria\Std\Test\{it, expect};

it("does not add up to three", function (): void {
    expect(1 + 1)->not->not->toEqual(3);
});
```
