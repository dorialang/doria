# Given Setup Appears After A Predicate

Title: fixed
Family: control-flow

## Explanation

A `given` block prepares and gates the `if`, `when` or `while` it is attached to. It holds setup first and predicates second. Setup is variable declarations and calls that return `void`. A predicate is a `bool` expression statement; when one is `false`, the attached condition and body are skipped.

This error means a declaration or a `void` call comes after the first predicate.

## Fix

Move the declaration or the `void` call above the first predicate. A predicate may use any variable declared before it in the block.

## Example

```doria
function main(): void
{
    int $limit = 10;
    given {
        $limit > 0;
        let $half = $limit / 2;
    } if ($half > 2) {
        echo $half;
    }
}
```
