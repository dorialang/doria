# Included Source Contains Executable Statements

Title: fixed
Family: projects

## Explanation

`include "path";` adds one named file of the same package to the compilation. The included file contributes declarations only: functions, classes, enums, interfaces, traits and constants. An `include` is resolved when the program is compiled, and the included file is not run at that point.

This error means a file that enters the compilation through `include` contains a statement outside every function, such as a top-level `echo` or a call.

## Fix

Move the statements into a function in the included file, and call that function from the code that needs it, for example from `main`.

## Example

No single source file raises this code: it takes a file with an `include` and the file it includes, checked together as a project, for example with `baton check`. The same statement is also reported there as E0683, because the included file is not the entry file. A file checked alone with `doriac check` does not follow an `include`.
