# When Branch Result Type Mismatch

Title: fixed
Family: control-flow

## Explanation

A `when` has one result type. It is the type written on the head, as in `when ($ready): int`, or the type the surrounding code expects, such as the type of a typed declaration. With neither, it is the type of the first value the head branch returns.

This error means a branch returns a value of a different type. Doria performs no implicit conversions between branch results.

## Fix

Return the same type from every branch.

When the branches differ on purpose, for example a `string` in one and `null` in another, write the wider result type on the head: `when ($count > 1): ?string`.

## Example

```doria
function main(): void
{
    int $count = 3;
    let $label = when ($count > 1) {
        return "many";
    } else {
        return 1;
    };
    echo $label;
}
```
