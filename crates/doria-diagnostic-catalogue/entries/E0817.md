# Windows Error Code Captured Off Windows

Title: fixed
Family: unsafe

## Explanation

`#[CaptureSystemCode(SystemCodeSource::WindowsLastError)]` on an extern declaration reads `GetLastError` right after each call, and only Windows has it. This error means the program calls such a binding in code it builds for Linux or macOS. A call inside a branch whose condition is false for the target, such as `if (Platform::operatingSystem == OperatingSystem::Windows) { ... }` on macOS, is not built, so it raises nothing.

## Fix

Call the Windows binding only inside a `Platform::operatingSystem == OperatingSystem::Windows` branch, and give the other platforms a binding that captures `SystemCodeSource::Errno`.

## Example

No program shows this code on its own: `doriac check` and `baton check` accept the program, and the code is reported when the program is compiled for Linux or macOS, by `doriac compile`, `doriac run`, `baton build` or `baton run`. A user meets it at a call to a binding marked `#[CaptureSystemCode(SystemCodeSource::WindowsLastError)]` outside a `Platform::operatingSystem == OperatingSystem::Windows` branch.
