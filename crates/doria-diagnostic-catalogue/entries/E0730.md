# Override Has No Target

Title: fixed
Family: classes

## Explanation

`override` marks a method or property that replaces an `open` member inherited from a parent class. This error means there is nothing to replace: the class has no parent, or no class above it declares a member with that name.

A misspelled member name is the usual cause.

## Fix

Remove `override` to declare a new member. To replace an inherited member, use its exact name, and check that the class names the right parent after `extends`.

## Example

```doria
open class Shape
{
    open function area(): int
    {
        return 0;
    }
}

class Square extends Shape
{
    override function perimeter(): int
    {
        return 4;
    }
}

function main(): void
{
    let $square = new Square();
    echo $square->perimeter();
}
```
