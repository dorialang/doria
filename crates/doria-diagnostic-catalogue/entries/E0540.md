# Generic Class Static Access Or `shared writable new` Is Not Valid

Title: varies
Family: generics

## Explanation

This code is raised for two separate mistakes.

A static member of a generic class is reached through the class name alone, as in `Counter::start()`. Each use of a generic class with concrete type arguments is a distinct type, and the name `Counter` alone does not identify one of them.

The words `shared writable new` are written. `shared` is a construction modifier with one form, `shared new T(...)`, which constructs a `SharedReference<T>`. It does not combine with `writable`.

## Fix

Inside the generic class, reach the static member with `self::`, as in `self::start()`. From outside the class, call a method of the class that uses `self::`, or move the operation to a free function.

For shared ownership, write `shared new T(...)` for a `SharedReference<T>`. For a shared value that will be changed, write `new WritableSharedReference(new T(...))`.

## Example

```doria
class Counter<T>
{
    static function start(): int
    {
        return 0;
    }
}

function main(): void
{
    echo Counter::start();
}
```
