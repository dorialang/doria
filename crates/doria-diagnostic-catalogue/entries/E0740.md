# Constructor Parameter Role Is Misordered

Title: fixed
Family: classes

## Explanation

The parts of a constructor parameter come in a set order: attributes, then the role (`internal`, `override` or `parameter`), then `writable` or `take`, then the type and the name. This error means the role word comes after `writable` or `take`, or after the type.

## Fix

Move the role word in front of the mode and the type: `internal writable string $name`. An editor offers the move as a quick fix.

## Example

```doria
class Person
{
    function __construct(writable internal string $name)
    {
    }
}

function main(): void
{
    let $person = new Person("Ada");
}
```
