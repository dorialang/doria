# Parameter Declared Both `take` And `writable`

Title: varies
Family: ownership

## Explanation

`take` and `writable` are two different ways for a function to receive an argument. A `take` parameter receives ownership of the value, and the caller cannot use the value afterward. A `writable` parameter borrows the caller's value in order to change it, and the caller keeps the value. A parameter uses one of them.

## Fix

Keep `take` when the function keeps the value or is the last to use it. Keep `writable` when the function changes the value and the caller goes on using it.

A `take` parameter is readonly. To change a value the function has taken, give it to a writable variable first: `let writable $owned = $guard;`.

A promoted constructor parameter is the one place both are written: `function __construct(internal take writable List<Scene> $scenes)` takes ownership of the argument and makes the new property writable.

## Example

```doria
class Guard
{
}

function release(take writable Guard $guard): void
{
}

function main(): void
{
    release(new Guard());
}
```
