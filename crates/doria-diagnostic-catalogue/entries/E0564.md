# Case Name Must Use PascalCase

Title: fixed
Family: names

## Explanation

Enum cases use PascalCase, like the enum they belong to. This error means the name of a case does not begin with an uppercase letter.

## Fix

Rename the case so that it begins with an uppercase letter, as in `case Draft;`, and update the places that refer to it, such as `Status::Draft`.

## Example

```doria
enum Status
{
    case draft;
    case Published;
}

function main(): void
{
    Status $current = Status::Published;
}
```
