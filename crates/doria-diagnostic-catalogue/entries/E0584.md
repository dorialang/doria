# Payload Enum Equality Is Unavailable

Title: fixed
Family: enums

## Explanation

`==` and `!=` on a payload enum compare the case and then the payload fields of that case. They are available only when every payload type in every case supports equality. This error means a field has a type without equality, such as `List<int>` or another collection. The message names the case and the field.

Comparing a nullable enum with `null` tests presence only and is always allowed.

## Fix

Use `match` to bind the payload fields and compare what the program needs, for example the `count` of a list.

To keep `==`, give the payload fields types that support equality, such as `int` or `string`.

## Example

```doria
enum Bucket
{
    case Values(List<int> $values);
}

function main(): void
{
    Bucket $left = Bucket::Values([1]);
    Bucket $right = Bucket::Values([1]);
    echo $left == $right ? "same" : "different";
}
```
