# Error Message Property Is Missing

Title: fixed
Family: errors

## Explanation

A class that declares `implements Error` must have a `message` property: an externally accessible readonly `string $message`. Code that catches the error reads its text from that property.

This error means the class has no property named `message`.

## Fix

Add the property. The shortest form is a constructor parameter named `message`, which becomes the property: `function __construct(string $message) {}`.

A declared property with an initializer also satisfies the interface: `string $message = "unexpected token";`.

## Example

```doria
class ParseError implements Error
{
    function __construct(string $reason)
    {
    }
}

function main(): void
{
    let $error = new ParseError("unexpected token");
    echo $error->reason;
}
```
