# Interface Or Trait Cycle

Title: varies
Family: interfaces

## Explanation

An interface may extend other interfaces, and a trait may compose other traits with `uses`. This error means the chain leads back to where it started: an interface extends itself through its parents, or a trait uses itself through the traits it composes.

## Fix

Remove one `extends` or `uses` entry in the cycle. The diagnostic marks each entry that takes part.

When two interfaces need the same requirement, move it into a third interface that both extend.

## Example

```doria
interface Readable extends Stored
{
    function read(): string;
}

interface Stored extends Readable
{
    function path(): string;
}

function main(): void
{
    echo "ready";
}
```
