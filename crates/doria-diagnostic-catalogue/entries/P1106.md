# Integer Division Overflowed

Title: fixed
Family: runtime

## Explanation

A signed type holds one more negative value than positive values: an `int8` holds -128 through 127. Dividing the lowest value of a signed type by `-1` gives a result one above the highest value, so the program panics. No other integer division overflows.

## Fix

Convert the left operand to a wider type before dividing: `Int::from($lowest) / -1`.

If the operands are already `int`, test for a divisor of `-1` and handle the lowest value separately.

## Example

```doria
function main(): void
{
    int8 $lowest = -128;
    int8 $divisor = -1;
    echo $lowest / $divisor;
}
```
