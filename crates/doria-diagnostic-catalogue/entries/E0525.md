# Collection Equality Is Reserved For A Later Release

Title: varies
Family: collections
Availability: later

## Explanation

The program compares two collections with `==` or `!=`. Doria reserves equality between collections for a later release, so the compiler cannot answer whether two `List`, `Dictionary`, `Set` or typed array values hold the same elements.

`Bytes` values are the exception: two `Bytes` values are equal when they hold the same bytes.

## Fix

Compare what the program cares about. To ask whether two lists hold the same elements in the same order, compare `count` first and then each pair of elements, as a small function of your own:

`if ($first->count != $second->count) { return false; }`, then a `for` loop that returns `false` at the first pair that differs.

To ask whether a collection holds one value, use `contains`.

## Example

```doria
function main(): void
{
    List<int> $first = [1, 2];
    List<int> $second = [1, 2];
    if ($first == $second) {
        echo "same\n";
    }
}
```
