# Operator Is Not Part Of Doria

Title: varies
Family: syntax

## Explanation

The program uses an operator from another language that Doria does not have. Four spellings are reported under this code: the power operator `**` with its assignment form `**=`, the three-way comparison `<=>`, the error-suppression prefix `@`, and backticks around a command.

## Fix

For `**`, write the multiplication, as in `$side * $side`.

For `<=>`, compare with `<`, `==` and `>`. A type that implements `Comparable<T>` has `compare`, which returns `Ordering::Less`, `Ordering::Equal` or `Ordering::Greater`.

For `@`, remove it and handle the result: catch a checked `Error` with `try` and `catch`, or give a nullable result a fallback with `??`. Remove backticks; a string literal is written with `"` or `'`.

## Example

```doria
function main(): void
{
    let $side = 3;
    let $area = $side ** 2;
    echo $area;
}
```
