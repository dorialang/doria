# Ternary Condition Must Be Bool

Title: fixed
Family: control-flow

## Explanation

`$condition ? $left : $right` chooses between its two values on a `bool`. This error means the condition has another type. Doria does not treat numbers, strings or `null` as true or false.

## Fix

Write a comparison that produces a `bool`, as in `$count > 0 ? "some" : "none"`.

To fall back when a nullable value is `null`, use `??`: `$name ?? "unknown"`.

## Example

```doria
function main(): void
{
    let $count = 1;
    echo $count ? "some" : "none";
}
```
