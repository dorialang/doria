# Missing Required Argument

Title: varies
Family: functions

## Explanation

A call that uses named arguments, or an attribute, leaves out a parameter that has no default value. Every parameter without a default needs an argument, passed by position or by name. The message names the parameters that were left out.

## Fix

Add the missing argument, for example `save(name: "notes", size: 12)`. If the argument should be optional, give its parameter a default value in the declaration.

## Example

```doria
function save(string $name, int $size): void
{
    echo "{$name}: {$size}";
}

function main(): void
{
    save(name: "notes");
}
```
