# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

The compiler could not turn a `when` expression that passed checking into executable code. A `when` expression chooses a branch and produces that branch's value. This code means that the compiler's record of the result type was missing or differs from the compiled type, that a branch contains a `return` with no value, or that a branch can reach its end without producing a value.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the `when` expression or the branch, so keep that expression and remove the code around it.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that uses `when`.
