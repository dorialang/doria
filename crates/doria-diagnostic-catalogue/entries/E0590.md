# Match Payload Arity Mismatch

Title: fixed
Family: enums

## Explanation

A payload case pattern with parentheses binds every field of the case, by position. This error means the number of bindings differs from the number of fields the case declares. A pattern binds all of the fields or none of them.

## Fix

Write one binding for each field, in declaration order: `Shape::Rect($width, $height)`. The binding names are yours to choose.

To match the case and ignore its fields, write the case without parentheses: `Shape::Rect`.

## Example

```doria
enum Shape
{
    case Circle(float $radius);
    case Rect(float $width, float $height);
}

function area(Shape $shape): float
{
    return match ($shape) {
        Shape::Circle($radius) => 3.14159 * $radius * $radius,
        Shape::Rect($width) => $width * $width,
    };
}

function main(): void
{
    echo area(Shape::Rect(2.0, 3.0));
}
```
