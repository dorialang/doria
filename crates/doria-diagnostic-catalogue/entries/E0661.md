# Function Value Cannot Be Stored Here Yet

Title: varies
Family: functions
Availability: planned

## Explanation

The program stores a function value in a static property or as the payload of a shared reference, as in `new WritableSharedReference(fn() => 1)`. Storing a function value in these two places is part of Doria. This compiler does not implement it yet.

A function value can be stored in a local variable, a parameter, an owned property and a collection.

## Fix

Until the compiler implements these two places, keep the function value in storage that works today: a local such as `let $task = fn() => 1;`, a property of a class, or a collection such as `List<function(): int>`. Share the object that owns it when several parts of the program need to call it.

## Example

```doria
function main(): void
{
    let $shared = new WritableSharedReference(fn() => 1);
}
```
