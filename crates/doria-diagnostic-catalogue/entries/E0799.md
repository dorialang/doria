# Union Construction Names One Member

Title: fixed
Family: unsafe

## Explanation

A foreign union is built in one of two ways: `new Value()` makes every byte zero, and `new Value(number: $number)` writes exactly one named member and makes every other byte zero. The members overlap, so naming two of them, or passing a member positionally, does not say which one the value holds.

## Fix

Name one member, as in `new Value(number: 1)`, or build it with no arguments and write the member afterwards. Writing a member is safe; reading one needs an unsafe context.

## Example

```doria
extern "C" union Value
{
    int32 $number;
    float32 $ratio;
}

function main(): void
{
    let $value = new Value(number: 1, ratio: 2.0);
}
```
