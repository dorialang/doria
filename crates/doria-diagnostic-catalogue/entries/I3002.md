# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

The compiler could not turn a `map`, `filter` or `reduce` call on a `List<T>` that passed checking into executable code. This code means that one of the types of the call has no compiled form or disagrees with another: the list being read, its element type, the callback's function type, the result type, or the accumulator of `reduce`. It also covers a call with the wrong number of arguments and a `filter` callback whose compiled result is not a `bool`.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the call, the list or the callback, so keep that call and the declarations it uses, and remove the code around them.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that calls `map`, `filter` or `reduce` on a `List<T>`.
