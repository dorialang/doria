# Unsafe Code Denied

Title: varies
Family: unsafe

## Explanation

An unsafe policy of `"deny"` forbids unsafe code: an `unsafe` block or expression, an `unsafe function`, an `extern "C"` block, a foreign struct or union, and a C-callable function. A file sets the policy with `declare(unsafe: "deny");`, and a package sets it for every source with `unsafe = "deny"` in its `Baton.toml`. Calling a safe function that a file or package allowing unsafe code defines stays allowed.

The title says where the policy comes from: `Unsafe Code Denied By This File` or `Unsafe Code Denied By This Package`.

## Fix

Move the unsafe code into a file or package that allows it, wrap it in a safe function there, and call that function from here. A package keeps its foreign bindings in a dependency that allows unsafe code.

## Example

```doria
declare(unsafe: "deny");

function main(): void
{
    let $sum = unsafe(1 + 2);
    echo $sum;
}
```
