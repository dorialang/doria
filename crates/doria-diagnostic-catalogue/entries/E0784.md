# Unsafe Code Is Not Available Yet

Title: varies
Family: unsafe
Availability: planned

## Explanation

Unsafe code and the foreign function interface are part of Doria. This compiler does not implement it yet in full. It checks `unsafe` contexts, unsafe functions, `extern "C"` declarations, C-ABI functions, C function pointer types, foreign structs and unions, pointer operations and C boundary conversions. For the native target it builds C boundary conversions, pointer operations, calls to the platform C runtime, and foreign structs and unions as locals, parameters, results and pointer targets and by value across the C boundary. It cannot yet check `declare` directives, fixed-length array fields as regions, typed array regions, `CString`, `Utf16String`, `Handle`, `Platform` and `ForeignCall`. It cannot yet build C-ABI functions, C function pointer types, variadic foreign functions, native libraries, system code capture, pointers to properties, or foreign structs and unions in properties, nullable values, type arguments, enum payloads, closures and `mixed` values. The interpreter and PHP output run unsafe code through the native companion library, which this compiler does not build yet. The program is read correctly; the compiler names each such form and stops.

The title names the form, such as `Declare Directives Are Not Available Yet` or `Extern Blocks Cannot Be Built Yet`.

## Fix

Keep the code for a compiler that implements unsafe code. To build the program with this compiler, move the foreign bindings out of it and reach the same work through the standard library, such as `Doria\Std\Io` for files and processes.

## Example

```doria
declare(unsafe: "deny");

function main(): void
{
}
```
