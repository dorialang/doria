# Unsafe Code Is Not Available Yet

Title: varies
Family: unsafe
Availability: planned

## Explanation

Unsafe code and the foreign function interface are part of Doria. This compiler does not implement it yet in full. It checks `unsafe` contexts, unsafe functions, `extern "C"` declarations, C-ABI functions and C function pointer types. It cannot yet check `declare` directives, foreign structs and unions, typed array regions, `CString`, `Utf16String`, `Handle`, `Platform` and `ForeignCall`, and it cannot yet build or run foreign calls and foreign types. The program is read correctly; the compiler names each such form and stops.

The title names the form, such as `Declare Directives Are Not Available Yet` or `Extern Blocks Cannot Be Built Yet`.

## Fix

Keep the code for a compiler that implements unsafe code. To build the program with this compiler, move the foreign bindings out of it and reach the same work through the standard library, such as `Doria\Std\Io` for files and processes.

## Example

```doria
declare(unsafe: "deny");

function main(): void
{
}
```
