# Unsafe Code Is Not Available Yet

Title: varies
Family: unsafe
Availability: planned

## Explanation

Unsafe code and the foreign function interface are part of Doria. This compiler does not implement it yet in full. It checks `unsafe` contexts, unsafe functions, `extern "C"` declarations, C-ABI functions, C function pointer types, foreign structs and unions, pointer operations and C boundary conversions. For the native target it builds C boundary conversions, pointer operations, calls to the platform C runtime and to native libraries, variadic ones included, linked from `[native-libraries]` or the `--link-library` flags, foreign structs and unions as locals, parameters, results and pointer targets and by value across the C boundary, pointers to region storage, `CString` and `Utf16String` values and their pointers, calls through C function pointer values, C-ABI functions, whose names are C function pointer values that C calls on the program's thread, `errno` and `GetLastError` capture with `ForeignCall::lastSystemCode`, fixed-length array fields of scalar and nullable pointer elements read, supplied and assigned as regions, and typed array regions over numbers, `bool`, enum cases, pointers, nullable pointers and other plain Copy values, which the interpreter also runs. It cannot yet check `declare` directives, `Handle` and `Platform`, or enforce a package's `unsafe = "deny"` policy, and it cannot yet link a program for the Windows GUI subsystem. It cannot yet build typed array regions over strings, classes, collections, foreign structs and unions and other element types that own or share a value, `WindowsLastError` capture for a target other than Windows, pointers to properties, or foreign structs and unions in properties, nullable values, type arguments, enum payloads, closures and `mixed` values. The interpreter and PHP output run unsafe code through the native companion library, which this compiler does not build yet. The program is read correctly; the compiler names each such form and stops.

The title names the form, such as `Declare Directives Are Not Available Yet` or `Extern Blocks Cannot Be Built Yet`.

## Fix

Keep the code for a compiler that implements unsafe code. To build the program with this compiler, move the foreign bindings out of it and reach the same work through the standard library, such as `Doria\Std\Io` for files and processes.

## Example

```doria
declare(unsafe: "deny");

function main(): void
{
}
```
