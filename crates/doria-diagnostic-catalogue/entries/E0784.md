# Unsafe Code Is Not Available Yet

Title: varies
Family: unsafe
Availability: planned

## Explanation

Unsafe code and the foreign function interface are part of Doria: `unsafe { ... }` blocks and `unsafe(<expression>)`, `unsafe function`, `extern "C"` blocks, C-ABI functions, foreign structs and unions, C function pointer types, the `Doria\Std\Ffi` module, typed array regions and `declare` directives. This compiler does not implement it yet. The program is read correctly; checking stops at the first of these forms and names each one.

The title names the form, such as `Unsafe Blocks Are Not Available Yet` or `Extern Blocks Are Not Available Yet`.

## Fix

Keep the code for a compiler that implements unsafe code. To build the program with this compiler, move the foreign bindings out of it and reach the same work through the standard library, such as `Doria\Std\Io` for files and processes.

## Example

```doria
function main(): void
{
    unsafe {
        echo "inside an unsafe block";
    }
}
```
