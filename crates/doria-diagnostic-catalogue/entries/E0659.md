# Closure Has Multiple Incompatible Return Roots

Title: fixed
Family: functions

## Explanation

A function may return a closure that borrows one of its parameters, or `$this`. The caller then keeps that one argument alive for as long as it uses the closure.

This error means the returned closure borrows from more than one of them, for example two parameters captured with `with ($left, $right)`. A returned closure can depend on one borrowed owner only.

## Fix

Capture the values with `take`, as in `with (take $left, take $right)`, so that the closure owns them. For class values, also declare the parameters `take`.

Or borrow from one parameter only, and pass the other value to the closure as an argument when it is called.

## Example

```doria
function makeSum(int $left, int $right): function(): int
{
    return fn() with ($left, $right) => $left + $right;
}

function main(): void
{
    let $sum = makeSum(2, 3);
    echo $sum();
}
```
