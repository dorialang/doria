# Attribute Class Is Not Declared

Title: varies
Family: projects

## Explanation

An attribute application such as `#[Route("/posts")]` names an attribute class. This error means no attribute class with that name is visible where the attribute is written. The name may be misspelled, the class may be declared in another namespace without a `use` statement, or the name may belong to something that is not a class, such as an enum.

`Attribute`, `Test` and `PHPExport` are known to the compiler. Every other attribute is a class that the program or one of its dependencies declares and marks with `#[Attribute]`.

## Fix

Check the spelling and the case of the name. Declare the attribute class and mark it with `#[Attribute]`, or import it with `use` when it lives in another namespace.

When the class is declared in another file of the project, check the project as a whole with `baton check` so that the compiler sees that file.

## Example

```doria
#[Route("/posts")]
function listPosts(): void
{
    echo "posts";
}

function main(): void
{
    listPosts();
}
```
