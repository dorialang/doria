# Duplicate Case Or Payload Field

Title: varies
Family: enums

## Explanation

Case names are unique within an enum, and payload field names are unique within a case. This error means an enum declares the same case name twice, or one case declares two payload fields with the same name, as in `case Rect(float $width, float $width);`.

## Fix

Rename or remove the second case. For a payload, give each field its own name: `case Rect(float $width, float $height);`.

## Example

```doria
enum Status
{
    case Draft;
    case Published;
    case Draft;
}

function main(): void
{
    Status $current = Status::Published;
}
```
