# Duplicate Closure Capture

Title: fixed
Family: functions

## Explanation

A `with` clause names each enclosing variable once. This error means the same variable appears twice in one clause. Two entries with different modes, such as `$value` and `writable $value`, are duplicates too.

## Fix

Keep one entry for the variable. Give it the mode the closure body needs: no keyword to read the variable, `writable` to change it, or `take` to move it into the closure.

## Example

```doria
function main(): void
{
    let $minimum = 70;
    let $passes = fn(int $score) with ($minimum, $minimum) => $score >= $minimum;
    echo $passes(82);
}
```
