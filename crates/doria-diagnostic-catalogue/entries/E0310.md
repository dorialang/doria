# Function Or Method Name Is Reserved

Title: varies

## Explanation

A function or method declaration uses a name that Doria reserves. Reserved names include the built-in functions such as `read_line` and `panic`, the scalar companions such as `Int`, `Float` and `Bool`, and the words `array`, `mixed`, `object` and `resource`.

A top-level function also cannot be named `print` or have a name that begins with `__doria_`.

## Fix

Choose another name for the function or method. A program has no need to declare `print`, because `echo` writes output.

## Example

```doria
function read_line(): string
{
    return "";
}

function main(): void
{
    echo "Doria";
}
```
