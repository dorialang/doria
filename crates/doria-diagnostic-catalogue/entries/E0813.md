# Unknown Declare Directive

Title: varies
Family: unsafe

## Explanation

A `declare` directive at the top of a file names one compiler directive and gives it a value as a string: `declare(unsafe: "deny");`. Doria has one directive, `unsafe`, whose value is `"allow"` or `"deny"`. This error means the directive names another key, or gives `unsafe` another value.

The title says which part is unknown: `Unknown Declare Directive` for the key, `Unknown Unsafe Policy` for the value.

## Fix

Write `declare(unsafe: "deny");` to forbid unsafe code in the file, or remove the directive. A file without one allows unsafe code unless its package denies it.

## Example

```doria
declare(unsafe: "never");

function main(): void
{
}
```
