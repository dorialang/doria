# Unknown Constant

Title: varies
Family: names

## Explanation

A bare name in an expression, with no `$` and no parentheses, refers to a top-level constant. This error means no top-level constant has that name.

Common causes are a variable written without its `$`, a class constant written without its class, and a misspelled name. A constant whose own declaration has an error is also reported as unknown where it is used.

## Fix

Check the spelling and the case; constants are written in `SCREAMING_SNAKE_CASE`. Write a variable with its `$`, as in `$total`. Write a class constant with its class, as in `Limits::MAX_DEPTH`, or as `self::MAX_DEPTH` inside the class.

If the constant is missing, declare it at the top level: `const PAGE_LIMIT = 25;`. If its declaration is reported with an error of its own, fix that error first.

## Example

```doria
const PAGE_SIZE = 25;

function main(): void
{
    echo PAGE_LIMIT;
}
```
