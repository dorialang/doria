# Invalid Nullable Type

Title: varies
Family: types

## Explanation

`?T` is the nullable form of a type `T`: a value of type `?T` is a `T` or `null`. This error means the type written after `?` has no nullable form.

`void` says that a function returns nothing, and `null` is a literal. Neither is a value type, so `?void` and `?null` name no type.

## Fix

Write `?` before a value type, such as `?int`, `?string` or `?Person`. A function that returns nothing declares `void` with no `?`.

## Example

No program shows this code on its own: each type that it rejects is reported first under its own code at the place where the type is written, `?void` as E0430 and `?null` as E0431, and the compiler reports nothing further for that type.
