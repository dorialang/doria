# Value Arguments To Generic Types Are Reserved For A Later Release

Title: varies
Family: generics
Availability: later

## Explanation

A compile-time value argument is a value, such as a number, written among the type arguments of a generic type, as in `Buffer<int, 16>`. Doria reserves compile-time value arguments for a later release.

Every argument between `<` and `>` is a type, such as `int`, `string` or `List<int>`.

## Fix

Remove the value and keep the type arguments: `Buffer<int>`.

Pass the value when the object is created, and keep it in a property. A class that declares `function __construct(int $capacity)` is created with `new Buffer<int>(16)` and reads the value as `$this->capacity`.

## Example

```doria
class Buffer<T>
{
    internal writable List<T> $items = [];

    writable function add(take T $item): void
    {
        $this->items->add($item);
    }
}

function main(): void
{
    writable Buffer<int, 16> $buffer = new Buffer<int>();
    $buffer->add(4);
}
```
