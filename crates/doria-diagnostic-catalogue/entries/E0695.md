# Too Many Attribute Arguments

Title: fixed
Family: projects

## Explanation

An attribute application passes its arguments to the constructor parameters of the attribute class. This error means the application has more arguments than the constructor has parameters.

The markers `#[Test]` and `#[PHPExport]` take no arguments.

## Fix

Remove the extra arguments, or add a constructor parameter to the attribute class for each value the application should carry.

## Example

```doria
#[Attribute]
class Route
{
    function __construct(string $path)
    {
    }
}

#[Route("/posts", "GET")]
function listPosts(): void
{
    echo "posts";
}

function main(): void
{
    listPosts();
}
```
