# Continue Outside A Loop

Title: varies
Family: control-flow

## Explanation

`continue` jumps to the next iteration of the nearest enclosing loop. This error means the `continue` statement has no loop around it, for example in an `if` that stands directly in a function body.

A closure body is separate from a loop that contains the closure. `continue` inside the closure cannot reach that loop.

## Fix

Move the `continue` into the body of the loop it should advance. To leave the function early, use `return`.

## Example

```doria
function main(): void
{
    let $count = 3;
    if ($count > 2) {
        continue;
    }
    echo $count;
}
```
