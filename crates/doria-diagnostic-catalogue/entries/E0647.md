# Closure Cannot Capture Its Initializing Binding

Title: fixed
Family: functions

## Explanation

A variable exists only after its declaration is complete. This error means a closure written as the initial value of a variable names that same variable in its `with` clause, usually so that the closure can call itself.

## Fix

Use a named function for recursion. A top-level function can call itself by name and needs no capture.

If the closure does not call itself, remove the entry from the `with` clause.

## Example

```doria
function main(): void
{
    let $countdown = fn(int $from) with ($countdown) => $from == 0 ? 0 : $countdown($from - 1);
    echo $countdown(3);
}
```
