# List Filter Requires Copy Or Cloneable Elements

Title: fixed
Family: collections

## Explanation

`filter` leaves its list unchanged and returns a new list that holds the selected elements. Each selected element is therefore duplicated. Copy values such as `int` and `string` are copied. A class value is duplicated only through the `Cloneable` interface, which the class implements with `function clone(): self`.

This error means the list's element type is not Copy and does not implement `Cloneable`. Most often it is a class.

## Fix

Declare the class `implements Cloneable` and give it `function clone(): self`, returning a new, independent object with the same contents.

When the result does not need the objects themselves, use `map` first to read the values of interest, then `filter` the list of those values.

## Example

```doria
class Item
{
    function __construct(int $price)
    {
    }
}

function main(): void
{
    List<Item> $items = [new Item(5), new Item(50)];
    let $cheap = $items->filter(fn(Item $item) => $item->price < 10);
    echo $cheap->count;
}
```
