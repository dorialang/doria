# Override Cannot Add Unsafe

Title: fixed
Family: unsafe

## Explanation

A method marked `unsafe` overrides a safe parent method or implements a safe interface requirement. Code that calls the parent or the interface does so without an unsafe context, so every implementation must be safe to call that way. An override may drop `unsafe` from an unsafe parent method, and an implementation of an unsafe requirement may be safe.

## Fix

Make the implementation safe: remove `unsafe` from it and write its unsafe operations in `unsafe { ... }` blocks inside its body, upholding their conditions there.

## Example

```doria
interface Device
{
    function reset(): void;
}

class Port implements Device
{
    /** @safety The port is open. */
    unsafe function reset(): void
    {
    }
}

function main(): void
{
}
```
