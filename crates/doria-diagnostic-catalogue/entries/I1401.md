# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

The type the compiler recorded for a floating-point expression during checking differs from the type of the code it then produced for that expression. This code covers `float` expressions: a literal that does not fit its `float32` or `float64` type, a variable, a call to a function that returns a float, and the conversions `Int::toFloat` and `Float::toInt`.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the expression the compiler was working on, so start there and remove the code around it.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that uses `float` values or converts between `int` and `float`.
