# Thrown Value Must Implement Error

Title: varies
Family: errors

## Explanation

`throw` takes an owned value of a class that implements `Error`. This error means the operand has another type: a `string`, a number, or an instance of a class that does not declare `implements Error`.

Conformance is explicit. A class with a `message` property is an error class only when it declares `implements Error`.

## Fix

Declare the class `implements Error` and give it a readonly `string $message` property. A constructor parameter named `message` provides it.

To throw with a text message, define an error class and throw an instance of it: `throw new ParseError("empty input");`. A function that throws lists the error in its `throws` clause.

## Example

```doria
class ParseFailure
{
    function __construct(string $message)
    {
    }
}

function parse(string $text): int
{
    if ($text == "") {
        throw new ParseFailure("empty input");
    }
    return $text->length;
}

function main(): void
{
    echo parse("abc");
}
```
