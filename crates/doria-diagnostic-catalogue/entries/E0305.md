# Unknown Class

Title: varies

## Explanation

The program creates an object with `new`, or uses a static member with `::`, of a class that does not exist under that name. No class with this name is declared in the program or imported with `use`.

## Fix

Check the spelling and the case of the name. If the class lives in another namespace, import it with `use` or write its full name. If it has not been written yet, declare it.

## Example

```doria
function main(): void
{
    let $origin = Point::origin();
}
```
