# Enum Must Have A Case

Title: fixed
Family: enums

## Explanation

An enum is a fixed set of cases, and a value of the enum is always one of them. This error means the enum declares no case, so it could have no value.

## Fix

Declare at least one case, each ending with `;`, as in `case Draft;`. Remove the enum if nothing uses it.

## Example

```doria
enum Status
{
}

function main(): void
{
}
```
