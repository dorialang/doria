# Unescaped Brace In Interpolated String

Title: varies
Family: syntax

## Explanation

In a double-quoted string, `{` begins an interpolation, and the text up to the matching `}` is a Doria expression. This error means the braces do not hold an expression: they hold a bare word such as `{name}`, or another `{`.

A variable keeps its `$` inside the braces.

## Fix

To interpolate a variable, write its `$`: `"Hello, {$name}"`.

To print a brace as text, write `\{`. A `}` needs no escape, and doubling a brace does not escape it. A single-quoted string never interpolates, so `'{name}'` is plain text.

## Example

```doria
function main(): void
{
    let $name = "Ada";
    echo "Hello, {name}";
}
```
