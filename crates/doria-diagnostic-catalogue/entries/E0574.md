# Unknown Enum Case

Title: fixed
Family: enums

## Explanation

A case is selected with `Enum::Case`. This error means the enum declares no case with the name after `::`. Case names match exactly, including upper and lower case.

When a declared case has a similar name, the message suggests it.

## Fix

Write the name of a case the enum declares. When the message suggests a case, an editor offers the rename as a quick fix.

If the case is new, add it to the enum declaration, as in `case Archived;`.

## Example

```doria
enum Status
{
    case Draft;
    case Published;
}

function main(): void
{
    Status $status = Status::Draf;
    echo match ($status) {
        Status::Draft => "draft",
        Status::Published => "published",
    };
}
```
