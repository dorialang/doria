# `mixed` Value Used Before Narrowing

Title: varies
Family: nullability

## Explanation

`mixed` is the dynamic type. Any value may be stored in a `mixed` place, and nothing can be done with that value until the program proves what it holds. This error means a `mixed` value is used in an operator, a comparison, a property access, a method call, an `echo` or a typed `foreach` binding before it has been narrowed.

## Fix

Test the value with `is` and use it where the test holds: `if ($payload is int and $payload == 1)`. Inside the body of `if ($payload is int)` the value is an `int`.

When the type is known from the start, declare the variable with that type.

## Example

```doria
function main(): void
{
    mixed $payload = 1;
    if ($payload == 1) {
        echo "one";
    }
}
```
