# Wrong Number Of Type Arguments

Title: varies

## Explanation

A type was written with a different number of type arguments than it takes. `List<T>` and `Set<T>` take one, `Dictionary<K, V>` takes two, and types such as `int` and `string` take none.

## Fix

Give the type exactly the arguments it takes, for example `List<string>` or `Dictionary<string, int>`. To hold several values in each element of a list, declare a class for the element and use it as the type argument.

## Example

```doria
function main(): void
{
    List<string, int> $names = ["Ada"];
    echo $names->count;
}
```
