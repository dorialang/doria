# Source Is Not A Binary Entry

Title: fixed
Family: projects

## Explanation

In a project, one file may contain statements outside every function: the entry file of the binary being built, which `Baton.toml` names with `entry`. Every other source file contains declarations only. That covers the other files of the package, its test sources, the files of its dependencies, and included files. A library has no entry file, so none of its files may contain such statements.

This error means a file other than the entry file contains a top-level statement, such as an `echo` or a call written outside every function. The order in which Baton finds the source files of a project has no meaning for the running program, so such a statement has no moment at which to run.

## Fix

Move the statements into a function and call it from the entry file, for example from `main`.

If the file is meant to be the starting point of the program, name it as `entry` in `Baton.toml`.

## Example

No single source file raises this code: a file checked alone with `doriac check` may contain top-level statements. The code is reported when a project is checked, for example with `baton check`, for a statement in any file other than the entry file of the selected binary.
