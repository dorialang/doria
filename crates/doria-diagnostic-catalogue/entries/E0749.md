# Invalid Interface Or Trait Requirement

Title: varies
Family: interfaces

## Explanation

An interface lists requirements: instance method signatures that end with `;`, and property accessors without bodies. Each method requirement states its return type. This error means a member of an interface does not have that shape. It has a body, a default parameter value, no return type, or a modifier such as `static`, `internal`, `open` or `override`, or it is a constant or a constructor.

The code is also reported for a bodyless method in a trait that has no return type or declares a default value, and for `self` in an interface requirement anywhere other than as the whole return type.

## Fix

Write each interface method as a signature with a return type and a closing `;`, as in `function render(): string;`. Move the body into the class that implements the interface.

Declare constants, constructors and static members on a class.

## Example

```doria
interface Renderable
{
    function render(): string
    {
        return "";
    }
}

class Report implements Renderable
{
    function render(): string
    {
        return "report";
    }
}

function main(): void
{
    let $report = new Report();
    echo $report->render();
}
```
