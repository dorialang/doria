# Wrong Number Of Arguments To `panic`

Title: varies
Family: functions

## Explanation

`panic` takes exactly one argument, the message. This error means the call has no argument or more than one.

## Fix

Pass one `string`. To include other values in the message, interpolate them: `panic("request failed with status {$code}");`.

## Example

```doria
function main(): void
{
    let $code = 404;
    panic("request failed", $code);
}
```
