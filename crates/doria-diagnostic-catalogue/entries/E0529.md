# Collection Cannot Be Filled Or Iterated This Way

Title: varies
Family: collections

## Explanation

The repeat form `[value; count]` builds a typed array `T[]` or a `List<T>`. This error means it is used where a `Set` or a `Dictionary` is expected. A set holds each value once and a dictionary needs a key for every value, so repeating one value fills neither.

The code is also raised for `foreach` over a `PriorityQueue`. A priority queue hands out its smallest element next and has no order to iterate in.

## Fix

Build a `List` with the repeat form. If a set is needed, pass the list to `Set::from`. Fill a dictionary by calling `set` for each key.

For a `PriorityQueue`, take the elements with `pop` until `isEmpty` is true. This empties the queue.

## Example

```doria
function main(): void
{
    Set<int> $zeros = [0; 3];
    echo $zeros->count;
}
```
