# Unknown Collection Member

Title: fixed

## Explanation

The program uses a method or property that this collection type does not have. Each collection has its own member set, and names from other languages are not aliases. A `List` grows with `add` and reports `count`.

## Fix

Use the member the message suggests, or look up the collection in the standard-library reference. Common ones: `List` has `add`, `insertAt`, `removeAt`, `pop`, `get`, `contains`, `first`, `last` and `count`; `Dictionary` has `get`, `set`, `remove` and `containsKey`; a typed array reports `length`.

## Example

```doria
function main(): void
{
    List<string> $names = ["Ada"];
    $names->push("Grace");
}
```
