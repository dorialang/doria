# Property Accessor Is Missing

Title: fixed
Family: interfaces

## Explanation

A property with hooks is read through its `get` hook. This error means the program reads a property that declares a `set` hook and no `get` hook.

A compound assignment such as `+=`, and `++` or `--`, read the property before they assign it, so they need the `get` hook as well.

## Fix

Add a `get` hook to the property, for example `get => $this->hash;`.

When the property is meant to be assigned and never read, remove the read and expose the value another way, for example through a method.

## Example

```doria
class Account
{
    internal writable string $hash = "";

    writable string $password {
        set (string $value) => $this->hash = String::upper($value);
    }
}

function main(): void
{
    let writable $account = new Account();
    $account->password = "secret";
    echo $account->password;
}
```
