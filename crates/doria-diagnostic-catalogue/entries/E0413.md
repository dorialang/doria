# Readonly Property Needs A Plain Assignment

Title: varies

## Explanation

A constructor initializes a readonly property with a plain assignment, `$this->count = $value`. A compound assignment such as `+=` changes a value that is already there, and a readonly property does not allow that.

## Fix

Work out the full value and assign it once with `=`, for example `$this->count = 10 + $start`. Declare the property `writable` if the constructor or a later method should change it.

## Example

```doria
class Counter
{
    int $count = 10;

    function __construct(parameter int $start)
    {
        $this->count += $start;
    }
}

function main(): void
{
    let $counter = new Counter(1);
    echo $counter->count;
}
```
