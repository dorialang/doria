# Invalid Argument To A Conversion

Title: varies
Family: types

## Explanation

The conversion members of the number companions each take exactly one argument of one kind. `Int::from` and the `from` member of every other integer companion take an integer. `Int::toFloat` takes an `int`. `Float::toInt` takes a `float`. `Int::parse` and `Float::parse` take a `string`.

This error means the call has the wrong number of arguments, or its argument has another type.

## Fix

Call the member that matches the value you have: `Float::toInt($ratio)` for a `float`, `Int::toFloat($count)` for an `int`, and `Int::parse($text)` for a `string`. `parse` gives a nullable result, so supply a fallback with `??` or test for `null`.

## Example

```doria
function main(): void
{
    let $ratio = 2.5;
    let $count = Int::from($ratio);
}
```
