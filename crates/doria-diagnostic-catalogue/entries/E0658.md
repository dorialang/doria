# Borrowing Closure Cannot Escape

Title: varies
Family: functions

## Explanation

A closure that captures with `with ($value)` or `with (writable $value)` borrows the variable, so it can be used only while that variable exists. A closure with no captures, or with `take` captures only, owns everything it needs and can go anywhere.

This error means a borrowing closure is sent somewhere that outlives what it borrows. It is returned from the function that declares the captured variable, added to a collection or assigned to a variable declared in an outer block, or stored in a property. A closure that captures `$this` cannot be stored in a property of the same object.

## Fix

Capture with `take`, as in `fn() with (take $start) => $start + 1`. A Copy value such as an `int` is copied into the closure, and a class value moves into it.

Or keep the closure inside the scope of the variable it borrows and use it there.

## Example

```doria
function makeCounter(): function(): int
{
    let $start = 10;
    return fn() with ($start) => $start + 1;
}

function main(): void
{
    let $next = makeCounter();
    echo $next();
}
```
