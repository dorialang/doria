# Initializer Is Not A Constant Expression

Title: varies
Family: classes

## Explanation

The initializer of a constant or a static property is evaluated when the program is compiled. It may contain literals, other constants, parentheses, arithmetic, comparison, boolean and string operators, and numeric conversions such as `Int::toFloat`.

This error means the initializer contains something else, such as a function call or `new`, or that an operation in it fails, such as integer overflow or division by zero.

## Fix

Rewrite the initializer with literals, constants and operators. When the value has to be computed while the program runs, compute it in a function and call that function where the value is needed.

## Example

```doria
function defaultLimit(): int
{
    return 25;
}

const PAGE_SIZE = defaultLimit();

function main(): void
{
    echo PAGE_SIZE;
}
```
