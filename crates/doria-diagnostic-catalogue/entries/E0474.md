# Borrowed Value Cannot Be Given Away

Title: varies
Family: ownership

## Explanation

Only the owner of a value can give it away. A parameter declared without `take` borrows its argument, and the caller remains the owner. Inside an ordinary method, `$this` is borrowed in the same way, and so is a result that a method returns from one of its object's properties.

This error means the program gives such a value to a new owner, for example by passing it to a `take` parameter.

## Fix

Declare the parameter `take` so that the function receives ownership: `function forward(take Ticket $ticket)`. To give away `$this`, declare the method `consuming function`.

If the receiving function only reads the value, remove `take` from its parameter. Otherwise pass a value that the caller owns, such as a new object.

## Example

```doria
class Ticket
{
    function __construct(string $holder)
    {
    }
}

function redeem(take Ticket $ticket): void
{
    echo "Redeemed for {$ticket->holder}";
}

function forward(Ticket $ticket): void
{
    redeem($ticket);
}

function main(): void
{
    forward(new Ticket("Ada"));
}
```
