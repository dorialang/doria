# Setter Requires A Writable Property

Title: fixed
Family: interfaces

## Explanation

A property is readonly unless it is declared `writable`. A `set` hook runs when the property is assigned, so a property that declares one must be assignable. This error means a property without `writable` declares a `set` hook.

The rule is the same in a class, a trait and an interface.

## Fix

Declare the property `writable`, as in `writable float $fahrenheit { get => ...; set (float $value) => ...; }`.

To keep the property readonly, remove the `set` hook and leave the `get` hook.

## Example

```doria
class Temperature
{
    internal writable float $celsius = 0.0;

    float $fahrenheit {
        get => $this->celsius * 9.0 / 5.0 + 32.0;
        set (float $value) =>
            $this->celsius = ($value - 32.0) * 5.0 / 9.0;
    }
}

function main(): void
{
    let writable $reading = new Temperature();
    $reading->fahrenheit = 212.0;
    echo $reading->fahrenheit;
}
```
