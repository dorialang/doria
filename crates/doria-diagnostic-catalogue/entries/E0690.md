# Attribute Class Cannot Be Generic

Title: fixed
Family: projects

## Explanation

A class marked with `#[Attribute]` describes metadata that is fixed when the program is compiled. Its constructor parameters have exact types, so the class cannot declare type parameters.

## Fix

Remove the type parameters from the class and give each constructor parameter a concrete type such as `string`, `int`, `bool` or an enum.

If the class is meant to be an ordinary generic class, remove `#[Attribute]`.

## Example

```doria
#[Attribute]
class Tagged<T>
{
    function __construct(string $label)
    {
    }
}

function main(): void
{
    echo "ready";
}
```
