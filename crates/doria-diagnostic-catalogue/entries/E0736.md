# Parent Constructor Call Is Not Allowed Here

Title: fixed
Family: classes

## Explanation

`parent::__construct(...)` initializes the parent part of an object while the object is being constructed. It is allowed in one place: as the first statement of a subclass constructor. This error means the call appears in another method.

## Fix

Remove the call from the method and keep the one in `__construct`.

To change the object after construction, assign its `writable` properties or call an ordinary method of the parent, as in `parent::reset()`.

## Example

```doria
open class Shape
{
    function __construct(string $name)
    {
    }
}

class Square extends Shape
{
    function __construct()
    {
        parent::__construct("square");
    }

    function reset(): void
    {
        parent::__construct("square");
    }
}

function main(): void
{
    let $square = new Square();
    $square->reset();
}
```
