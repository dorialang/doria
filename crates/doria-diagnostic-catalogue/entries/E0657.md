# Nonescaping Callback Cannot Be Retained

Title: fixed
Family: functions

## Explanation

A parameter of a function type borrows its function value for the length of the call. The function may call it and pass it on to another call. It cannot keep it.

This error means a function returns such a parameter, stores it in a property or a collection, or passes it to a `take` parameter of another function.

## Fix

Declare the parameter `take`, as in `take function(int): int $transform`. The function then owns the function value and may return or store it, and the caller gives it up. An editor offers this change as a fix to review.

If the function only needs to call the callback, remove the code that keeps it.

## Example

```doria
function keep(function(int): int $transform): function(int): int
{
    return $transform;
}

function main(): void
{
    let $double = keep(fn(int $value) => $value * 2);
    echo $double(21);
}
```
