# Use The Doria Spelling

Title: varies

## Explanation

The call names a function from another language, or an earlier Doria spelling, for something Doria spells differently. The compiler knows the replacement and names it in the message.

Most often this is a PHP string function. Doria keeps string operations on the `String` companion and string measurements on properties, and has no `str_*` family: `str_pad` is `String::padEnd` or `String::padStart`, `strtolower` is `String::lower`, and `strlen` is `$text->byteLength`. The PHP input function `readline` is `read_line`.

## Fix

Write the spelling the message names. When the arguments already fit, an editor offers the rename as a quick fix.

Some replacements take their arguments in a different order, for example `String::replace($text, $search, $replacement)` and `String::split($text, $separator)`. Doria measures text in grapheme clusters where PHP counts bytes, so check lengths and positions after translating.

## Example

```doria
function main(): void
{
    echo str_pad("Doria", 8);
}
```
