# Constructor Or Destructor Called Directly

Title: varies

## Explanation

The program calls `__construct` or `__destruct` by name. Doria runs these two methods itself: `new` runs the constructor when it creates an object, and the destructor runs when the object is destroyed.

## Fix

Create an object with `new`, as in `new Session()`. To put an existing object back into its starting state, write an ordinary method that does so and call that method.

Remove a direct call to `__destruct`. Move cleanup that must happen earlier into an ordinary method.

## Example

```doria
class Session
{
    function __destruct()
    {
    }
}

function main(): void
{
    let $session = new Session();
    $session->__destruct();
}
```
