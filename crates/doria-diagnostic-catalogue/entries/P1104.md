# Integer Negation Overflowed

Title: fixed
Family: runtime

## Explanation

Negating a signed integer is checked. A signed type holds one more negative value than positive values: an `int8` holds -128 through 127. This panic means the program negated the lowest value of its type, and the result does not fit.

## Fix

Convert to a wider type before negating: `-Int::from($lowest)`.

If the value is already `int`, test for the lowest value before negating and handle it separately.

## Example

```doria
function main(): void
{
    int8 $lowest = -128;
    int8 $flipped = -$lowest;
    echo $flipped;
}
```
