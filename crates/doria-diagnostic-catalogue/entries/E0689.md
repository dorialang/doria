# Attribute Marker Does Not Accept Arguments

Title: fixed
Family: projects

## Explanation

`#[Attribute]` is a marker with no parameters. It states that a class is an attribute class and carries no options of its own. This error means the marker was written with arguments.

## Fix

Write the marker as `#[Attribute]`. Values that belong to the attribute are declared as constructor parameters of the class and supplied where the attribute is applied, as in `#[Route("/posts")]`.

## Example

```doria
#[Attribute(repeatable: true)]
class Route
{
    function __construct(string $path)
    {
    }
}

function main(): void
{
    echo "ready";
}
```
