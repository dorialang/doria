# List Map Result Must Be Owned

Title: fixed
Family: collections

## Explanation

`map` stores each value its callback returns in a new list, and that list owns its elements. The callback receives each element of the source list readonly, so it borrows the element.

This error means the callback returns a class value or collection that still belongs to the source list, most often the element itself, as in `fn(Item $item) => $item`.

## Fix

Return a value the callback creates, such as `new Item($item->price)`, or a Copy value read from the element, such as `$item->price`.

To select elements without changing them, use `filter`.

## Example

```doria
class Item
{
    function __construct(int $price)
    {
    }
}

function main(): void
{
    List<Item> $items = [new Item(5), new Item(50)];
    let $same = $items->map(fn(Item $item) => $item);
    echo $same->count;
}
```
