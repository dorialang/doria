# Constructor Or Destructor Declares A Return Type

Title: varies

## Explanation

`__construct` and `__destruct` return no value, so the only return type either one may declare is `void`. The object comes from `new`, and the constructor prepares it.

## Fix

Remove the return type, or write `: void`. To give the caller a value worked out during construction, store it in a property, or write a static method that returns it.

## Example

```doria
class Counter
{
    writable int $count = 0;

    function __construct(): int
    {
    }
}

function main(): void
{
    let $counter = new Counter();
    echo $counter->count;
}
```
