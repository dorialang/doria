# Duplicate Catch

Title: fixed
Family: errors

## Explanation

The `catch` clauses of a `try` are tested in source order, and the first clause that covers the error handles it. This error means two clauses of one `try` name the same type, so the second can never run.

## Fix

Remove one of the two clauses. If both bodies hold code that is needed, merge them into the clause that remains.

## Example

```doria
class ParseError implements Error
{
    function __construct(string $message)
    {
    }
}

function parse(string $text): int throws ParseError
{
    if ($text == "") {
        throw new ParseError("empty input");
    }
    return $text->length;
}

function main(): void
{
    try {
        echo parse("abc");
    } catch (ParseError $error) {
        echo $error->message;
    } catch (ParseError $error) {
        echo "failed";
    }
}
```
