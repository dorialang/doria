# Integer Division By Zero

Title: fixed
Family: runtime

## Explanation

The right operand of an integer `/` was zero when the program ran. Integer division by zero has no result, so the program panics. `/=` is checked the same way.

## Fix

Test the divisor before dividing, and decide what the program does when it is zero: `if ($people > 0) { ... }`.

If the divisor comes from input or from a count, such as the `count` of a collection, zero is an ordinary case and needs its own branch.

## Example

```doria
function main(): void
{
    let $total = 120;
    let $people = 0;
    echo $total / $people;
}
```
