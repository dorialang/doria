# Variadic Declaration Is Not Valid

Title: varies
Family: unsafe

## Explanation

A binding of a variadic C function is not valid. `#[Variadic(fixedParameters: N)]` names how many leading parameters are fixed, between one and the declaration's parameter count. C promotes every argument after them: `float` to `double`, and an integer narrower than `int`, `bool`, `char` and `wchar_t` to `int`. A binding therefore declares those parameters with their promoted types, so every call passes exactly what the C function reads on every platform.

## Fix

Declare the promoted type the message names, such as `float64` for `float32` and `int32` for `int8`, `int16`, `bool` or `CChar`. Keep `fixedParameters` within the declaration's parameter count.

## Example

```doria
use Doria\Std\Ffi\{CChar, LinkName, Pointer, Variadic};

extern "C"
{
    /** @safety `$format` points to a NUL-terminated format with one `%f`. */
    #[LinkName("printf")]
    #[Variadic(fixedParameters: 1)]
    function printReal(Pointer<CChar> $format, float32 $value): int32;
}

function main(): void
{
}
```
