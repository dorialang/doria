# `panic` Used As A Value

Title: varies
Family: types

## Explanation

`panic` stops the program and produces no value. A call to it is a statement by itself. This error means the call is part of an expression: an initializer, an argument, an operand, a `return` value or the body of an arrow closure.

## Fix

Write `panic("message");` as its own statement. Where the call depends on a condition, test the condition with `if` and put the call in the branch.

In a closure, use the block form: `function (): void { panic("invalid state"); }`.

## Example

```doria
function main(): void
{
    let $stop = fn() => panic("invalid state");
    $stop();
}
```
