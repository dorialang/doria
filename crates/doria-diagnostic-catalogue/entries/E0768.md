# Property Accessor Is Missing

Title: fixed
Family: interfaces

## Explanation

A property with hooks is assigned through its `set` hook. This error means the program assigns a property that declares a `get` hook and no `set` hook. A property with only a `get` hook cannot be assigned.

## Fix

Assign the properties that the getter reads. In the example, change `$shape->width` or `$shape->height`, and `$shape->area` follows.

When the property is meant to be assigned, declare it `writable` and add a `set` hook whose parameter has the property's type, for example `set (int $value) => ...;`.

## Example

```doria
class Rectangle
{
    function __construct(writable int $width, writable int $height) {}

    int $area {
        get => $this->width * $this->height;
    }
}

function main(): void
{
    let writable $shape = new Rectangle(3, 4);
    $shape->area = 20;
    echo $shape->area;
}
```
