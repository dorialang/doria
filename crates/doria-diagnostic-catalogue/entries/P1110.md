# Float To Integer Conversion Is Out Of Range

Title: fixed
Family: runtime

## Explanation

`Float::toInt` drops the fraction of a `float` and gives the whole part as an `int`. This panic means the float has no `int` value: it is NaN, it is infinite, or its whole part is outside the range of `int`.

Float division by zero does not panic. It gives an infinity, or NaN for zero divided by zero, and the panic comes later when that result is converted.

## Fix

Find where the float came from. If it is the result of a division, test the divisor before dividing: `if ($count > 0.0) { ... }`.

If the value can be very large, compare it with the bounds the program accepts before calling `Float::toInt`.

## Example

```doria
function main(): void
{
    let $total = 12.5;
    let $count = 0.0;
    let $average = Float::toInt($total / $count);
    echo $average;
}
```
