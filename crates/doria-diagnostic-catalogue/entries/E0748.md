# Foreach Binding Type Is Required

Title: fixed
Family: control-flow

## Explanation

Each binding in a `foreach` declares a variable for the loop body, and every binding is written with its type. This error means a binding has only a name. The rule covers the value binding and, in the two-binding form, the first binding.

## Fix

Write the type before the binding name, as in `foreach ($names as string $name)`. The message names the type the binding has.

In the two-binding form, write both types: `foreach ($names as int $index => string $name)`.

## Example

```doria
function main(): void
{
    List<string> $names = ["Ada", "Grace"];
    foreach ($names as $name) {
        echo $name;
    }
}
```
