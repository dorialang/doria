# Return Value Not Allowed

Title: varies

## Explanation

A `return` statement gives a value in a place that returns none: a function or method declared `void`, a constructor, or a destructor.

## Fix

Remove the value. A bare `return;` leaves the function early. If the function should produce the value, declare the value's type as its return type.

## Example

```doria
function greet(): void
{
    echo "Hello";
    return 1;
}

function main(): void
{
    greet();
}
```
