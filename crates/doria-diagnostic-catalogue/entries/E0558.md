# Use A Collection Literal

Title: fixed
Family: collections

## Explanation

`List` and `Dictionary` are constructed with bracket literals. `::from` belongs to the collection types that have no literal form, such as `SortedSet` and `Deque`. This error means the program calls `List::from` or `Dictionary::from`.

## Fix

Write the bracket literal directly: `List<int> $scores = [90, 75];` or `Dictionary<string, int> $ages = ["Ada" => 36];`.

For an empty collection, declare the type: `List<int> $scores = [];`.

## Example

```doria
function main(): void
{
    List<int> $scores = List::from([90, 75]);
    echo $scores->count;
}
```
