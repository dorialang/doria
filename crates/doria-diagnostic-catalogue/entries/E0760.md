# Primitive Interface Erasure Is Not Allowed

Title: fixed
Family: interfaces

## Explanation

A variable, a property or a collection element whose type is an interface holds an object of a class that implements that interface. This error means an `int`, `float`, `bool` or `string` value, or an enum value, was stored in such a place.

A primitive, or a Copy enum, satisfies a constraint such as `Equatable` or `Hashable` on a generic type parameter. It is never held as an interface value.

## Fix

Declare the place with the value's own type: `string $label = "ready";`.

To write code that accepts any displayable value, including primitives, use a generic type parameter with a constraint: `function describe<T implements Displayable>(T $value): string`. A call such as `describe(42)` is then valid.

## Example

```doria
function main(): void
{
    Displayable $label = "ready";
    echo $label->toString();
}
```
