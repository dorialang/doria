# Constructor Parameter Role Is Required

Title: fixed
Family: classes

## Explanation

A constructor parameter becomes a property of its class unless it carries a role. This error means a constructor parameter in a derived class has the name and type of a property the class already inherits, so it would declare that property a second time.

## Fix

Write `override` before the parameter to reuse the inherited property. No new property is created, and the value reaches the parent through `parent::__construct(...)`.

Write `parameter` before it if the value is only an input to the constructor.

## Example

```doria
open class Document
{
    function __construct(string $title)
    {
    }
}

class Article extends Document
{
    function __construct(string $title)
    {
        parent::__construct($title);
    }
}

function main(): void
{
    let $article = new Article("News");
    echo $article->title;
}
```
