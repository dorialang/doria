# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

A grouped declaration declares several variables with one initializer, as in `int $minimum, $maximum = 0;`. This code means that a group whose type holds values with a single owner passed checking and then reached a step of compilation that cannot give one such value to several variables. Those types are classes, collections, `mixed`, interfaces, enums with a payload, function values, and shared-ownership handles.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the grouped declaration, so keep it and the type it names, and remove the code around them.

Until the defect is corrected, declare each variable of the group in its own statement, as in `?Shape $first = null;` followed by `?Shape $second = null;`.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that declares several variables of such a type in one grouped declaration.
