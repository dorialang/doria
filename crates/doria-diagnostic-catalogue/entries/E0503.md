# `$this` Used Before Every Property Is Initialized

Title: varies
Family: classes

## Explanation

Inside a constructor, the object is incomplete until every property has a value. Until then the constructor may assign properties and read the ones that already have a value. This error means the constructor uses `$this` as a whole before that point: it calls a method on `$this`, or it passes `$this` to a function. The message lists the properties that are still missing.

## Fix

Initialize every property first, then make the call. Moving the assignments to the top of the constructor is usually enough.

If the method only computes a value from the constructor's inputs, make it a `static function` and pass the inputs to it.

## Example

```doria
class Token
{
    string $value;

    function __construct()
    {
        $this->announce();
        $this->value = "ready";
    }

    function announce(): void
    {
        echo "created";
    }
}

function main(): void
{
    let $token = new Token();
    echo $token->value;
}
```
