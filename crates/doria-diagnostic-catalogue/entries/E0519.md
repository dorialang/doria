# Named Arguments Are Not Accepted Here

Title: varies
Family: functions

## Explanation

Named arguments match the parameter names of functions, methods, static methods and constructors that a program declares. Built-in functions such as `write_stderr` and `panic`, collection methods such as `add`, and collection factories such as `Set::from` take their arguments by position only.

## Fix

Remove the name and pass the value by position: `write_stderr("disk is full")`. When the built-in takes several arguments, write them in its documented order.

## Example

```doria
function main(): void
{
    write_stderr(message: "disk is full");
}
```
