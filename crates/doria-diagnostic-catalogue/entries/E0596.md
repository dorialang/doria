# Match Guard Uses The Wrong Keyword

Title: fixed
Family: enums

## Explanation

A guard is an extra condition on a `match` arm, and it is written with `if`: `Pattern if condition => value`. This error means the guard is written with `when` or `where`.

## Fix

Replace the keyword with `if`. An editor offers the replacement as a quick fix.

## Example

```doria
function label(int $count, bool $urgent): string
{
    return match ($count) {
        1 when $urgent => "single, urgent",
        1 => "single",
        default => "many",
    };
}

function main(): void
{
    echo label(1, true);
}
```
