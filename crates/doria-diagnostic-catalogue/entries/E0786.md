# Type Cannot Cross The C Boundary

Title: fixed
Family: unsafe

## Explanation

A foreign signature, a C function pointer type, a pointer's pointee or a foreign struct or union field uses a type that has no C representation. The types that cross the C boundary unchanged are the fixed-width integers and floats, `bool`, `Ptr<T>` and `MutPtr<T>` and their nullable forms, the `Doria\Std\Ffi` boundary types such as `CLong` and `CSize`, C function pointer types and foreign structs and unions.

Doria strings, collections, class instances and closures are not among them: a binding never converts them implicitly, so every copy and allocation at the boundary stays visible in the source.

## Fix

Use the type the message names. Pass a string as `Ptr<CChar>` from a `CString`, or as `$text->byteRegion->pointer` with its length. Pass `Bytes` or a typed array as a region pointer with its length. Pass a class instance as a raw handle, `MutPtr<Opaque>`. Pass a callback as a C-ABI function.

## Example

```doria
extern "C"
{
    /** @safety `$text` is a string. */
    function puts(string $text): int32;
}

function main(): void
{
}
```
