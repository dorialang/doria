# Type Cannot Cross The C Boundary

Title: fixed
Family: unsafe

## Explanation

A foreign signature, a C function pointer type, a pointer's pointee or a foreign struct or union field uses a type that has no C representation. A generic call, or a use of a generic class, interface or enum such as `Reader<string>`, reports it when the type it supplies for a type parameter that is a pointee, as `T` in `Pointer<T>`, has none. The types that cross the C boundary unchanged are the fixed-width integers and floats, `bool`, `Pointer<T>` and `WritablePointer<T>` and their nullable forms, the `Doria\Std\Ffi` boundary types such as `CLong` and `CSize`, C function pointer types and foreign structs and unions.

Doria strings, collections, class instances and closures are not among them: a binding never converts them implicitly, so every copy and allocation at the boundary stays visible in the source.

## Fix

Use the type the message names. Pass a string as `Pointer<CChar>` from a `CString`, or as `$text->byteRegion->pointer` with its length. Pass `Bytes` or a typed array as a region pointer with its length. Pass a class instance as a handle, `WritablePointer<Opaque>`. Pass a callback as a C-callable function.

## Example

```doria
extern "C"
{
    /** @safety `$text` is a string. */
    function puts(string $text): int32;
}

function main(): void
{
}
```
