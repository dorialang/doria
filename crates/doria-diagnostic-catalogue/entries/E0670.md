# Import Name Is Already Taken

Title: varies
Family: projects

## Explanation

A `use` statement brings a declaration into the file under a short name: the last segment of its path, or the name written after `as`. Each short name in a file means one thing.

This error means an import's short name cannot be used. Another `use` in the file already has that name, the same declaration is imported twice, the file declares something of its own with that name, or the name is reserved by the language, such as `List` or `read_line`.

## Fix

Give the import a different name with `as`: `use Doria\Std\Io\IoOperation as Operation;`. If the same declaration is imported twice, remove one of the two `use` statements.

When the name belongs to a declaration in the same file, rename that declaration or alias the import.

## Example

```doria
use Doria\Std\Io\IoError as Failure;
use Doria\Std\Io\IoOperation as Failure;

function main(): void
{
    echo "ready";
}
```
