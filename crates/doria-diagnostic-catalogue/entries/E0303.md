# Unknown Property

Title: varies

## Explanation

The program reads or writes a property that the value's class does not have. No property with this name is declared in the class.

When a value is typed as an interface, the properties available on it are the ones that interface declares.

## Fix

Check the spelling and the case of the property name. If the class should have the property, declare it in the class.

For a value typed as an interface, declare the property accessor in that interface.

## Example

```doria
class Point
{
    writable int $x = 0;
}

function main(): void
{
    let $point = new Point();
    echo $point->y;
}
```
