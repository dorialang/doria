# List Algorithm Callback Requires Writable Access

Title: fixed
Family: collections

## Explanation

`map`, `filter` and `reduce` on a `List` call their callback once for every element. A closure that changes a captured variable, such as one declared `with (writable $calls)`, is a writable function value: calling it needs exclusive access to the function value.

This error means such a callback is held in a readonly variable or parameter. A readonly function value is never widened to writable access, so the list method cannot call it.

## Fix

Declare the variable that holds the callback `writable`: `let writable $callback = function (int $value): int with (writable $calls) { ... };`. For a parameter, write `writable` before its function type and pass a writable value at the call.

If the callback has no need to change what it captures, remove `writable` from its capture list so that it is a readonly function value.

## Example

```doria
function main(): void
{
    List<int> $values = [1, 2, 3];
    let writable $calls = 0;
    let $callback = function (int $value): int with (writable $calls) {
        $calls += 1;
        return $value * 2;
    };
    let $doubled = $values->map($callback);
    echo $doubled->count;
}
```
