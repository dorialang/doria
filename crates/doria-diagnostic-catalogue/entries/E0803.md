# Array Region Length Does Not Match The Field

Title: fixed
Family: unsafe

## Explanation

A fixed-length array field of a foreign struct or union is supplied at construction, or assigned whole with `$value->field = $region`, from an `ArrayRegion<T>`, whose elements are copied into the field. The region must have exactly as many elements as the field declares: the copy never truncates or pads. This error means the compiler can see the region's length, from a `getRegion` with a constant length or from another fixed-length array field, and it differs from the field's count. A length the compiler cannot see is checked when the program runs, which panics with P1704.

## Fix

Take a region of the field's length. To copy fewer elements, copy them into the field's region with `$value->field->copyFrom($source)`; at construction, omit the field, which is zero-filled, first.

## Example

```doria
extern "C" struct Tip
{
    uint16[3] $text;
}

function main(): void
{
    uint16[] $letters = [72, 105, 33, 0];
    let $tip = new Tip(text: $letters->getRegion(0, 4));
}
```
