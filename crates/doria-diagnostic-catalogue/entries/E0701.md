# Behavioral Test Declaration Requires Development Source

Title: fixed
Family: testing

## Explanation

`describe`, `it` and `test` from `Doria\Std\Test` declare tests. They are available only in development source: the files that a Baton project maps under `[autoload-dev.namespaces]` in `Baton.toml`.

This error means one of them is called in main source. The files mapped under `[autoload.namespaces]` are main source, and so is a file given directly to `doriac check`.

## Fix

Move the test into a development source file of a Baton project and run it with `baton test`. A development source directory is declared in `Baton.toml` with an entry such as `"App\\Tests\\" = "tests/"` under `[autoload-dev.namespaces]`, and a file in it begins with the matching `namespace App\Tests;`.

Remove the test declaration from the main source file.

## Example

```doria
use Doria\Std\Test\{it, expect};

it("adds two numbers", function (): void {
    expect(1 + 1)->toEqual(2);
});

function main(): void
{
    echo "started";
}
```
