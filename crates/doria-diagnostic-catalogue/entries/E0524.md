# Collection Operation Needs Equatable Values

Title: varies
Family: collections

## Explanation

`contains`, `indexOf`, `remove`, `containsKey` and `containsValue` find a value by comparing it for equality with the values in the collection. This error means the value type has no equality that the collection can use.

A class has value equality when it declares `implements Equatable` for itself. A method named `equals` on a class without that declaration does not count.

## Fix

Declare the class `implements Equatable<Point>` and give it `function equals(Point $other): bool`.

If the class should not define equality, hold an `int` or `string` identifier for each object and search for the identifier.

## Example

```doria
class Point
{
    function __construct(int $x, int $y) {}
}

function main(): void
{
    List<Point> $points = [new Point(1, 2)];
    let $origin = new Point(0, 0);
    echo $points->contains($origin);
}
```
