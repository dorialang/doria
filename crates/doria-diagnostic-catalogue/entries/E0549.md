# Weak Reference Has No Direct Member Access

Title: varies
Family: ownership

## Explanation

A `WeakReference<T>` or a `WritableWeakReference<T>` does not keep its value alive, so the value may already be gone. This error means a member of the value is used directly on the weak reference.

## Fix

Call `acquire()` on the weak reference. It returns a nullable shared reference, which is `null` once the last owner has released the value. Test the result for `null`, then use the member on it: `let $live = $weak->acquire();` followed by `if ($live != null) { echo $live->name; }`.

`acquire()` on a `WritableWeakReference<T>` returns a `?WritableSharedReference<T>`, so acquire access on the result before using the value.

## Example

```doria
class Node
{
    string $name = "root";
}

function main(): void
{
    let $node = shared new Node();
    let $weak = $node->createWeakReference();
    echo $weak->name;
}
```
