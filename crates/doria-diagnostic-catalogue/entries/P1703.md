# Pointer Arithmetic Left The Address Space

Title: fixed
Family: runtime

## Explanation

`offset` and `byteOffset` move a pointer by a number of elements or bytes. The arithmetic is checked in every profile. This panic means the new address would be below zero, past the largest address, or exactly zero, which no `Pointer<T>` holds: `?Pointer<T>` is the type that may be null. It usually means a count or length went negative or was much larger than the buffer it walks.

The four `fromPointer` constructors of `ByteRegion`, `WritableByteRegion`, `ArrayRegion` and `WritableArrayRegion` panic with this code when their length is negative, or when that many bytes or elements from the pointer would pass the largest address.

## Fix

Find where the count came from and test it against the length of the memory the pointer addresses before moving: `if ($index >= 0 and $index < $length) { ... }`.

## Example

```doria
use Doria\Std\Ffi\Pointer;

function main(): void
{
    unsafe {
        ?Pointer<uint8> $pointer = Pointer::fromAddress(8);
        if ($pointer != null) {
            let $before = $pointer->byteOffset(-16);
            echo $before->address;
        }
    }
}
```
