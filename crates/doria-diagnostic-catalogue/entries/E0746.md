# Sequence Index Binding Must Be Int

Title: fixed
Family: collections

## Explanation

When `foreach` runs over a `List<T>` or an array `T[]`, the first binding is the position of the element, counted from zero, and its type is `int`. This error means the first binding is declared with another type, such as `string`, `?int` or `mixed`.

## Fix

Declare the first binding as `int`: `foreach ($names as int $index => string $name)`.

If the loop does not use the position, remove the first binding and `=>`.

## Example

```doria
function main(): void
{
    List<string> $names = ["Ada", "Grace"];
    foreach ($names as string $index => string $name) {
        echo $name;
    }
}
```
