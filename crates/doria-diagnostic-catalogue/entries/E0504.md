# Readonly Property Initialized Inside A Loop

Title: varies
Family: classes

## Explanation

A readonly property is initialized exactly once. The body of a `while`, `for` or `foreach` loop can run many times or zero times, so an assignment there cannot be the one initialization of the property.

## Fix

Keep the value in a local variable declared `writable` while the loop runs, and assign the property once after the loop.

If the property is meant to change while the loop runs, declare it `writable` and give it an initializer.

## Example

```doria
class History
{
    int $latest;

    function __construct(parameter List<int> $readings)
    {
        foreach ($readings as int $reading) {
            $this->latest = $reading;
        }
    }
}

function main(): void
{
    let $history = new History([3, 5, 8]);
    echo $history->latest;
}
```
