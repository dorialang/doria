# Input Text Is Not Valid UTF-8

Title: fixed
Family: runtime

## Explanation

This code names a line of standard input that was not valid UTF-8 and ended the program as a panic. It is a historical identity. A `string` is always valid UTF-8, so `read_line` reports such a line as a checked `Doria\Std\Io\InvalidUtf8Error`, which the program can catch.

An `InvalidUtf8Error` that nothing catches ends the program with R1000 under the title `Unhandled Doria\Std\Io\InvalidUtf8Error`.

## Fix

Catch the error where the program can recover: wrap the call in `try` and add `catch (Doria\Std\Io\InvalidUtf8Error $error)`. `$error->validByteCount` is the number of bytes that were valid before the first bad one.

To accept input in any encoding, read it with `read_stdin_bytes`, which returns `Bytes` and performs no UTF-8 validation.

## Example

No program raises this code on demand: input that is not valid UTF-8 reaches the program as a `Doria\Std\Io\InvalidUtf8Error`, so no read ends with this panic. A programmer meets the same failure as R1000 when the error is not caught.
