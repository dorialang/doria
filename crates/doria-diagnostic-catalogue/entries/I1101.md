# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

The compiler found a path that reaches the end of a function body without returning a value, in a function or method whose return type is not `void`, after checking had accepted it. Checking requires such a function to return a value on every path, so the compiler has contradicted itself. The developer details name the function.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the body of the function, so keep that function and remove the code around it.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that contains a function or method with a return value.
