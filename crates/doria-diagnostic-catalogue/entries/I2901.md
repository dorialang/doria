# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

The compiler produced a result of an unexpected type for an expression that skips part of its evaluation. This code covers the short-circuit operators `&&` and `||`, with their synonyms `and` and `or`, whose result is a `bool`, and calls through the null-safe operator `?->`, whose result is nullable. It means that the compiled result of the operator is not a `bool`, or that a null-safe call produced no value or a value with no nullable form.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the expression the compiler was working on, so start there and remove the code around it.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that uses `&&`, `||` or `?->`.
