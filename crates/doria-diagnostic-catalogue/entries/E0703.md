# Behavioral Test Arguments Must Be Positional

Title: fixed
Family: testing

Example source: development

## Explanation

`describe`, `it` and `test` from `Doria\Std\Test` are declarations that the compiler reads, and their two arguments have no parameter names. The description comes first and the body closure second.

This error means an argument of one of them is written as a named argument, such as `body: function (): void { ... }`.

## Fix

Remove the names and keep the order, description then body: `it("adds two numbers", function (): void { ... });`.

## Example

```doria
use Doria\Std\Test\{it, expect};

it(description: "adds two numbers", body: function (): void {
    expect(1 + 1)->toEqual(2);
});
```
