# File Path Contains A NUL Byte

Title: fixed
Family: runtime

## Explanation

This code names a file operation whose path contained a NUL byte and ended the program as a panic. It is a historical identity. A path cannot contain a NUL byte, and the file functions report such a path as a checked `Doria\Std\Io\IoError` with the reason `IoErrorReason::InvalidInput`, which the program can catch.

An `IoError` that nothing catches ends the program with R1000 under the title `Unhandled Doria\Std\Io\IoError`.

## Fix

Find where the path was built. A NUL byte in a path usually comes from input that was not checked, such as a name read from binary data.

Where the program can recover, wrap the file operation in `try` and add `catch (Doria\Std\Io\IoError $error)`, then compare `$error->reason` with `IoErrorReason::InvalidInput`.

## Example

No program raises this code on demand: a path with a NUL byte reaches the program as a `Doria\Std\Io\IoError`, so no file operation ends with this panic. A programmer meets the same failure as R1000 when the error is not caught.
