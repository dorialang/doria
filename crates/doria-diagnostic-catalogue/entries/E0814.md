# Repeated Declare Directive

Title: fixed
Family: unsafe

## Explanation

Each `declare` key appears at most once in a file, so the file has one value for it. This error means the file states the same key a second time, even with the same value.

## Fix

Remove the repeated directive. When the two give different values, keep the one with the policy the file needs.

## Example

```doria
declare(unsafe: "deny");
declare(unsafe: "deny");

function main(): void
{
}
```
