# This Foreach Source Does Not Provide A First Binding

Title: fixed
Family: collections

## Explanation

The two-binding form of `foreach`, as in `foreach ($items as int $index => string $item)`, is for sources that have a first value to give. A `List<T>` or `T[]` gives an `int` index, and a `Dictionary<K, V>` or `SortedDictionary<K, V>` gives its key.

Integer ranges, `Set<T>`, `SortedSet<T>`, `Deque<T>` and the `keys` and `values` of a dictionary yield values only. This error means the loop asks one of those for a first binding.

## Fix

Remove the first binding and `=>`: `foreach ($ids as int $id)`. An editor offers the removal as a quick fix.

To number the values, declare a counter before the loop with `let writable $position = 0;` and increase it in the body with `$position++;`.

## Example

```doria
function main(): void
{
    Set<int> $ids = Set::from([3, 5]);
    foreach ($ids as int $index => int $id) {
        echo $id;
    }
}
```
