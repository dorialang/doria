# Cannot Assign To Class Constant

Title: varies
Family: classes

## Explanation

A class constant keeps the value from its declaration for the whole program. This error means the program assigns to one.

## Fix

Remove the assignment. For a class value that changes while the program runs, declare a writable static property, as in `static writable int $maxDepth = 8;`, and assign it through the class name: `Limits::maxDepth = 16;`.

## Example

```doria
class Limits
{
    const MAX_DEPTH = 8;
}

function main(): void
{
    Limits::MAX_DEPTH = 16;
    echo Limits::MAX_DEPTH;
}
```
