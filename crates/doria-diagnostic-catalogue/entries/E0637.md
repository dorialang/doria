# Catch Cannot Follow Finally

Title: fixed
Family: errors

## Explanation

A `try` statement lists every `catch` clause first and ends with at most one `finally` clause. This error means a `catch` clause is written after `finally`.

## Fix

Move the `catch` clause above `finally`, so that `finally` is the last clause of the `try` statement. The `finally` block still runs after the `catch` body.

## Example

```doria
class ConfigError implements Error
{
    function __construct(string $message)
    {
    }
}

function loadName(): string throws ConfigError
{
    throw new ConfigError("no name configured");
}

function main(): void
{
    try {
        echo loadName();
    } finally {
        echo "done";
    } catch (ConfigError $error) {
        echo $error->message;
    }
}
```
