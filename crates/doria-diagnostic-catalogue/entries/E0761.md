# Invalid Borrow Parameter

Title: varies
Family: ownership

## Explanation

`borrow` marks a constructor parameter whose value stays owned by the caller while the new object keeps access to it. The parameter becomes a property, and the object cannot outlive the value it was given. An iterator uses this to walk a collection that another object owns.

This error means `borrow` is written where that relationship cannot exist: on a parameter of a function or of a method other than `__construct`, on a constructor parameter marked `parameter`, which creates no property, or together with `take`, which gives the value away. It is also raised when a `borrow` parameter has a default value, because every construction must name a value that the caller owns.

## Fix

Remove `borrow` from a function or method parameter. A parameter without `take` already uses the caller's value for the length of the call and leaves ownership with the caller.

In a constructor, write `borrow` on a parameter that becomes a property, as in `function __construct(borrow List<Book> $source) {}`, without `take`, without `parameter`, and without a default value.

## Example

```doria
function total(borrow List<int> $values): int
{
    let writable $sum = 0;
    foreach ($values as int $value) {
        $sum += $value;
    }
    return $sum;
}

function main(): void
{
    List<int> $values = [1, 2, 3];
    echo total($values);
}
```
