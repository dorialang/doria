# Availability Clause Is Not Allowed Here

Title: fixed
Family: generics

## Explanation

A `where (...)` clause makes part of a generic class or trait available only when a type parameter implements an interface. It is allowed on a method, on a computed property, and on an entry of a class's `implements` list.

This error means the clause is written somewhere else: on a free function, on `__construct` or `__destruct`, on a requirement in an interface, or on a property that stores a value or has an initializer.

## Fix

On a free function, put the bound in the type parameter list: `function show<T implements Describable>(T $value): string`.

Constructors, destructors and stored properties exist for every instance of the class, and interface requirements are fixed. Remove the clause from them. To make a value conditional, declare a computed property, which has hooks and no storage of its own, and write the clause after the property name.

## Example

```doria
interface Describable
{
    function describe(): string;
}

class Label implements Describable
{
    function describe(): string
    {
        return "a label";
    }
}

function show<T>(T $value): string where (T implements Describable)
{
    return $value->describe();
}

function main(): void
{
    echo show(new Label());
}
```
