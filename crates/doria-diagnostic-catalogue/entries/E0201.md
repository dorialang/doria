# Readonly Value Cannot Be Changed

Title: varies

## Explanation

Variables and parameters are readonly unless they are declared `writable`. This error means the program changes something through a readonly one: it assigns the variable again, assigns to a property or an element through it, or calls a mutating collection method such as `add` on it.

Inside a method, `$this` is readonly unless the method is declared `writable function`.

## Fix

Declare the variable `writable`, as in `let writable $count = 1;` or `writable List<string> $names = [];`. For a parameter, write `writable` before its type and pass a writable value at the call.

To change properties of `$this`, declare the method `writable function`.

## Example

```doria
function main(): void
{
    let $count = 1;
    $count = 2;
    echo $count;
}
```
