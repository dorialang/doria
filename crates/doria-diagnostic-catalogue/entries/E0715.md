# Expectation Cannot Be Stored Or Returned

Title: varies
Family: testing

Example source: development

## Explanation

An expectation is a statement of its own: `expect(...)` followed by its matcher, or a call to `fail`. It produces no value.

This error means the program uses one as a value: it assigns it to a variable, returns it, or tests it as a condition. The code is also raised when the value given to `expect` is `void`, such as a call to a function that returns nothing.

## Fix

Write the expectation as its own statement: `expect($total)->toEqual(2);`. To reuse a group of checks, put them in a function and call that function from each test.

To check a function that returns `void`, call it first and then expect a value that it changed.

## Example

```doria
use Doria\Std\Test\{it, expect};

it("adds two numbers", function (): void {
    let $result = expect(1 + 1)->toEqual(2);
});
```
