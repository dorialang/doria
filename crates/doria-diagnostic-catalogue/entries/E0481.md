# Member Or Constant Is Already Declared

Title: varies
Family: names

## Explanation

A name is declared twice where each name may be declared once.

Inside a class, a constructor parameter becomes a property of the class with the same name. The error is raised when the class already declares a member with that name, so the parameter would declare it twice.

The code is also raised for a constant or a static member that is declared a second time under the same name.

## Fix

For a constructor parameter, remove the separate property declaration and let the parameter declare it, or rename one of the two. If the parameter is only an input to the constructor and should not become a property, mark it with `parameter`.

For a constant or a static member, remove the second declaration or give it another name.

## Example

```doria
class Point
{
    internal writable int $x = 0;

    function __construct(int $x)
    {
    }
}

function main(): void
{
    let $point = new Point(1);
}
```
