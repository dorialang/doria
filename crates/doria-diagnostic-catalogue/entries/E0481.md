# Promoted Property Name Is Already Used

Title: varies

## Explanation

A constructor parameter becomes a property of the class with the same name. This error means the class already declares a member with that name, so the parameter would declare it twice.

## Fix

Remove the separate property declaration and let the constructor parameter declare it, or rename one of the two. If the parameter is only an input to the constructor and should not become a property, mark it with `parameter`.

## Example

```doria
class Point
{
    internal writable int $x = 0;

    function __construct(int $x)
    {
    }
}

function main(): void
{
    let $point = new Point(1);
}
```
