# Parent Constructor Call Is Repeated

Title: fixed
Family: classes

## Explanation

A subclass constructor calls its parent constructor once, as its first statement, and the parent part of the object is initialized once. This error means the constructor contains a second `parent::__construct(...)` call.

## Fix

Keep the call that is the first statement and remove every later one.

## Example

```doria
open class Shape
{
    function __construct(string $name)
    {
    }
}

class Square extends Shape
{
    function __construct(int $side)
    {
        parent::__construct("square");
        parent::__construct("box");
    }
}

function main(): void
{
    let $square = new Square(2);
    echo $square->name;
}
```
