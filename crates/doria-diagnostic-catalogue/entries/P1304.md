# Byte Region Is Out Of Bounds

Title: fixed
Family: runtime

## Explanation

`getRegion` or `getWritableRegion` was called with an offset and a length that do not fit inside the source. Both must be zero or greater, and the offset plus the length must be at most the `length` of the buffer or region the view is taken from.

`copyWithin` on a `WritableByteRegion` panics with this code when its source range or its destination range does not fit inside the region.

## Fix

Work out the length from the source. `$packet->getRegion($offset, $packet->length - $offset)` covers everything from `$offset` to the end.

When the offset or the length comes from data, check it against `length` before taking the region.

## Example

```doria
function main(): void
{
    let $packet = Bytes::allocate(8);
    let $payload = $packet->getRegion(4, 8);
    echo $payload->length;
}
```
