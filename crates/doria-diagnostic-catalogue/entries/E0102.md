# `$this` Is Not Available Here

Title: varies

## Explanation

`$this` is the object an instance method was called on. This error means `$this` appears where there is no such object: in a free function, in a static method, or in top-level code.

## Fix

Pass the object as a parameter and use that parameter, or move the code into an instance method of the class.

In a static method, reach static members with `self::`, or remove `static` if the method needs an object.

## Example

```doria
function describe(): void
{
    echo $this->name;
}

function main(): void
{
    describe();
}
```
