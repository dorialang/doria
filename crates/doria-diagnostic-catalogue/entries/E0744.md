# Constructor Parameter Role Is Duplicated

Title: fixed
Family: classes

## Explanation

A constructor parameter carries at most one role word: `internal`, `override` or `parameter`. This error means the same role word is written twice on one parameter.

## Fix

Remove the repeated word. An editor offers the removal as a quick fix.

## Example

```doria
class Person
{
    function __construct(parameter parameter string $name)
    {
        echo $name;
    }
}

function main(): void
{
    let $person = new Person("Ada");
}
```
