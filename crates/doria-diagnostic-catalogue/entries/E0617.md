# Function Return Type Is Required

Title: fixed
Family: functions

## Explanation

Every named function and method declares its return type after the parameter list. The return type is never inferred from the body. This error means the declaration has no return type.

Constructors and destructors may omit it.

## Fix

Add the return type after the parameters: `function greet(string $name): void`. Write `: void` when the function returns no value.

## Example

```doria
function greet(string $name)
{
    echo "Hello, {$name}";
}

function main(): void
{
    greet("Ada");
}
```
