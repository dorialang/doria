# Missing Return Value

Title: varies

## Explanation

A function, method or closure that declares a return type must return a value of that type on every path. This error means execution can reach the end of the body without a `return`, or a `return;` gives no value.

The usual cause is an `if` that returns in one branch while the other path runs to the end of the body.

## Fix

Add a `return` with a value to each path that reaches the end. One final `return` after the last `if` is often enough.

If the function has nothing to return, declare it `void`. If it has no result in some cases, declare a nullable return type such as `?string` and return `null` in those cases.

## Example

```doria
function sign(int $value): string
{
    if ($value < 0) {
        return "negative";
    }
}

function main(): void
{
    echo sign(3);
}
```
