# Conflicting Uses Of One Value

Title: varies
Family: ownership

## Explanation

A `writable` use of a value is exclusive: while it lasts, nothing else may read or change that value. Readonly uses may overlap each other. This error means a `writable` use overlaps another use of the same value.

Arguments are evaluated from left to right, and an earlier argument stays in use until the call returns. `report($counter, $counter->increment())` reads `$counter` for the first argument and then needs `writable` access to it for the second.

A variable that holds a result borrowed from an object, such as `let $engine = $car->getEngine();`, keeps `$car` in use until the last use of `$engine`.

An assignment holds the place it assigns until its new value is computed. The value may read exactly that place, as `$this->count = $this->count + 1;` does, and any separate field, but not a place that contains it or lies inside it: `$this->left->value = measure($this->left);` passes the object that holds `$this->left->value`. An element assignment such as `$items[0] = $items[1];` holds its whole collection.

A pointer formed with `Pointer::to` or `WritablePointer::to` pins its place until the unsafe context it is formed in ends. Inside the context the program may read the pinned value and write its fields, but it cannot give the value away, assign a new value to it or to a value containing it, or pass `writable` access to any of them.

## Fix

Finish one use before the other begins. Compute the value in a statement of its own, store it in a local variable, and pass the variable: `let $next = $counter->increment();`. For an assignment, compute the value into a local first and assign the local: `let $size = measure($this->left); $this->left->value = $size;`.

When a local variable borrows from the object, move its last use before the change, or make the change first.

When a pointer pins the value, write through the pointer with `write`, write one of the value's fields, or make the change after the unsafe context ends.

## Example

```doria
class Counter
{
    writable int $count = 0;

    writable function increment(): int
    {
        $this->count += 1;
        return $this->count;
    }
}

function report(Counter $counter, int $next): void
{
    echo "{$counter->count} then {$next}";
}

function main(): void
{
    let writable $counter = new Counter();
    report($counter, $counter->increment());
}
```
