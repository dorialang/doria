# Shared-Ownership Operation Takes No Arguments

Title: varies
Family: ownership

## Explanation

The operations on the shared-ownership types take no arguments: `share()`, `createWeakReference()`, `acquire()`, `acquireReadonlyAccess()` and `acquireWritableAccess()`. This error means one of them is called with one or more arguments.

## Fix

Remove the arguments, as in `$node->createWeakReference()`.

## Example

```doria
class Node
{
    string $name = "root";
}

function main(): void
{
    let $node = shared new Node();
    let $weak = $node->createWeakReference(true);
    echo $node->name;
}
```
