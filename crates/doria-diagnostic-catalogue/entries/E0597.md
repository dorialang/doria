# Match Guard Must Be Bool

Title: fixed
Family: enums

## Explanation

A guard is the condition after `if` on a `match` arm. The arm is chosen only when its pattern matches and its guard is `true`. This error means the guard has a type other than `bool`. Doria does not treat numbers, strings or `null` as true or false.

## Fix

Write a comparison that produces a `bool`, as in `State::Ready($attempt) if $attempt > 1 => "retried"`.

## Example

```doria
enum State
{
    case Ready(int $attempt);
    case Waiting;
}

function label(State $state): string
{
    return match ($state) {
        State::Ready($attempt) if $attempt => "retried",
        State::Ready($attempt) => "ready",
        State::Waiting => "waiting",
    };
}

function main(): void
{
    echo label(State::Ready(2));
}
```
