# Grouped Bindings Share One Declared Type

Title: fixed
Family: names

## Explanation

In a grouped declaration, the type is written once, before the first variable, and applies to every variable in the group, as in `int $width, $height = 0;`. This error means a type is written again before a later variable.

## Fix

Remove the repeated type: `int $width, $height = 0;`.

When the variables need different types, write separate declarations.

## Example

```doria
function main(): void
{
    int $width, int $height = 0;
    echo $width + $height;
}
```
