# `static::` Cannot Qualify A Member

Title: varies
Family: classes

## Explanation

In PHP, `static::member` looks the member up in the class the call was made through. Doria has no late static binding. `static` is a declaration modifier only, and `self::` names the class the code is written in.

This error means a member is accessed through `static::`.

## Fix

Replace `static::` with `self::` and leave the member name as it is: `self::MAX_DEPTH`. An editor offers the replacement as a quick fix.

## Example

```doria
class Limits
{
    const MAX_DEPTH = 8;

    static function getMaxDepth(): int
    {
        return static::MAX_DEPTH;
    }
}

function main(): void
{
    echo Limits::getMaxDepth();
}
```
