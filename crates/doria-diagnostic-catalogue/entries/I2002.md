# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

A call passed checking although it gives no argument for a parameter that has no default value. The compiler found the gap when it filled in the default values for the arguments the call leaves out. Checking requires an argument for every parameter without a default, so the compiler has contradicted itself. The developer details name the callable and the position of the parameter.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the call, so keep that call and the declaration it calls, and remove the code around them.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that calls a function or method and leaves out arguments that have default values.
