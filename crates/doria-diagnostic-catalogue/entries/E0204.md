# Mutation Needs A Writable Place

Title: varies

## Explanation

The program changes something that is not a place it can write to. Two cases are common.

An argument for a `writable` parameter must be a writable variable or property, because the function changes the caller's value. A property assignment must go through a variable or a property, so `make()->count = 5` is rejected: nothing holds the object that `make()` returns.

## Fix

Pass a variable declared `writable`, as in `let writable $counter = new Counter();`.

Store the result of a call in a writable variable, then assign to its property: `let writable $counter = make();` and then `$counter->count = 5;`.

## Example

```doria
class Counter
{
    writable int $count = 0;
}

function make(): Counter
{
    return new Counter();
}

function main(): void
{
    make()->count = 5;
}
```
