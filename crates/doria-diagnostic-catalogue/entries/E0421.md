# Break Outside A Loop

Title: varies
Family: control-flow

## Explanation

`break` exits the nearest enclosing loop. This error means the `break` statement has no loop around it, for example in an `if` that stands directly in a function body.

A closure body is separate from a loop that contains the closure. `break` inside the closure cannot exit that loop.

## Fix

Move the `break` into the body of the loop it should exit. To leave the function early, use `return`.

## Example

```doria
function main(): void
{
    let $count = 3;
    if ($count > 2) {
        break;
    }
    echo $count;
}
```
