# Throw Is A Statement

Title: fixed
Family: errors

## Explanation

`throw` is a statement. It has no value, so it cannot stand where an expression is expected: as an operand of `??`, as a branch of a conditional expression, as an argument, or as the body of an arrow function.

## Fix

Write `throw $error;` as its own statement. Test the condition with `if` first and throw inside it, as in `if ($name == null) { throw new ConfigError("no name configured"); }`. Use the value on the lines after the `if`.

## Example

```doria
class ConfigError implements Error
{
    function __construct(string $message)
    {
    }
}

function nameOrFail(?string $name): string throws ConfigError
{
    return $name ?? throw new ConfigError("no name configured");
}

function main(): void
{
    echo nameOrFail("Doria");
}
```
