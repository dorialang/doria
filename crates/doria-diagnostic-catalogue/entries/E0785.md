# Unsafe Operation Outside An Unsafe Context

Title: fixed
Family: unsafe

## Explanation

An operation that needs an unsafe context is written outside one. Calling an extern declaration, an `unsafe function` or an unsafe method, and calling a C function pointer, each need one: the compiler cannot check what the foreign code or the unsafe function requires of its caller, so the program states where it takes that responsibility.

An unsafe context is an `unsafe { ... }` block or an `unsafe(<expression>)`. It covers exactly the code written inside it, and it does not extend into a closure body written inside it. The body of an `unsafe function` is an ordinary context.

## Fix

Read the declaration's Safety section, check the conditions it states, and write the operation inside `unsafe { ... }` or `unsafe(<expression>)`. Keep the unsafe context as small as the operation. Inside a closure, write the unsafe context in the closure's own body.

## Example

```doria
extern "C"
{
    /** @safety Any value is valid. */
    function abs(int32 $value): int32;
}

function main(): void
{
    echo abs(-3);
}
```
