# Missing Semicolon After Do-While

Title: varies
Family: syntax

## Explanation

A `do ... while` statement ends with `;` after its condition. This error means the closing `)` of the condition is followed by something else.

## Fix

Add `;` after the condition: `} while ($count < 3);`.

When a `finally` block follows the condition, the block ends the statement and no `;` is written: `} while ($count < 3) finally { ... }`.

## Example

```doria
function main(): void
{
    let writable $count = 0;
    do {
        $count = $count + 1;
    } while ($count < 3)
    echo $count;
}
```
