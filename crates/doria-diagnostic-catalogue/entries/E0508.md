# Type Cannot Be Tested With `is`

Title: varies
Family: nullability

## Explanation

`$value is T` tests a `mixed` or nullable value against one exact type: a numeric type, `bool`, `string`, an enum, a class or an interface. This error means the type after `is` is outside that set, for example a nullable type such as `?int` or a collection type such as `List<int>`.

## Fix

Name one of the types that `is` can test. For a nullable type, remove the `?`: a value that passes `$value is int` is never `null`.

To find out whether a nullable value is missing, compare it with `null` using `== null` or `!= null`.

## Example

```doria
function describe(mixed $value): string
{
    if ($value is ?int) {
        return "number";
    }
    return "other";
}

function main(): void
{
    echo describe(4);
}
```
