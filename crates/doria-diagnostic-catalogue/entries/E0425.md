# Concatenation Needs A String Operand

Title: varies
Family: strings

## Explanation

The `.` operator joins two values into a `string`. Each operand may be a `string`, a number or a `bool`, and at least one of the two must already be a `string`. `"x=" . 1` is valid and `1 . 2` is an error.

The same code is raised when a `foreach` over an integer range declares its value binding `writable`. A range produces a readonly value for each iteration.

## Fix

Use `+` to add two numbers. To join two numbers as text, use interpolation: `"{$major}{$minor}"`.

In a `foreach` over a range, remove `writable` from the binding. To change the number inside the loop, copy it first: `let writable $step = $index;`.

## Example

```doria
function main(): void
{
    let $major = 4;
    let $minor = 2;
    let $version = $major . $minor;
}
```
