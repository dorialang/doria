# Type Name Collision

Title: fixed
Family: names

## Explanation

Classes, interfaces, traits and enums share one set of type names. This error means two declarations of different kinds use the same name, such as a class and an enum both named `Status`.

It is also raised when an enum takes the name of a type the compiler already provides, such as `Bytes`, `String`, `Error` or `SharedReference`.

## Fix

Rename one of the declarations so that each type name is used once, then update the places that refer to it.

## Example

```doria
class Status
{
    string $label = "draft";
}

enum Status
{
    case Draft;
    case Published;
}

function main(): void
{
    let $status = new Status();
    echo $status->label;
}
```
