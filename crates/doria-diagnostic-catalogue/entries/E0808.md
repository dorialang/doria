# Handle Needs A Value Type

Title: fixed
Family: unsafe

## Explanation

A handle is an untyped `WritablePointer<Opaque>`, so `Handle::reclaim`, `Handle::borrow` and the `reclaim` and `borrow` of `SharedReference` and `WritableSharedReference` take the type of the value they give back from where the result goes: a declared local, a parameter or a return type. For `Handle` that type is a class; for a shared reference it is a reference of the same family. Reclaiming or borrowing a handle as a type other than the one it was created with is undefined behavior.

## Fix

Declare the result with its type: `Counter $counter = Handle::reclaim($handle);`, or `SharedReference<Counter> $shared = SharedReference::borrow($handle);`.

## Example

```doria
use Doria\Std\Ffi\{Handle, Opaque, WritablePointer};

class Counter
{
}

function main(): void
{
    unsafe {
        WritablePointer<Opaque> $handle = Handle::create(new Counter());
        let $counter = Handle::reclaim($handle);
    }
}
```
