# Handle Needs A Value Type

Title: fixed
Family: unsafe

## Explanation

A handle is an untyped `WritablePointer<Opaque>`, so `Handle::reclaim`, `Handle::borrow` and the `reclaim` and `borrow` of `SharedReference` and `WritableSharedReference` each declare one type parameter `T` for the value they give back. The call states it, as in `Handle::reclaim<Counter>($handle)`, or it comes from where the result goes: a declared local, a parameter or a return type. For `Handle`, `T` is a class; for a shared reference the result is a reference of the same family to `T`. Reclaiming or borrowing a handle as a type other than the one it was created with is undefined behavior.

## Fix

State the value type at the call: `let $counter = Handle::reclaim<Counter>($handle);`, or `let $shared = SharedReference::borrow<Counter>($handle);`. Or declare the result with its type: `Counter $counter = Handle::reclaim($handle);`.

## Example

```doria
use Doria\Std\Ffi\{Handle, Opaque, WritablePointer};

class Counter
{
}

function main(): void
{
    WritablePointer<Opaque> $handle = Handle::create(new Counter());
    unsafe {
        let $counter = Handle::reclaim($handle);
    }
}
```
