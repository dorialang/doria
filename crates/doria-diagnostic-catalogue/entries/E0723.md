# Class Parent Must Be A Class

Title: fixed
Family: classes

## Explanation

The type after `extends` in a class declaration must be a class. This error means it names another kind of type, such as an interface, an enum, or a built-in type like `string`.

A class has at most one direct parent, and that parent is an `open class`.

## Fix

To make the class conform to an interface, write `implements`: `class Post implements Named`. A class may have both clauses, as in `class Post extends Model implements Named`.

Otherwise name an `open class` after `extends`, or remove the clause.

## Example

```doria
interface Named
{
    function name(): string;
}

class Post extends Named
{
    function name(): string
    {
        return "post";
    }
}

function main(): void
{
    let $post = new Post();
    echo $post->name();
}
```
