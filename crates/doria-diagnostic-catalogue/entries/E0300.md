# Class Is Already Declared

Title: varies

## Explanation

Two class declarations use the same name. A class name can be declared once, so the compiler rejects the second declaration and points to the first.

## Fix

Rename one of the classes, or remove the declaration that is not needed. If both declarations describe the same thing, move their members into one class.

## Example

```doria
class Point
{
    writable int $x = 0;
}

class Point
{
    writable int $y = 0;
}

function main(): void
{
    let $point = new Point();
    echo $point->x;
}
```
