# Integer Conversion Is Out Of Range

Title: fixed
Family: runtime

## Explanation

The `from` member of an integer companion, such as `UInt8::from` or `Int32::from`, converts an integer to that type. A conversion to a narrower type, or between a signed and an unsigned type, is checked. This panic means the value is outside the range of the target type: `UInt8::from(300)` and `UInt64::from(-1)` both panic.

## Fix

Test that the value is in the range of the target type before converting, and decide what the program does when it is outside: `if ($length >= 0 and $length <= 255) { ... }`.

If the value can be that large, keep it in the wider type and change the declared type of the place that receives it.

## Example

```doria
function main(): void
{
    let $length = 300;
    uint8 $small = UInt8::from($length);
    echo $small;
}
```
