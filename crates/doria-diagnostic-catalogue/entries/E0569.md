# Duplicate Backing Value

Title: fixed
Family: enums

## Explanation

Every case of a backed enum has its own backing value. This error means two cases of the same enum declare the same value. It is reported on the later case.

## Fix

Give the case a value that no other case of the enum uses.

If the two cases mean the same thing, keep one of them.

## Example

```doria
enum Priority: int
{
    case Low = 1;
    case High = 1;
}

function main(): void
{
    echo Priority::High->value;
}
```
