# Duplicate Fully Qualified Declaration

Title: fixed
Family: names

## Explanation

Every class, enum, interface, trait, function and constant declared at the top level of a file has a fully qualified name: the namespace of the file followed by its own name, as in `App\Models\User`. A declaration in a file without a `namespace` statement is known by its own name alone. All the source files of a project, and of the packages it depends on, share one set of these names.

This error means two or more declarations have the same fully qualified name, whatever their kinds. The report marks the first one and lists the others.

## Fix

Rename one of the declarations, or move one into another namespace by changing the `namespace` statement of its file and moving the file to the matching folder. Import the one you mean with `use`, as in `use Mail\greeting;`.

If the two are copies of the same declaration, delete one.

## Example

No single source file raises this code: it is reported when a project is checked, for example with `baton check`, where the declarations of every file are compared. Two functions with the same name are also reported there as E0308 at the second declaration, and a file checked alone with `doriac check` reports only that second error.
