# Static Property Needs An Initializer

Title: varies
Family: classes

## Explanation

A static property belongs to its class and exists once for the whole program. Its first value is fixed when the program is compiled, so the declaration carries an initializer that is a constant expression. This error means a static property is declared without an initializer.

## Fix

Add an initializer built from literals, constants and operators: `static writable int $total = 0;`. A `writable` static property can be assigned a different value later through the class name, as in `Counter::total = 1;`.

## Example

```doria
class Counter
{
    static writable int $total;
}

function main(): void
{
    Counter::total = 1;
    echo Counter::total;
}
```
