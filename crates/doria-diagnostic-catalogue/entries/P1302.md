# Byte Buffer Allocation Failed

Title: fixed
Family: runtime

## Explanation

The program asked for a byte buffer and the runtime could not get the memory for it. `Bytes::allocate`, `Bytes::fromArray`, `read_file_bytes` and `read_stdin_bytes` each create a buffer and can end with this panic.

The usual cause is a length far larger than intended, for example one computed from unchecked input. The panic also occurs when the machine has no memory left for a buffer of ordinary size.

## Fix

Check a computed length against a limit the program can justify before passing it to `Bytes::allocate`.

For large data, allocate one buffer of a fixed size and work through the data in parts.

## Example

```doria
function main(): void
{
    let $buffer = Bytes::allocate(9223372036854775807);
    echo $buffer->length;
}
```
