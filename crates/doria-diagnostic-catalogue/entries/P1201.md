# String Slice Length Cannot Be Negative

Title: fixed
Family: runtime

## Explanation

`String::slice($text, $start, $length)` returns at most `$length` graphemes of `$text`, beginning at `$start`. The length is a count, so it cannot be negative. This panic means a negative length reached the call when the program ran.

## Fix

Pass a length of zero or more. Zero gives an empty string, and a length past the end of the text gives the text up to its end. When the length is calculated, test it before the call.

To take the rest of the text, leave the length out: `String::slice($title, 2)`. To count from the end, use a negative start: `String::slice($title, -3)` gives the last three graphemes.

## Example

```doria
function main(): void
{
    let $title = "Doria";
    let $length = 2 - 5;
    echo String::slice($title, 0, $length);
}
```
