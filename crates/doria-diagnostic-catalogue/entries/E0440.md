# Unary Operator Does Not Accept This Operand

Title: varies
Family: types

## Explanation

Unary `-` negates a signed integer or a float. Unary `~` inverts the bits of an integer. This error means the operand has another type: `-` is applied to a `string`, a `bool` or an unsigned integer such as `uint8`, or `~` is applied to a value that has no integer type, such as a `float`.

## Fix

Convert an unsigned integer to a signed type first: `-Int::from($level)`. Parse text before negating it: `-(Int::parse($text) ?? 0)`.

To invert a `bool`, use `!` or `not`.

## Example

```doria
function main(): void
{
    uint8 $level = 3;
    let $below = -$level;
}
```
