# Test Body Closure Takes No Parameters

Title: varies
Family: testing

Example source: development

## Explanation

The body closure of `describe`, `it` and `test` has no parameters. Nothing passes arguments to a test when `baton test` runs it, so a parameter would have no value.

This error means the closure declares one or more parameters.

## Fix

Remove the parameters and declare the values inside the body, as in `let $left = 1;`.

To run the same checks with several values, put the checks in a function that takes the value, and call that function once for each value from the body of the test.

## Example

```doria
use Doria\Std\Test\{it, expect};

it("adds two numbers", function (int $left): void {
    expect($left + 1)->toEqual(2);
});
```
