# Behavioral Test Declaration Requires Two Arguments

Title: fixed
Family: testing

Example source: development

## Explanation

`describe`, `it` and `test` from `Doria\Std\Test` declare the tests that `baton test` runs. Each takes exactly two arguments: a description string, then a closure that holds the body.

This error means a declaration has fewer or more than two arguments. The usual cause is a description written with no body.

## Fix

Write both arguments: `it("adds two numbers", function (): void { ... });`. A test that has no checks yet takes an empty closure, `function (): void {}`, and `baton test` reports it as passed.

Remove any argument that follows the closure.

## Example

```doria
use Doria\Std\Test\it;

it("adds two numbers");
```
