# Catch Cannot Match An Error From This Try

Title: fixed
Family: errors

## Explanation

A `catch` clause handles errors thrown inside its `try` block. This error means nothing in the block can throw the named error: the block has no `throw` of that type and calls nothing whose `throws` clause lists it.

An error thrown in another `catch` body or in the `finally` block of the same `try` is outside the `try` block, and these clauses do not cover it.

## Fix

Remove the `catch` clause, and remove the `try` if no clause remains.

If a call inside the block is meant to throw the error, check that the called function throws it and lists it in its `throws` clause.

## Example

```doria
class ParseError implements Error
{
    function __construct(string $message)
    {
    }
}

function measure(string $text): int
{
    return $text->length;
}

function main(): void
{
    try {
        echo measure("abc");
    } catch (ParseError $error) {
        echo $error->message;
    }
}
```
