# Grouped Declaration Cannot Have A Trailing Comma

Title: fixed
Family: names

## Explanation

In a grouped declaration, every comma is followed by another variable. This error means the last comma is followed by `=`.

## Fix

Remove the comma before `=`, or write the missing variable after it.

## Example

```doria
function main(): void
{
    let $width, $height, = 0;
    echo $width + $height;
}
```
