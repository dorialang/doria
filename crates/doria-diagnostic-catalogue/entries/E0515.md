# Positional Argument After Named Argument

Title: varies
Family: functions

## Explanation

A call may pass arguments by position, by name, or both. Positional arguments come first. Once a call names an argument, as in `name: "notes"`, every argument after it is named too. The same rule applies to the arguments of an attribute.

## Fix

Move the positional arguments ahead of the named ones, as in `save("notes", size: 12)`, or name the remaining arguments, as in `save(name: "notes", size: 12)`. Named arguments may be written in any order.

## Example

```doria
function save(string $name, int $size): void
{
    echo "{$name}: {$size}";
}

function main(): void
{
    save(name: "notes", 12);
}
```
