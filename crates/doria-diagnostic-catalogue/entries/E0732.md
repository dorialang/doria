# Parent Constructor Call Is Required

Title: fixed
Family: classes

## Explanation

The parent class has a constructor with at least one parameter that has no default value, so a subclass has to supply those arguments. This error means the subclass declares no constructor, or its constructor never calls `parent::__construct(...)`.

## Fix

Declare `__construct` in the subclass and make `parent::__construct(...)` its first statement, passing every required argument.

## Example

```doria
open class Shape
{
    function __construct(string $name)
    {
    }
}

class Square extends Shape
{
    function __construct(int $side)
    {
    }
}

function main(): void
{
    let $square = new Square(2);
    echo $square->side;
}
```
