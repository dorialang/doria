# Return Type Mismatch

Title: varies

## Explanation

A `return` statement gives a value whose type differs from the return type that the function, method or closure declares. Doria performs no implicit conversions, so an `int` cannot be returned as a `string`, and a `?string` cannot be returned as a `string`.

## Fix

Return a value of the declared type, or change the declared return type. To turn a number into text, use interpolation: `"{$count}"`. To turn text into a number, use the companion of the target type, for example `Int::parse($text)`, which gives `?int`.

When the value is nullable and the return type is not, supply a fallback with `??` or test for `null` first.

## Example

```doria
function label(): string
{
    return 42;
}

function main(): void
{
    echo label();
}
```
