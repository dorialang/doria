# Increment Target Is Not A Number

Title: varies
Family: types

## Explanation

`$count++;` and `$count--;` are statements that add one to, or subtract one from, a writable variable or property. The target must be an integer or a float. This error means the target has another type, such as `string` or `bool`.

## Fix

Use `++` and `--` on a number. If a string holds a number, parse it with `Int::parse($text)`, which gives `?int`, and keep the result in a writable `int` variable.

To make a string longer, assign the new text: `$name = $name . "!";`.

## Example

```doria
function main(): void
{
    let writable $name = "Ada";
    $name++;
    echo $name;
}
```
