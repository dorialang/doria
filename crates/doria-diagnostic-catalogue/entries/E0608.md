# When Must Produce A Value

Title: varies
Family: control-flow

## Explanation

`when` is the value-returning form of `if`. Each branch produces the result with `return expression;`, which completes the `when` and leaves the enclosing function running.

This error means a branch has a bare `return;`, returns the result of a call that returns `void`, or the `when` names `void` as its result type.

## Fix

Return a value from the branch: `return "many";`. Every branch returns a value of the one result type.

When no value is needed, use an `if` statement.

## Example

```doria
function main(): void
{
    int $count = 3;
    let $label = when ($count > 1) {
        return;
    } else {
        return "one";
    };
    echo $label;
}
```
