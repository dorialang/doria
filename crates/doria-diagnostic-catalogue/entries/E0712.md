# Test Module Requires Development Source

Title: fixed
Family: testing

## Explanation

`expect`, `fail` and `AssertionError` from `Doria\Std\Test` are the assertion part of the testing module. They are available only in development source: the files that a Baton project maps under `[autoload-dev.namespaces]` in `Baton.toml`. Development source does not enter release artifacts.

This error means main source calls `expect` or `fail`, or names the type `AssertionError`. The files mapped under `[autoload.namespaces]` are main source, and so is a file given directly to `doriac check`.

## Fix

Move the assertion into a test in a development source file, inside the body of an `it` or `test` declaration, and run it with `baton test`. A development source directory is declared in `Baton.toml` with an entry such as `"App\\Tests\\" = "tests/"` under `[autoload-dev.namespaces]`.

If the program itself must check the condition, write an ordinary `if` in main source.

## Example

```doria
use Doria\Std\Test\expect;

function main(): void
{
    let $total = 1 + 1;
    expect($total)->toEqual(2);
}
```
