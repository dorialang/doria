# Error Message Property Must Be String

Title: fixed
Family: errors

## Explanation

The `Error` interface requires the `message` property to have type `string`. This error means the class declares `message` with another type, such as `int` or `?string`.

## Fix

Declare the property as `string $message`.

Keep other data, such as a numeric code, in a property of its own. An error class may have any number of properties besides `message`.

## Example

```doria
class ParseError implements Error
{
    function __construct(int $message)
    {
    }
}

function main(): void
{
    let $error = new ParseError(12);
    echo $error->message;
}
```
