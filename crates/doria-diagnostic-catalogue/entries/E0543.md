# Shared-Ownership Type Cannot Be Constructed With `new`

Title: varies
Family: ownership

## Explanation

Of the six shared-ownership types, only `WritableSharedReference` is constructed with `new`. This error means `new` names one of the other five: `SharedReference`, `WeakReference`, `WritableWeakReference`, `ReadonlySharedReferenceAccess` or `WritableSharedReferenceAccess`. Each of them comes from an operation on a value that already exists.

## Fix

Construct a `SharedReference<T>` with `shared new T(...)`.

Get a `WeakReference<T>` or a `WritableWeakReference<T>` by calling `createWeakReference()` on the shared reference. Get an access object by calling `acquireReadonlyAccess()` or `acquireWritableAccess()` on a `WritableSharedReference<T>`.

## Example

```doria
class Node
{
    string $name = "root";
}

function main(): void
{
    let $node = new SharedReference(new Node());
    echo $node->name;
}
```
