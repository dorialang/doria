# Grouped Bindings Share One Mutability Mode

Title: fixed
Family: names

## Explanation

In a grouped declaration, `writable` is written once, before the first variable, and applies to every variable in the group. This error means `writable` or `readonly` is written before a later variable.

## Fix

To make the whole group writable, move `writable` to the front: `let writable $width, $height = 0;` or `writable int $width, $height = 0;`.

If only some of the variables are writable, declare them separately.

## Example

```doria
function main(): void
{
    let $width, writable $height = 0;
    $height = 3;
    echo $width + $height;
}
```
