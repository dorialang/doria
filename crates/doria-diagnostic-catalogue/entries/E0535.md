# Type Argument Does Not Satisfy Constraint

Title: varies
Family: generics

## Explanation

A type parameter may carry a constraint, as in `<T implements Comparable>`. Every type used for that parameter must implement the named interface. This error means a type argument does not. The type argument is written in a type such as `Box<float>`, or it is inferred from the arguments of a call.

Integers, `bool` and `string` satisfy `Comparable`, `Hashable` and `Equatable`. `float` is neither `Comparable` nor `Hashable`. A class satisfies a constraint when it declares the interface with `implements`.

## Fix

Use a type that implements the constraint, or add `implements` and the required methods to the class used as the type argument.

If the constraint is stricter than the code needs, remove it from the declaration.

## Example

```doria
function largest<T implements Comparable>(T $first, T $second): T
{
    return $first;
}

function main(): void
{
    echo largest(1.5, 2.5);
}
```
