# Getter Does Not Satisfy Its Borrowed Result Contract

Title: fixed
Family: interfaces

## Explanation

`borrowed get` declares that a getter lends a value the object already holds. The caller reads that value, and the object keeps owning it. An ordinary `get` gives the caller a value that the caller owns.

This error means a getter declared `borrowed get` returns a value that the object does not hold, such as an object created inside the getter. The rule applies to class instances, collections and other values that have one owner. Values that are copied, such as `int` and `string`, are not affected.

## Fix

Return a value stored in the object, for example another property: `borrowed get => $this->first;`.

When the getter is meant to create a value for the caller to own, remove `borrowed` and write `get`.

## Example

```doria
class Book
{
    function __construct(string $title) {}
}

class Shelf
{
    Book $featured {
        borrowed get => new Book("Doria");
    }
}

function main(): void
{
    let $shelf = new Shelf();
    echo $shelf->featured->title;
}
```
