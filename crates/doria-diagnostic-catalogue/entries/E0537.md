# Type Parameter Constraints Do Not Guarantee This Operation

Title: varies
Family: generics

## Explanation

Inside a generic function or class, a value whose type is a type parameter supports only what the constraints on that parameter guarantee. This error means the code uses such a value in a way that no constraint covers.

The operation is one of these: a comparison with `==` or `!=`, a method call, a property read, or use of the type parameter as a `Dictionary` key, a `Set` element, or an element of an ordered collection such as `SortedSet` or `PriorityQueue`.

## Fix

Declare the constraint that provides the operation, in the angle brackets that declare the type parameter. `<T implements Equatable>` allows `==` and `!=`. `<T implements Hashable>` allows a `Dictionary` key or a `Set` element. `<T implements Comparable>` allows an ordered collection.

For a method or a property, name an interface that declares it, for example `<T implements Displayable>` for `toString`. Separate several constraints with commas: `<T implements Equatable, Hashable>`.

## Example

```doria
function same<T>(T $left, T $right): bool
{
    return $left == $right;
}

function main(): void
{
    echo same(1, 2);
}
```
