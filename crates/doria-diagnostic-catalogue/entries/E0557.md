# Property Is Not A Method

Title: fixed
Family: collections

## Explanation

Collections expose their state as properties, which are read without parentheses. `count` and `isEmpty` are properties of every named collection. So are `first` and `last` on `List`, `Set` and `SortedSet`, `keys` and `values` on `Dictionary` and `SortedDictionary`, `peek` on `PriorityQueue`, `peekFront` and `peekBack` on `Deque`, and `length` on a typed array.

This error means one of these properties is written as a call, as in `$names->count()`.

## Fix

Remove the parentheses: `$names->count`.

When the call uses a name from another language, such as `size()`, the message names the Doria property. Write that property without parentheses.

## Example

```doria
function main(): void
{
    List<string> $names = ["Ada", "Grace"];
    echo $names->count();
}
```
