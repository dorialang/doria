# Wrong Number Of Arguments To A Built-In Function

Title: varies
Family: functions

## Explanation

Each built-in I/O function takes a fixed number of arguments. `read_file` and `write_stderr` take one. `write_file` and `append_file` take two, the path and the contents. `read_line` takes none or one, the prompt. This error means the call passes too few or too many.

## Fix

Pass the arguments the function declares, for example `write_file($path, $contents)`. To write several values, build one string by interpolation and pass that.

## Example

```doria
function main(): void
{
    write_file("notes.txt");
}
```
