# Callee Takes No Type Arguments

Title: fixed
Family: generics

## Explanation

A call may state its type arguments between `<` and `>` after the callee's name, as in `first<int>($values)`, when the function or method declares type parameters. This error means the callee declares none, so the list has nothing to fill.

`<` and `>` after a name are read as comparisons when a name between them is a value, such as a constant. This error appears only when every name between them is a type.

## Fix

Remove the type arguments: `plain($value)`.

## Example

```doria
function plain(int $value): int
{
    return $value;
}

function main(): void
{
    echo plain<int>(1);
}
```
