# Explicit Type Or Constructor Required

Title: varies
Family: collections

## Explanation

The expression does not tell the compiler how to build the value or which type it has. There are two cases.

A bracket literal builds a `List`, a `Dictionary` or a typed array. `SortedSet`, `SortedDictionary`, `PriorityQueue` and `Deque` have no literal form, so a bracket literal cannot be assigned to a variable of one of those types.

A generic call infers each type parameter from its arguments. `null` and a call to a `void` function carry no type, so passing either one for a parameter whose type is a type parameter leaves that type parameter unknown.

## Fix

Wrap the literal in the `from` constructor of the collection type: `SortedSet::from([3, 1, 2])`, `SortedDictionary::from(["Ada" => 36])`, `PriorityQueue::from([3, 1, 2])` or `Deque::from([1, 2, 3])`.

For a generic call, pass an argument that has a type. To pass an empty value, declare a nullable variable and pass the variable: `?int $missing = null;`.

## Example

```doria
function main(): void
{
    Deque<int> $pending = [1, 2, 3];
    echo $pending->count;
}
```
