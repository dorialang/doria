# Enum Cannot Be Compared With Its Backing Type

Title: fixed
Family: enums

## Explanation

An enum value is compared only with a value of the same enum. This error means `==` or `!=` has an enum on one side and a value that is not an enum on the other, such as an `int` or a `string`.

Doria has no implicit conversion between a backed enum and its backing type, so `Priority::Low == 1` is rejected even when `Low` is backed by `1`.

## Fix

Compare with a case: `$priority == Priority::Low`.

To compare the backing value, read it through the `value` property: `$priority->value == 1`.

## Example

```doria
enum Priority: int
{
    case Low = 1;
    case High = 10;
}

function main(): void
{
    Priority $priority = Priority::Low;
    echo $priority == 1 ? "low" : "high";
}
```
