# Attribute Argument Must Be Const Evaluable

Title: fixed
Family: projects

## Explanation

Applying an attribute runs no code. Each argument is worked out when the program is compiled and recorded as metadata, so it must be a constant expression: a literal, a constant, an enum case, or an expression built from these.

This error means an argument needs the running program to produce its value. A call to a function or to a static method is rejected, even when it would return the same value every time.

## Fix

Write the value as a literal, or declare it with `const` and name the constant in the attribute, as in `const POSTS_PATH = "/posts";` and `#[Route(POSTS_PATH)]`.

## Example

```doria
#[Attribute]
class Route
{
    function __construct(string $path)
    {
    }
}

function defaultPath(): string
{
    return "/posts";
}

#[Route(defaultPath())]
function listPosts(): void
{
    echo "posts";
}

function main(): void
{
    listPosts();
}
```
