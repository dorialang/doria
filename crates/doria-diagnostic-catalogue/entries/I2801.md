# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

The compiler could not turn a `match` expression that passed checking into executable code. Either its record of how the `match` is decided was missing or disagreed with the compiled result type, or the pattern of an arm did not fit the value being matched: an enum case against a value that is not an enum, a class pattern that names no class, a `null` or type pattern against a value that is neither nullable nor `mixed`, payload bindings against an enum without payloads, or a constant with no exact comparison.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the `match` or the pattern when it has a location for it, so keep that `match` and the declarations its patterns name, and remove the code around them.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that uses `match`.
