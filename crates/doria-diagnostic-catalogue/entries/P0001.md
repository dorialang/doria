# Syntax Error

Title: varies

## Explanation

The parser reached text that cannot continue the program at that point. The message says what it expected, such as an expression, a `;`, or a closing bracket. One mistake can produce further errors on later lines, so start with the first one reported.

## Fix

Read the first error and look at the marked position and the text before it. Common causes are a missing `;` at the end of the previous statement, an unclosed `(`, `[` or `{`, a value left out after `=`, and a keyword used as a name.
