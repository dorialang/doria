# Generic Type Arguments Cannot Be Resolved

Title: varies
Family: generics

## Explanation

Each use of a generic function, class or enum is compiled for the concrete type arguments it is used with. This error means the compiler cannot settle those type arguments. There are two cases.

A generic declaration refers to itself with a larger type argument at every step, such as a class `Chain<T>` with a property of type `?Chain<List<T>>`, or a function `grow<T>` that calls itself with `[$value]`. `Chain<int>` needs `Chain<List<int>>`, which needs `Chain<List<List<int>>>`, and the series has no end.

A declaration without a type is initialized from an empty source, as in `let $pending = Deque::from([]);`. An empty literal has no element to take the element type from.

## Fix

Keep a recursive reference at the same type arguments, as in `?Chain<T> $next`. If the type has to change, make that step outside the declaration that refers to itself.

Give an empty collection its type in the declaration: `Deque<int> $pending = Deque::from([]);`.

## Example

```doria
class Chain<T>
{
    ?Chain<List<T>> $next = null;
}

function main(): void
{
    let $chain = new Chain<int>();
}
```
