# Override Parameter Is Not Valid Here

Title: fixed
Family: classes

## Explanation

In the constructor of a derived class, `override` before a parameter says that the parameter supplies a property inherited from the parent. This error means `override` appears on a parameter of an ordinary function or method, which has no inherited property to refer to.

## Fix

Remove `override` from the parameter. To replace an inherited method, write `override` before `function`.

## Example

```doria
function greet(override string $name): void
{
    echo "Hello, {$name}";
}

function main(): void
{
    greet("Ada");
}
```
