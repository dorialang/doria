# Setter Input Type Must Match The Property

Title: fixed
Family: interfaces

## Explanation

The parameter of a `set` hook receives the value being assigned to the property, so its type is the property's type exactly. This error means the parameter declares a different type, for example `?string` on a `string` property or `int` on a `float` property.

A setter does not widen what can be assigned to the property, and it performs no conversion from another type.

## Fix

Declare the setter parameter with the property's type: `set (string $value) => ...;`.

To accept another type, add a method that takes that type, converts the value, and assigns the property.

## Example

```doria
class Profile
{
    internal writable string $stored = "";

    writable string $name {
        get => $this->stored;
        set (?string $value) => $this->stored = $value ?? "anonymous";
    }
}

function main(): void
{
    let writable $profile = new Profile();
    $profile->name = "Ada";
    echo $profile->name;
}
```
