# Wrong Number Of Arguments

Title: varies

## Explanation

A call passes more or fewer arguments than the function, method or constructor accepts. Every parameter without a default value needs an argument, and a call cannot pass more arguments than there are parameters.

## Fix

Compare the call with the declaration, then add the missing arguments or remove the extra ones. If an argument should be optional, give its parameter a default value in the declaration.

## Example

```doria
function add(int $left, int $right): int
{
    return $left + $right;
}

function main(): void
{
    echo add(1);
}
```
