# Different Enum Types Cannot Be Compared

Title: fixed
Family: enums

## Explanation

`==` and `!=` on enum values require both operands to have the same enum type. Each enum is its own type, so cases of two different enums are never compared, even when their names or their backing values are the same. The rule is the same for nullable enum values.

## Fix

Compare values of the same enum.

If both enums are backed and the backing values are what the program means to compare, compare the `value` properties: `$status->value == $signal->value`.

## Example

```doria
enum Status
{
    case Ready;
}

enum Signal
{
    case Ready;
}

function main(): void
{
    Status $status = Status::Ready;
    echo $status == Signal::Ready ? "ready" : "waiting";
}
```
