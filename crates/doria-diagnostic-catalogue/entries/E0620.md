# Duplicate Throws Entry

Title: fixed
Family: errors

## Explanation

A `throws` clause names each checked error once. This error means the same type appears twice in one clause.

## Fix

Remove the repeated entry. An editor offers the removal as a quick fix.

## Example

```doria
class ParseError implements Error
{
    function __construct(string $message)
    {
    }
}

function parse(string $text): int throws ParseError, ParseError
{
    if ($text == "") {
        throw new ParseError("empty input");
    }
    return $text->length;
}

function main(): void
{
    try {
        echo parse("abc");
    } catch (ParseError $error) {
        echo $error->message;
    }
}
```
