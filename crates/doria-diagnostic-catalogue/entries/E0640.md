# Reserved Standard-Library Type

Title: fixed
Family: names

## Explanation

The types of the standard library belong to namespaces under `Doria\Std`, such as `Doria\Std\Io`, `Doria\Std\Time`, `Doria\Std\Concurrency` and `Doria\Std\Term`. The compiler provides them, and a program cannot declare them again.

This error means a file in one of those namespaces declares a class, interface, trait or enum under the name of a standard-library type, for example `Duration` in `Doria\Std\Time`.

## Fix

Declare the type in a namespace of your own, such as `namespace App\Time;`. There it may keep its name. Or keep the namespace and choose a name the standard library does not use.

To use the standard-library type, remove the declaration and import the type: `use Doria\Std\Time\Duration;`.

## Example

```doria
namespace Doria\Std\Time;

class Duration
{
    function __construct(int $seconds)
    {
    }
}

function main(): void
{
    let $pause = new Duration(5);
    echo $pause->seconds;
}
```
