# Missing Safety Section

Title: fixed
Family: unsafe

## Explanation

This warning means an `unsafe function` or an extern declaration does not state what its callers must uphold. Its Safety section, the `@safety` tag of the documentation comment before the declaration, states the conditions a caller checks before calling it, and an editor shows it at every call. A Safety section on an `extern "C"` block's comment covers every declaration in the block.

## Fix

Write `/** @safety ... */` before the declaration with the conditions, such as which pointers must be valid and for how long.

## Example

```doria
unsafe function release(int $address): void
{
}

function main(): void
{
}
```
