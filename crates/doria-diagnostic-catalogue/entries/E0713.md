# Expect Takes One Positional Argument

Title: varies
Family: testing

Example source: development

## Explanation

`expect` from `Doria\Std\Test` begins an expectation. It takes exactly one argument, the value under test, and that argument has no name. The value to compare against belongs to the matcher that ends the chain.

This error means `expect` is called with no argument, with more than one, or with a named argument such as `expect(value: $total)`.

## Fix

Pass the value under test alone and give the expected value to the matcher: `expect($total)->toEqual(2);`.

An expectation takes no message. To fail a test with a message of your own, call `fail("the sum is wrong");`.

## Example

```doria
use Doria\Std\Test\{it, expect};

it("adds two numbers", function (): void {
    expect(1 + 1, "the sum is wrong")->toEqual(2);
});
```
