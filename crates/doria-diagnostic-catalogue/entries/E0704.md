# Test Description Must Be A Const-Evaluable String

Title: fixed
Family: testing

Example source: development

## Explanation

The first argument of `describe`, `it` and `test` is the description. The compiler records it when the project is compiled, and `baton test` prints it and matches it against `--filter`. The description is a string the compiler can work out without running the program: a string literal, a `const string`, or a concatenation of those.

This error means the description is something else, such as a call to a function or a value that is not a string.

## Fix

Write the description as a string literal: `it("adds two numbers", function (): void { ... });`.

To share text between descriptions, declare a constant, as in `const string SUITE = "Calculator";`, and pass the constant or a concatenation such as `SUITE . " adds"`.

## Example

```doria
use Doria\Std\Test\{it, expect};

function label(): string
{
    return "adds two numbers";
}

it(label(), function (): void {
    expect(1 + 1)->toEqual(2);
});
```
