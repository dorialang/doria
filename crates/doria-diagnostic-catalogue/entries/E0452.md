# Format String Is Not A Literal

Title: varies
Family: strings

## Explanation

The compiler checks the format of `printf` and `sprintf` against the arguments that follow it, so the format must be a string literal written directly in the call. This error means the first argument is a variable, a call, a concatenation or an interpolated string.

## Fix

Write the format as a literal in the call and pass the parts that change as arguments after it: `printf("%d items", $count);`.

To build text from values without a format, use interpolation: `echo "{$count} items";`.

## Example

```doria
function main(): void
{
    let $format = "%d items";
    printf($format, 3);
}
```
