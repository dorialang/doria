# Unreachable Match Arm

Title: fixed
Family: enums

## Explanation

Arms are tested in order, and an arm that can never be chosen is an error. `default` matches every remaining value, so it is the last arm, and nothing after it is reachable. A `default` is itself unreachable when the earlier arms already cover every value, such as every case of an enum or both `true` and `false`.

An arm is also unreachable when its `if` guard is always `false`, or when its type pattern names the type the matched value already has.

## Fix

Remove the arm that cannot be chosen. Keep `default` as the last arm, and leave it out when the other arms cover every value.

## Example

```doria
enum Status
{
    case Draft;
    case Published;
}

function label(Status $status): string
{
    return match ($status) {
        Status::Draft => "draft",
        Status::Published => "published",
        default => "unknown",
    };
}

function main(): void
{
    echo label(Status::Draft);
}
```
