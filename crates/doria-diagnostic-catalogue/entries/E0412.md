# Readonly Property Is Already Initialized

Title: varies

## Explanation

A property without `writable` is readonly. A constructor gives it a value once, and it keeps that value. This error means a constructor assigns to a readonly property that already has its value on that path.

A constructor parameter that becomes a property initializes that property. In a constructor that takes `string $name`, an assignment to `$this->name` in the body is a second initialization.

## Fix

Keep one assignment. If the value depends on a condition, work it out in a local variable and assign the property once.

Declare the property `writable` if it is meant to change. If a constructor parameter is an input only and should not become a property, mark it with `parameter`.

## Example

```doria
class Person
{
    string $name;

    function __construct(parameter string $given)
    {
        $this->name = $given;
        $this->name = "unknown";
    }
}

function main(): void
{
    let $person = new Person("Ada");
    echo $person->name;
}
```
