# Boolean Operator Requires Boolean Operands

Title: varies

## Explanation

The operators `!`, `&&` and `||`, and the word forms `not`, `and`, `or` and `xor`, work on `bool` values. This error means an operand has another type. Doria does not treat numbers, strings or `null` as true or false.

## Fix

Turn each operand into a `bool` with a comparison. Write `$count == 0` for `!$count`, and `$ready && $count > 0` for `$ready && $count`.

## Example

```doria
function main(): void
{
    int $count = 3;
    let $empty = !$count;
}
```
