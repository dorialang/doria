# Nullable Callable Must Be Narrowed

Title: fixed
Family: functions

## Explanation

A value of type `?function(...)` is either a function value or `null`. This error means the program calls such a value while it may still be `null`.

## Fix

Test the value before the call. Inside `if ($transform != null) { ... }` the value has the function type and can be called.

If a function value is always supplied, remove `?` from the declared type.

## Example

```doria
function apply(?function(int): int $transform, int $value): int
{
    return $transform($value);
}

function main(): void
{
    echo apply(null, 21);
}
```
