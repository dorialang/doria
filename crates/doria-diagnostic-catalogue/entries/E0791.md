# Foreign Symbol Needs A Link Name

Title: fixed
Family: unsafe

## Explanation

A foreign declaration's Doria name is its symbol, and this name is a compiler intrinsic such as `printf` or `read_line`, which no declaration can use. The declaration needs its own Doria name and `#[LinkName]` to name the symbol.

## Fix

Rename the declaration and name the symbol with `#[LinkName("printf")]`. A variadic function also takes `#[Variadic(fixedParameters: ...)]`, one binding per argument list used.

## Example

```doria
use Doria\Std\Ffi\{CChar, Pointer};

extern "C"
{
    /** @safety `$format` points to a NUL-terminated format. */
    function printf(Pointer<CChar> $format): int32;
}

function main(): void
{
}
```
