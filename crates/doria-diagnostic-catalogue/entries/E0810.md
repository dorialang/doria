# Foreach Source Is Not Iterable

Title: fixed
Family: collections

## Explanation

`foreach` walks integer ranges such as `0..<10`, typed arrays `T[]`, the collections (`List<T>`, `Dictionary<K, V>`, `SortedDictionary<K, V>`, `Set<T>`, `SortedSet<T>` and `Deque<T>`), byte and typed array regions, and values of classes that implement `Iterable<T>`. A value of any other type has no elements for `foreach` to give, so the loop cannot be built.

## Fix

Walk one of the iterable sources instead. For a value with elements, walk a region of them, as in `foreach ($numbers->getRegion(0, 3) as int $number)`, or loop with `for` over an index. For a class you own, implement `Iterable<T>`.

## Example

```doria
function main(): void
{
    let $count = 3;
    foreach ($count as int $value) {
        echo $value;
    }
}
```
