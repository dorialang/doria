# String Result Is Too Large

Title: fixed
Family: runtime

## Explanation

A string operation was asked for a result longer than a string can be. It is raised by operations that build a new string, such as `String::repeat`, `String::padStart` and `String::padEnd`, when the length of the result is beyond what the runtime can represent.

The usual cause is a count or a length that is far larger than intended, for example a value taken from input without a check.

## Fix

Find where the count or length comes from and correct it. Test values that come from input against a limit the program chooses before using them to build a string.

## Example

```doria
function main(): void
{
    let $width = 9223372036854775807;
    let $rule = String::repeat("-=-", $width);
    echo $rule;
}
```
