# Handle Holds A Class Value

Title: fixed
Family: unsafe

## Explanation

`Handle::create` hands an owned instance of a class to C as a handle, a `WritablePointer<Opaque>` a C library keeps as user data and passes back to a callback. Handing a value over is safe; `Handle::reclaim` and `Handle::borrow`, which need an unsafe context, give that instance back. Only class instances travel this way: numbers, strings, collections, inline values and foreign structs reach C as FFI-safe values or through a pointer, and a shared value travels with `toHandle` on its `SharedReference<T>` or `WritableSharedReference<T>`.

## Fix

Pass a class instance to `Handle::create`, or wrap the value in a class: `class Settings { function __construct(int $level) {} }`, then `Handle::create(new Settings(3))`.

## Example

```doria
use Doria\Std\Ffi\Handle;

function main(): void
{
    let $handle = Handle::create(3);
}
```
