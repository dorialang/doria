# Wrong Argument Type For A Built-In Function

Title: varies
Family: types

## Explanation

The built-in I/O functions declare the type of each argument. `read_file`, `write_file`, `append_file` and `write_stderr` take `string` arguments, and so does the prompt of `read_line`. The byte functions, such as `write_file_bytes` and `write_stdout_bytes`, take their contents as `Bytes`.

This error means an argument has another type. Doria performs no implicit conversions, so a number is rejected where a `string` is declared, and so is a `?string`.

## Fix

Pass a value of the declared type. To write a number as text, interpolate it: `write_stderr("{$code}");`. For a nullable string, supply a fallback with `??` or test for `null` first.

## Example

```doria
function main(): void
{
    write_stderr(404);
}
```
