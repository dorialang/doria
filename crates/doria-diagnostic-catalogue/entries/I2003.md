# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

A constant value passed checking, and the compiler then found that the value does not fit the type of the place that receives it in the compiled program. The compiler meets this when it fills in a parameter's default value for an argument a call leaves out, and when it uses a constant elsewhere, such as in a `match` arm. This code covers a `null` value, an enum case, an enum case with a payload and the fields of that payload, and any other constant.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. When the report marks a call, keep that call and the declaration whose default value it uses, and remove the code around them.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that declares parameters with default values, or that uses constants and enum cases as values.
