# Invalid Parameter Default

Title: varies
Family: functions

## Explanation

A parameter default is worked out when the program is compiled, so it is a constant expression: a literal, a constant, or operators applied to them. This error means the default is something else, such as a function call, or the parameter is of a kind that takes no default.

Defaults are available for integer, float, `bool`, `string` and enum parameters, and for the nullable forms of integer, float, `bool` and enum. A `take` parameter, a `writable string` parameter, and a parameter of a move type, such as a class or a collection, take no default.

## Fix

Use a literal or a constant as the default: `int $limit = DEFAULT_LIMIT`.

When the value has to be computed while the program runs, or the parameter takes no default, make the parameter required and pass the value at each call.

## Example

```doria
function defaultLimit(): int
{
    return 25;
}

function listPosts(int $limit = defaultLimit()): void
{
    echo "Showing {$limit} posts";
}

function main(): void
{
    listPosts();
}
```
