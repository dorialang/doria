# Readonly Property May Be Initialized Twice

Title: varies
Family: classes

## Explanation

A property without `writable` is readonly, and a constructor initializes it exactly once on each path. This error means an assignment is reached by one path on which the property already has its value and by another path on which it has none. The usual shape is an assignment inside an `if`, followed by an unconditional assignment to the same property.

## Fix

Assign the property once in every branch by moving the second assignment into an `else`. Or work the value out in a local variable declared `writable`, and assign the property once after the `if`.

Declare the property `writable` if it is meant to change.

## Example

```doria
class Token
{
    string $value;

    function __construct(parameter bool $set)
    {
        if ($set) {
            $this->value = "first";
        }
        $this->value = "fallback";
    }
}

function main(): void
{
    let $token = new Token(true);
    echo $token->value;
}
```
