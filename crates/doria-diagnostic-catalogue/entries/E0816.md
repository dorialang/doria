# File Cannot Allow Unsafe Code In A Denying Package

Title: fixed
Family: unsafe

## Explanation

A package's `unsafe = "deny"` in its `Baton.toml` applies to every source of the package, and a file cannot relax it with `declare(unsafe: "allow");`. A file may deny unsafe code where its package allows it, never the reverse.

## Fix

Remove the directive. Move the unsafe code to a package that allows it, which this package can depend on, and call its safe functions from here.

## Example

No program raises this code on demand from one file: it needs a package whose `Baton.toml` sets `unsafe = "deny"`, built through its build plan. A user meets it when a file of such a package starts with `declare(unsafe: "allow");`.
