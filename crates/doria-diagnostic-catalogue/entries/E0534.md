# Default Type Arguments Are Reserved For A Later Release

Title: varies
Family: generics
Availability: later

## Explanation

A default type argument is a type written after `=` in a type parameter, as in `class History<T = string>`. It would be the type of `T` wherever `History` is used without a type argument. Doria reserves default type arguments for a later release.

Every type parameter of a class, function or method gets its type where the declaration is used: from the type arguments written there, as in `History<string>`, or, for a call, from the types of the arguments.

## Fix

Remove `=` and the type after it, leaving `class History<T>`.

Write the type argument at each use: `History<string> $words = new History<string>();`. A call to a generic function needs no type arguments, because the compiler works them out from the arguments of the call.

## Example

```doria
class History<T = string>
{
    internal writable List<T> $entries = [];

    writable function push(take T $entry): void
    {
        $this->entries->add($entry);
    }
}

function main(): void
{
    writable History<string> $words = new History<string>();
    $words->push("first");
}
```
