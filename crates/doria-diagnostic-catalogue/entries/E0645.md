# Closure Capture Needs Stronger Access

Title: varies
Family: functions

## Explanation

Each capture mode asks for a kind of access to the enclosing variable. `with (writable $value)` requires a variable declared `writable`. `with (take $value)` moves a class value into the closure, so the enclosing scope must own it; a readonly or `writable` parameter is borrowed from the caller and cannot be taken.

This error means a capture asks for access its source cannot give, or the closure body needs more than its capture provides: it changes a variable captured without `writable`, or gives away a value captured without `take`.

The same code is reported when a function value with a `take` parameter is called with an argument the caller does not own.

## Fix

For a writable capture, declare the source `writable`, as in `let writable $total = 0;`. When the body changes a captured variable, write `with (writable $total)`.

For a `take` capture, capture a local variable that owns its value, or declare the enclosing parameter `take`. When the closure only reads the value, capture it without a keyword.

## Example

```doria
function main(): void
{
    let $total = 0;
    let writable $add = function (int $amount): void with (writable $total) {
        $total += $amount;
    };
    $add(5);
    echo $total;
}
```
