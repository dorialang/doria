# Payload Case Requires Arguments

Title: fixed
Family: enums

## Explanation

A payload case declares fields, and a value of that case is constructed by giving every field an argument. This error means a payload case is named without an argument list, as in `Coordinate::Point`.

In a `match` pattern a payload case may be written without parentheses to ignore its fields. That form is a pattern and does not construct a value.

## Fix

Add the arguments, by position or by name: `Coordinate::Point(1, 2)` or `Coordinate::Point(x: 1, y: 2)`.

## Example

```doria
enum Coordinate
{
    case Origin;
    case Point(int $x, int $y);
}

function main(): void
{
    Coordinate $point = Coordinate::Point;
    echo match ($point) {
        Coordinate::Origin => 0,
        Coordinate::Point($x, $y) => $x + $y,
    };
}
```
