# Backed Enum Cannot Have Payload Cases

Title: fixed
Family: enums

## Explanation

A backed enum names `int` or `string` after its name and gives each case one constant value. A payload case declares typed fields in parentheses, as in `case Custom(string $label);`. An enum has one or the other. This error means a case with payload fields appears in a backed enum.

## Fix

To keep the payload, remove the backing type from the enum and the `= value` part from every case.

To keep the enum backed, remove the payload fields from the case.

## Example

```doria
enum Priority: int
{
    case Low = 1;
    case Custom(string $label) = 2;
}

function main(): void
{
    echo Priority::Low->value;
}
```
