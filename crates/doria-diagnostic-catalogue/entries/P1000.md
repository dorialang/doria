# Program Panicked

Title: fixed
Family: runtime

## Explanation

The program called `panic`. A panic ends the program at once with exit status 101. It cannot be caught, and no cleanup or destructor runs.

The report shows the message passed to `panic` under `Note`, and the calls that led to it under `Call Path`.

## Fix

Read the note and the call path, then correct the value or the call that led to the `panic`.

When callers are expected to handle the condition, report it another way: `throw` a class that implements `Error` from a function that declares it with `throws`, or return a nullable type and `null`.

## Example

```doria
function levelName(int $level): string
{
    if ($level < 1) {
        panic("level must be at least 1");
    }
    return "Level {$level}";
}

function main(): void
{
    echo levelName(0);
}
```
