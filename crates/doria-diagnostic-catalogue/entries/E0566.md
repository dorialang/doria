# Invalid Backing Type

Title: fixed
Family: enums

## Explanation

A backed enum gives every case a constant value of one backing type, written after the enum name: `enum Priority: int`. The backing type is exactly `int` or `string`. This error means the enum names another type, such as `float`, or a nullable type, such as `?int`.

## Fix

Change the backing type to `int` or `string` and give each case a value of that type, as in `case Low = 1;`.

If the cases need no values, remove the backing type and the values.

## Example

```doria
enum Priority: float
{
    case Low = 1.0;
    case High = 10.0;
}

function main(): void
{
    Priority $current = Priority::High;
}
```
