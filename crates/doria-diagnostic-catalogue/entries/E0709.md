# Behavioral Test Name Is Duplicated

Title: fixed
Family: testing

Example source: development

## Explanation

The full name of a test is its description, preceded by the descriptions of the `describe` groups around it and joined with ` > `, as in `Cart > when it is empty > has a total of zero`. `baton test` reports each test under its full name, so a full name is used once in a package.

This error means two `it` or `test` declarations in the same package have the same full name. They may be in different files.

## Fix

Change one of the descriptions, or place the tests in `describe` groups that have different names. The same description is allowed under two different groups.

## Example

```doria
use Doria\Std\Test\{it, expect};

it("adds two numbers", function (): void {
    expect(1 + 1)->toEqual(2);
});

it("adds two numbers", function (): void {
    expect(2 + 2)->toEqual(4);
});
```
