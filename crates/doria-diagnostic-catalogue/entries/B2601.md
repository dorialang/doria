# Performance Report Could Not Be Written

Title: fixed
Family: compiler

## Explanation

The program compiled and the executable was written. The file named by `--performance-report` could not be written, so the command ends with this error.

The compiler writes the report to a temporary file in the destination directory and then moves it into place. This code means that the directory could not be created, the temporary file could not be written, or the move failed. The operating system's reason is in the developer details.

## Fix

Pass `--performance-report` a path in a directory where the current user can create files, and keep it separate from the source file and from the `--out` path. Check that no directory named in the path is an existing file.

To read the operating system's reason, run the command again with `--diagnostic-format json` and read the `developerDetails` field, or set `DORIA_DIAGNOSTIC_DEBUG=1`.

## Example

No program raises this code on demand: it depends on the report path and on the file system, and the program plays no part in it. A user meets it when running `doriac compile` with `--performance-report` and a path that cannot be written.
