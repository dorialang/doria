# Copy Match Does Not Need Take

Title: fixed
Family: enums

## Explanation

`match (take $value)` consumes its scrutinee: ownership of the whole value moves into the match, and the variable cannot be used afterwards. Consuming applies to move values, such as a class instance or an enum that carries a class instance as a payload.

This error means the scrutinee is a Copy value, such as a number, a `string`, or an enum whose payloads are all Copy. A Copy value stays available after a match, so `take` has nothing to transfer.

## Fix

Remove `take`: `match ($state) { ... }`. The value can still be used after the match.

## Example

```doria
enum State
{
    case Ready;
    case Waiting;
}

function main(): void
{
    State $state = State::Ready;
    string $label = match (take $state) {
        State::Ready => "ready",
        State::Waiting => "waiting",
    };
    echo $label;
}
```
