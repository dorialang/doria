# Static Member Access Takes No `$`

Title: varies
Family: classes

## Explanation

Static members are accessed without `$`: `Counter::total`. The `$` belongs to the declaration, `static writable int $total = 0;`. Instance properties follow the same rule, where `string $name` is read as `$this->name`.

This error means a static property is accessed as `Counter::$total`.

## Fix

Remove the `$` from the access: `Counter::total = 5;`. An editor offers the removal as a quick fix.

## Example

```doria
class Counter
{
    static writable int $total = 0;
}

function main(): void
{
    Counter::$total = 5;
    echo Counter::total;
}
```
