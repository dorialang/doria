# Missing Format String

Title: varies
Family: strings

## Explanation

`printf` and `sprintf` take a format string as their first argument. This error means the call has no arguments.

## Fix

Pass a string literal as the first argument, followed by one argument for each conversion in it: `printf("%d items", $count);`.

To write text that needs no formatting, use `echo`.

## Example

```doria
function main(): void
{
    printf();
}
```
