# Closure Uses A Variable It Does Not Capture

Title: varies
Family: functions

## Explanation

A closure lists every variable it uses from an enclosing scope in a `with` clause. The rule is the same for arrow functions and anonymous functions, and it covers local variables, parameters of the enclosing function, and `$this` inside a method. Nothing is captured automatically.

This error means the closure body uses an enclosing variable that its `with` clause does not list. A variable used by a nested closure is listed by every closure between its declaration and its use.

## Fix

Add the variable to the `with` clause, which follows the parameter list and the return type: `fn(int $score) with ($minimum) => $score >= $minimum`. An editor offers this as a quick fix.

`with ($value)` gives the closure readonly access. Write `with (writable $value)` when the closure changes the variable, and `with (take $value)` when the closure should own it. In a method, capture the receiver with `with ($this)`.

The closure's own parameters and locals, top-level functions, constants, type names and enum cases need no capture.

## Example

```doria
function main(): void
{
    let $minimum = 70;
    let $passes = fn(int $score) => $score >= $minimum;
    echo $passes(82);
}
```
