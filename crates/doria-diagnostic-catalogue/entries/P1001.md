# Runtime Diagnostic Failed

Title: fixed
Family: runtime

## Explanation

The runtime stopped the program because one of its own checks failed, or because it could not build the report for the failure that occurred. The program exits with status 101. When the runtime knows which check failed, the report names it under `Note`.

This is a defect in Doria. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project with the program, its input and the full report, including the `Note` when there is one.

## Example

No program raises this code on demand: it appears only when the runtime meets a state that a correct compiler and runtime never produce, so a program that raises it today stops raising it once the defect is corrected. A user meets it as the last report of a running program, in place of the panic that would have named the cause.
