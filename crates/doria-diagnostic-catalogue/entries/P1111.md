# Main Returned An Invalid Process Status

Title: fixed
Family: runtime

## Explanation

The value returned by `main(): int` becomes the exit status of the process. It must be from 0 through 125. This panic means `main` returned a value outside that range, such as a negative number or a count that grew past 125. The process exits with status 101.

## Fix

Return a status from 0 through 125. Use 0 for success and a small fixed value for each kind of failure, for example `return $failures > 0 ? 1 : 0;`.

If the program has no status to report, declare `main(): void`. It exits with status 0 when it completes.

## Example

```doria
function main(): int
{
    let $failures = 200;
    return $failures;
}
```
