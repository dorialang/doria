# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

The compiler could not find, or found inconsistent, its own record of which concrete function or method a part of the program uses. This code covers generic functions and classes and their type arguments, calls through an interface and the class methods that implement it, values converted to an interface type when they are returned, methods that a child class overrides, and property hooks.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the call or declaration the compiler was working on when it has a location for it, so start there and keep the generic, interface or class declarations it refers to.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when checking, compiling or running a program that uses generics, interfaces, inheritance or property hooks.
