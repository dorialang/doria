# Parent Used Without A Parent Class

Title: varies
Family: classes

## Explanation

`parent::` names the direct parent of the class that contains it. This error means there is no such parent: the class has no `extends` clause, or `parent::` appears in a function outside any class.

## Fix

Add `extends` and the parent class to the class declaration. The parent must be declared `open class`.

If the class has no parent, call the method through `$this`. In a function outside a class, call the method on an object.

## Example

```doria
class Counter
{
    function describe(): string
    {
        return parent::describe();
    }
}

function main(): void
{
    let $counter = new Counter();
    echo $counter->describe();
}
```
