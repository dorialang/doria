# Class Allocation Failed

Title: fixed
Family: runtime

## Explanation

A `new` expression could not get the memory for the object it creates. The program was out of memory at that expression. The memory is usually held elsewhere.

## Fix

Reduce the memory the program holds at one time. Let collections and objects that are no longer needed go out of scope, and work through large inputs in parts.

If the program creates objects inside a loop or a recursion that never ends and keeps each one, correct the loop or the recursion.

## Example

No program raises this code on demand: the panic needs the machine to refuse an allocation, which depends on the memory that is free at that moment. A program meets it at a `new` expression while memory is exhausted.
