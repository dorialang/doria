# Unknown Matcher Or Wrong Matcher Arguments

Title: varies
Family: testing

Example source: development

## Explanation

The matchers are a fixed set that `Doria\Std\Test` provides: `toEqual`, `toBeNull`, `toBeTrue`, `toBeFalse`, `toBeGreaterThan`, `toBeGreaterThanOrEqual`, `toBeLessThan`, `toBeLessThanOrEqual`, `toContain`, `toStartWith`, `toEndWith`, `toBeEmpty`, `toHaveCount`, `toHaveKey`, `toHaveValue` and `toThrow`.

This error means the name after `expect(...)->` is not one of them, or a matcher is called with the wrong number of arguments or with a named argument. `fail` is checked the same way: it takes one positional argument, the message.

## Fix

Use one of the matchers listed above. Equality is `toEqual`. A matcher name from another testing library, such as `toBe`, is not accepted.

Pass matcher arguments by position. `toBeNull`, `toBeTrue`, `toBeFalse` and `toBeEmpty` take no argument. `toThrow` takes none, or one closure that inspects the error. Every other matcher takes one argument.

## Example

```doria
use Doria\Std\Test\{it, expect};

it("adds two numbers", function (): void {
    expect(1 + 1)->toBe(2);
});
```
