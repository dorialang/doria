# Default Cannot Have A Guard

Title: fixed
Family: enums

## Explanation

`default` is the arm chosen when no earlier arm matches. It is unconditional and takes no `if` guard. This error means a `default` arm is written with one.

## Fix

Move the condition into the result of `default`, as a ternary or a nested `match`: `default => $count > 100 ? "many" : "several"`.

When the condition belongs to one pattern, put the guard on an arm for that pattern before `default`.

## Example

```doria
function label(int $count): string
{
    return match ($count) {
        1 => "single",
        default if $count > 100 => "many",
    };
}

function main(): void
{
    echo label(1);
}
```
