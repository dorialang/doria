# Shared-Ownership Type Takes One Type Argument

Title: varies
Family: ownership

## Explanation

Each of the six shared-ownership types takes exactly one type argument, the type of the value it refers to, as in `SharedReference<Node>`. This error means the type is written with no type argument, or with more than one.

## Fix

Write one type argument: `SharedReference<Node>`, `WeakReference<Node>`, `WritableSharedReference<Node>`.

In a `let` declaration the type is inferred, so it can be left out: `let $node = shared new Node();`.

## Example

```doria
class Node
{
    string $name = "root";
}

function main(): void
{
    SharedReference<Node, Node> $node = shared new Node();
    echo $node->name;
}
```
