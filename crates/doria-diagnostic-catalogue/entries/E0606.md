# Given Predicate Must Be Bool

Title: fixed
Family: control-flow

## Explanation

Inside a `given` block, an expression statement is a predicate when its type is `bool` and a setup action when it is a call that returns `void`. This error means an expression statement has another type, such as `int` or `string`.

Doria has no truthiness, so a number or a string cannot gate the attached construct.

## Fix

Write a comparison that produces `bool`, such as `$limit > 0;`.

If the value is needed later, keep it in a declaration: `let $half = $limit / 2;`. Declarations come before the first predicate.

## Example

```doria
function main(): void
{
    int $limit = 10;
    given {
        $limit;
    } if ($limit > 2) {
        echo $limit;
    }
}
```
