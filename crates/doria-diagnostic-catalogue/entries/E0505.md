# Borrowed Class Value Cannot Be Replaced

Title: varies
Family: ownership

## Explanation

Some variables give access to a class instance that another place owns. The usual one is a `foreach` binding declared `writable`: it borrows each element of the collection with writable access, and the collection remains the owner of the element. Through the binding the loop body can assign the element's writable properties and call its `writable function` methods.

This error means the program assigns a different object to such a variable, as in `$counter = new Counter(0);` inside `foreach ($counters as writable Counter $counter)`.

## Fix

Change the element through the binding: assign its writable properties, as in `$counter->count = 0;`, or call a `writable function` on it.

To put a different object in the collection, assign the element through the collection, as in `$counters[$index] = new Counter(0);` inside a `for` loop over the indexes.

## Example

No program shows this code on its own: `doriac check` and `baton check` accept the program, and the code is reported when the program is compiled, by `doriac compile`, `doriac run`, `baton build` or `baton run`. A user meets it at an assignment of a new object to a `writable` `foreach` binding whose type is a class.
