# Class Must Be Open To Be Extended

Title: fixed
Family: classes

## Explanation

Classes are closed by default. A class can be a parent only when it is declared `open class`. This error means a class names a closed class after `extends`.

## Fix

Declare the parent with `open`, as in `open class Model`, if subclassing is part of its design.

If the parent is meant to stay closed, remove the `extends` clause and keep a value of that class in a property.

## Example

```doria
class Model
{
    function table(): string
    {
        return "models";
    }
}

class Post extends Model
{
}

function main(): void
{
    let $post = new Post();
    echo $post->table();
}
```
