# Array Region Is Out Of Bounds

Title: fixed
Family: runtime

## Explanation

`getRegion` or `getWritableRegion` was called on a typed array `T[]`, an `ArrayRegion<T>` or a `WritableArrayRegion<T>` with an offset and a length that do not fit inside the source. Both count elements, both must be zero or greater, and the offset plus the length must be at most the `length` of the array or region the view is taken from.

## Fix

Work out the length from the source. `$samples->getRegion($offset, $samples->length - $offset)` covers every element from `$offset` to the end.

When the offset or the length comes from data, check it against `length` before taking the region.

## Example

```doria
function main(): void
{
    int32[] $samples = [1, 2, 3, 4];
    let $tail = $samples->getRegion(2, 4);
    echo $tail->length;
}
```
