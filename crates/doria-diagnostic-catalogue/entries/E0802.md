# Pointer Conversion Needs A Target Type

Title: fixed
Family: unsafe

## Explanation

`Pointer::cast`, `WritablePointer::cast`, `Pointer::fromAddress` and `Pointer::toFunction` take the type they produce from where their result goes: a typed declaration, a parameter, a property or a return. `Pointer::cast` and `Pointer::fromAddress` need a `Pointer<T>` there, `WritablePointer::cast` a `WritablePointer<T>`, and `Pointer::toFunction` a C function pointer type such as `extern "C" function(int32): int32`. This error means the position states no type, or states one of another kind.

## Fix

Declare the result with the type the conversion produces: `Pointer<uint8> $bytes = Pointer::cast($pointer);`, `?Pointer<int32> $value = Pointer::fromAddress($address);` or `extern "C" function(int32): int32 $callback = Pointer::toFunction($address);`. A call argument takes its type from the parameter.

## Example

```doria
use Doria\Std\Ffi\{Pointer, WritablePointer};

function main(): void
{
    writable int32 $value = 3;
    unsafe {
        let $pointer = WritablePointer::to($value);
        let $bytes = Pointer::cast($pointer);
    }
}
```
