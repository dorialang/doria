# Pointer Conversion Needs A Target Type

Title: fixed
Family: unsafe

## Explanation

`Ptr::cast`, `MutPtr::cast`, `Ptr::fromAddress` and `Ptr::toFunction` take the type they produce from where their result goes: a typed declaration, a parameter, a property or a return. `Ptr::cast` and `Ptr::fromAddress` need a `Ptr<T>` there, `MutPtr::cast` a `MutPtr<T>`, and `Ptr::toFunction` a C function pointer type such as `extern "C" function(int32): int32`. This error means the position states no type, or states one of another kind.

## Fix

Declare the result with the type the conversion produces: `Ptr<uint8> $bytes = Ptr::cast($pointer);`, `?Ptr<int32> $value = Ptr::fromAddress($address);` or `extern "C" function(int32): int32 $callback = Ptr::toFunction($address);`. A call argument takes its type from the parameter.

## Example

```doria
use Doria\Std\Ffi\{MutPtr, Ptr};

function main(): void
{
    writable int32 $value = 3;
    unsafe {
        let $pointer = MutPtr::to($value);
        let $bytes = Ptr::cast($pointer);
    }
}
```
