# Pointer Conversion Needs A Target Type

Title: fixed
Family: unsafe

## Explanation

`Pointer::cast`, `WritablePointer::cast`, `Pointer::fromAddress` and `Pointer::toFunction` each declare one type parameter for the type they produce. The call states it, as in `Pointer::cast<uint8>($pointer)`, or it comes from where the result goes: a typed declaration, a parameter, a property or a return. For `cast` and `fromAddress` the type argument is the pointee; for `toFunction` it is the C function pointer type. `Pointer::cast` and `Pointer::fromAddress` need a `Pointer<T>` there, `WritablePointer::cast` a `WritablePointer<T>`, and `Pointer::toFunction` a C function pointer type such as `extern "C" function(int32): int32`. This error means the position states no type, or states one of another kind.

## Fix

State the target at the call: `Pointer::cast<uint8>($pointer)` or `Pointer::fromAddress<int32>($address)`. Or declare the result with the type the conversion produces: `Pointer<uint8> $bytes = Pointer::cast($pointer);`, `?Pointer<int32> $value = Pointer::fromAddress($address);` or `extern "C" function(int32): int32 $callback = Pointer::toFunction($address);`. A call argument takes its type from the parameter.

## Example

```doria
use Doria\Std\Ffi\{Pointer, WritablePointer};

function main(): void
{
    writable int32 $value = 3;
    unsafe {
        let $pointer = WritablePointer::to($value);
        let $bytes = Pointer::cast($pointer);
    }
}
```
