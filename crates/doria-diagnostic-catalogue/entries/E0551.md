# Initializer Cannot Create Multiple Owned Bindings

Title: fixed
Family: ownership

## Explanation

A grouped declaration such as `let $left, $right = 0;` evaluates its initializer once and copies the result into every variable. Numbers, `bool` values and strings are copied, so they can start a group.

Classes, collections, `Bytes`, `mixed` values and shared-ownership handles are owned values that move. One owned value cannot have several owners, so it cannot initialize several variables.

## Fix

Write one declaration for each variable and construct each value separately.

If the variables are meant to refer to one value, construct it with `shared new` and give each further variable its own owner with `share()`.

A group with an explicit nullable type may start empty, because there is no value to own: `?Token $left, $right = null;`.

## Example

```doria
function main(): void
{
    List<int> $left, $right = [1, 2];
}
```
