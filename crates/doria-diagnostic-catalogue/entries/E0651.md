# Callable Requires Stronger Access

Title: varies
Family: functions

## Explanation

A function type states how its values are invoked. A plain `function(...)` value can be called through any access. A `function writable(...)` value changes state it captured, so calling it requires writable access to the variable that holds it. A `function once(...)` value is used up by its call, so calling it requires an owned value.

This error means a call goes through a variable or parameter that gives less access than the function value requires. A closure with a `writable` capture that it changes is a `function writable(...)` value.

The same code is reported when a function value has a `writable` parameter and the argument passed to it is readonly. In a test, the same rule applies to the function values passed to a `toThrow` expectation.

## Fix

Declare the variable that holds the function value `writable`, as in `let writable $next = function (): int with (writable $count) { ... };`. For a parameter, write `writable` before its type: `writable function writable(): int $next`.

For a `writable` parameter of the function value, pass a variable that is declared `writable`.

## Example

```doria
function main(): void
{
    let writable $count = 0;
    let $next = function (): int with (writable $count) {
        $count += 1;
        return $count;
    };
    echo $next();
}
```
