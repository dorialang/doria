# Pointer Source Is Not A Place

Title: fixed
Family: unsafe

## Explanation

`Pointer::to` and `WritablePointer::to` give the address of a place of a type that can cross the C boundary: a local, a foreign struct field, a property or static property, or an element of a `T[]`, a `List<T>` or a typed array region. The place stays where it is until the unsafe context the pointer is formed in ends. A computed value, such as a literal or a call result, has no lasting storage of its own to address, and neither has a value inside `mixed`. A dictionary value or set member has no fixed position.

## Fix

Store the value in a local first and form the pointer to the local: `writable int32 $value = 3;` then `WritablePointer::to($value)`. To pass the elements of a `T[]` or `Bytes` to C, use a region's `pointer`.

## Example

```doria
use Doria\Std\Ffi\Pointer;

function main(): void
{
    unsafe {
        let $pointer = Pointer::to(3);
    }
}
```
