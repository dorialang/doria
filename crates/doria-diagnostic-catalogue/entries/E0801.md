# Pointer Source Is Not A Place

Title: fixed
Family: unsafe

## Explanation

`Ptr::to` and `MutPtr::to` give the address of a place: a local, a foreign struct field or a property, of a type that can cross the C boundary. The place stays where it is until the unsafe context the pointer is formed in ends. A computed value, such as a literal, a call result or an index read, has no lasting storage of its own to address.

## Fix

Store the value in a local first and form the pointer to the local: `writable int32 $value = 3;` then `MutPtr::to($value)`. To pass the elements of a `T[]` or `Bytes` to C, use a region's `pointer`.

## Example

```doria
use Doria\Std\Ffi\Ptr;

function main(): void
{
    unsafe {
        let $pointer = Ptr::to(3);
    }
}
```
