# Pending Request Cannot Escape Its Phase

Title: fixed
Family: io

## Explanation

A `ReadRequest` or `WriteRequest` is a view of a slot that a transfer group owns and reuses. The methods `prepareRead`, `completeRead`, `prepareWrite` and `completeWrite` receive a request for the length of the call only.

This error means the program tries to keep a request or to own one: in a property, an enum case, a collection or a `mixed` value, as a `take` parameter, as a return value, or in a closure that is returned.

## Fix

Use the request inside the preparation or completion call. To hand it to a helper, pass it through an ordinary parameter without `take`.

To remember something about a transfer between the two phases, keep a value of your own in the class, such as a counter.

## Example

```doria
use Doria\Std\Io\ReadRequest;

class RequestLog
{
    ?ReadRequest $last = null;
}

function main(): void
{
    let $log = new RequestLog();
    echo "ready";
}
```
