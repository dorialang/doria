# Ownership Transfer Overlaps Another Use

Title: varies
Family: ownership

## Explanation

Giving a value away ends every other use of it, so one operation cannot give a value away and use it in another way at the same time. This error means the program does that.

The common cases are a call that passes the same value to a readonly or `writable` parameter and to a `take` parameter, an assignment of a variable to itself, and an assignment such as `$box->value = consume($box);`, which gives away the object whose property is being assigned.

## Fix

Give the `take` parameter a value of its own, separate from the other arguments and from the object the method is called on. For a property assignment, compute the new value from something other than the object being assigned to.

Remove an assignment of a variable to itself.

## Example

```doria
class Ticket
{
    function __construct(string $holder)
    {
    }
}

function transfer(Ticket $from, take Ticket $to): void
{
    echo "{$from->holder} to {$to->holder}";
}

function main(): void
{
    let $ticket = new Ticket("Ada");
    transfer($ticket, $ticket);
}
```
