# Format Conversion Does Not Accept This Type

Title: varies
Family: strings

## Explanation

Each conversion in a `printf` or `sprintf` format accepts one kind of value. `%d`, `%x`, `%X`, `%o` and `%b` take an integer. `%f` takes a float. `%s` takes a `string`, a number, a `bool` or a class value that implements `Displayable`. This error means an argument has a type that its conversion does not accept.

## Fix

Use the conversion that matches the value: `%f` or `%.1f` for a float, `%d` for an integer, `%s` for text.

To keep the conversion, convert the value, for example `Float::toInt($percent)` for `%d`.

## Example

```doria
function main(): void
{
    printf("%d percent", 12.5);
}
```
