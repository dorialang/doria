# Pending Request Keeps Selected Storage In Use

Title: fixed
Family: io

## Explanation

Once a pending transfer has selected a byte region, the region stays in use until the transfer completes. The transfer may read or write those bytes at any time before then.

This error means code that runs after the preparation call touches the selected storage: it reads or writes the bytes, replaces the buffer that owns them, or gives the buffer away. A region selected for a write is only read by the transfer, so reading it is still allowed. The `length` of a region can always be read.

## Fix

Do the work on the bytes before the preparation call.

Work that depends on the result of the transfer belongs in `completeRead` or `completeWrite`, which receives the region again when the transfer has finished.

## Example

```doria
use Doria\Std\Io\{PendingReadableStream, ReadableFile, ReadRequest, ReadOutcome,
    ReadinessSource, WritableByteRegion, IoError};

class ClearedFile implements PendingReadableStream
{
    internal writable ReadableFile $file;

    function __construct(parameter take ReadableFile $file)
    {
        $this->file = $file;
    }

    ReadinessSource $readinessSource {
        borrowed get => $this->file->readinessSource;
    }

    writable function read(writable WritableByteRegion $destination): ReadOutcome throws IoError
    {
        return $this->file->read($destination);
    }

    writable function prepareRead(writable ReadRequest $request, writable WritableByteRegion $destination): void throws IoError
    {
        $this->file->prepareRead($request, $destination);
        $destination[0] = 0;
    }

    writable function completeRead(ReadRequest $request, writable WritableByteRegion $destination): ?ReadOutcome throws IoError
    {
        return $this->file->completeRead($request, $destination);
    }
}

function main(): void
{
}
```
