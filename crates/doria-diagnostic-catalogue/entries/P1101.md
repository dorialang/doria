# Integer Addition Overflowed

Title: fixed
Family: runtime

## Explanation

Integer `+` is checked. This panic means the sum is outside the range of the integer type of the operands, so it cannot be stored in that type. A `uint8` holds 0 through 255, and `250 + 10` does not fit. `+=` and `++` are checked the same way.

## Fix

Use a type wide enough for the largest sum. Convert the operands with the companion of the wider type and add there: `Int::from($level) + Int::from($step)`.

If the type is right and the input can be too large, compare before adding and handle the large case, for example `if ($level <= $limit - $step)`.

## Example

```doria
function main(): void
{
    uint8 $step = 10;
    writable uint8 $level = 250;
    $level = $level + $step;
    echo $level;
}
```
