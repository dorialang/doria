# Invalid Return Type For `main`

Title: varies
Family: functions

## Explanation

`main` is where the program starts. It returns `void`, or an `int` that becomes the exit status of the process. This error means `main` declares another return type, such as `string`, `bool` or `int32`.

## Fix

Declare `main(): void` and write output with `echo`. To report an exit status, declare `main(): int` and return the status.

Move a computation that produces another type into its own function and call that function from `main`.

## Example

```doria
function main(): string
{
    return "done";
}
```
