# Invalid Format String

Title: varies
Family: strings

## Explanation

The format of a `printf` or `sprintf` call is malformed. The conversions are `%s`, `%d`, `%f`, `%x`, `%X`, `%o` and `%b`, and `%%` writes a percent sign. A conversion may carry a width, the `-` flag for left alignment and the `0` flag for zero padding, and `%f` may carry a precision, as in `%.2f`.

This error means the format has a `%` with nothing after it, a conversion letter outside that list, a repeated flag, a precision without digits, a precision on a conversion other than `%f`, or zero padding on `%s`. The message gives the byte position in the format.

## Fix

To write a percent sign, write `%%`. Otherwise correct the conversion at the position the message gives.

## Example

```doria
function main(): void
{
    printf("progress: 50%");
}
```
