# Wrong Number Of Type Arguments

Title: fixed
Family: generics

## Explanation

Type arguments stated at a call name every type parameter of the callee, in the order the declaration lists them. `pick<T, U>` takes two, as in `pick<int, string>(1, "two")`. This error means the call states more or fewer than the callee declares.

## Fix

State one type argument for each type parameter, or state none and let the arguments and the expected type determine them: `pick<int, string>(1, "two")` or `pick(1, "two")`.

## Example

```doria
function pick<T, U>(T $left, U $right): U
{
    return $right;
}

function main(): void
{
    echo pick<int>(1, "two");
}
```
