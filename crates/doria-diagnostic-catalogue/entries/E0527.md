# Invalid Sequence Fill Count

Title: varies
Family: collections

## Explanation

The repeat form `[value; count]` builds a sequence that holds `value` `count` times. The count is an `int`. This error means the count has another type, or it is a constant with a negative value.

A count that is negative only when the program runs causes a panic.

## Fix

Give a count of type `int` that is zero or greater, for example `[0; 3]` or `[0; $size]`. Convert a count held in another integer type with `Int::from`.

## Example

```doria
function main(): void
{
    List<int> $zeros = [0; -3];
    echo $zeros->count;
}
```
