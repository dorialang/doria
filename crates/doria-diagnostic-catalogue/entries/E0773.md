# Pending Request Cannot Outlive Selected Storage

Title: fixed
Family: io

## Explanation

Preparing a pending transfer selects the byte region that the transfer reads into or writes from. The transfer runs after the preparation call returns, so the selected region must still exist then.

This error means `prepareRead` or `prepareWrite` selects a region of storage that ends with the call, such as a local `Bytes` value.

## Fix

Select the region the method was given, `$destination` in `prepareRead` or `$source` in `prepareWrite`.

To transfer through a buffer of your own, keep the buffer in a property of the class and select a region of it, as in `$this->buffer->getWritableRegion(0, 64)`.

## Example

```doria
use Doria\Std\Io\{PendingReadableStream, ReadableFile, ReadRequest, ReadOutcome,
    ReadinessSource, WritableByteRegion, IoError};

class ScratchFile implements PendingReadableStream
{
    internal writable ReadableFile $file;

    function __construct(parameter take ReadableFile $file)
    {
        $this->file = $file;
    }

    ReadinessSource $readinessSource {
        borrowed get => $this->file->readinessSource;
    }

    writable function read(writable WritableByteRegion $destination): ReadOutcome throws IoError
    {
        return $this->file->read($destination);
    }

    writable function prepareRead(writable ReadRequest $request, writable WritableByteRegion $destination): void throws IoError
    {
        writable Bytes $scratch = Bytes::allocate(64);
        $this->file->prepareRead($request, $scratch->getWritableRegion(0, 64));
    }

    writable function completeRead(ReadRequest $request, writable WritableByteRegion $destination): ?ReadOutcome throws IoError
    {
        return $this->file->completeRead($request, $destination);
    }
}

function main(): void
{
}
```
