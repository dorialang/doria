# `shared` Is A Construction Modifier, Not A Declaration Modifier

Title: fixed
Family: ownership

## Explanation

`shared` is written in one place: directly before `new`. `shared new Node()` constructs a `SharedReference<Node>`. This error means `shared` is followed by something other than `new`, most often a type in a declaration such as `shared Node $node`.

`shared` is not a type, and it does not modify a variable, a parameter, a property, a method or a class.

## Fix

Write the type as `SharedReference<T>` and keep `shared` on the construction: `SharedReference<Node> $node = shared new Node();`.

With `let` the type is inferred: `let $node = shared new Node();`.

## Example

```doria
class Node
{
    string $name = "root";
}

function main(): void
{
    shared Node $node = shared new Node();
    echo $node->name;
}
```
