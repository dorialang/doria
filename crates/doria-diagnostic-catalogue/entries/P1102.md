# Integer Subtraction Overflowed

Title: fixed
Family: runtime

## Explanation

Integer `-` is checked. This panic means the difference is outside the range of the integer type of the operands. The usual cause is an unsigned type going below zero: a `uint8` holds 0 through 255, and `3 - 5` does not fit. `-=` and `--` are checked the same way.

## Fix

If the result can be negative, use a signed type. Convert the operands with the companion of that type and subtract there: `Int::from($credits) - Int::from($spent)`.

If a negative result is an error in the program's own terms, compare before subtracting, for example `if ($spent <= $credits)`.

## Example

```doria
function main(): void
{
    uint8 $spent = 5;
    writable uint8 $credits = 3;
    $credits = $credits - $spent;
    echo $credits;
}
```
