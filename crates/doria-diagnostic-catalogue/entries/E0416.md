# Condition Must Be Boolean

Title: varies

## Explanation

The condition of an `if`, `while`, `do` or `for` statement has a type other than `bool`. Doria does not treat numbers, strings or `null` as true or false.

## Fix

Write a comparison that produces a `bool`. Test a number with `$count > 0` or `$count != 0`, a nullable value with `$name != null`, and a string with `!$text->isEmpty`.

## Example

```doria
function main(): void
{
    int $count = 3;
    if ($count) {
        echo "some";
    }
}
```
