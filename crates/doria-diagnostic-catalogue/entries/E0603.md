# Payload-Level Take Is Not Allowed

Title: fixed
Family: enums

## Explanation

A payload binding in a match pattern, such as `$document` in `LoadResult::Loaded($document)`, is a readonly view of the payload. `take` before a binding asks to move one payload out of the enum and leave the remainder behind. A match consumes its scrutinee whole or borrows it whole; a pattern cannot move part of it.

## Fix

Put `take` on the scrutinee: `match (take $result)`. The match then owns the value, and in the selected arm each move payload binding is an owned value that the arm can return or store. The scrutinee variable cannot be used after the match.

To read the payload and keep the enum, remove `take` from the binding.

## Example

```doria
class Document
{
    function __construct(string $name) {}
}

enum LoadResult
{
    case Loaded(Document $document);
    case Missing;
}

function main(): void
{
    LoadResult $result = LoadResult::Loaded(new Document("notes"));
    Document $document = match ($result) {
        LoadResult::Loaded(take $document) => $document,
        LoadResult::Missing => new Document("empty"),
    };
    echo $document->name;
}
```
