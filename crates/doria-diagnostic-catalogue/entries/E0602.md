# Writable Match Is Not Supported

Title: fixed
Family: enums

## Explanation

A `match` reads its scrutinee. `match (writable $value)` asks for writable access to the value while the arms and their guards are tested, and Doria rejects that form: a guard that fails must leave the value unchanged for the arms after it.

## Fix

Remove `writable`: `match ($reading) { ... }`. The arms read the scrutinee and its payloads, and the result of the match is a new value that can be assigned to a `writable` variable.

When the scrutinee is a move value and an arm needs to own its payload, consume the whole value with `match (take $value)`.

## Example

```doria
enum Reading
{
    case Value(int $amount);
    case Missing;
}

function main(): void
{
    let writable $reading = Reading::Value(4);
    int $amount = match (writable $reading) {
        Reading::Value($amount) => $amount,
        Reading::Missing => 0,
    };
    echo $amount;
}
```
