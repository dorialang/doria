# Function Value Needs Writable Access Or Ownership

Title: varies
Family: functions

## Explanation

A variable or parameter that holds a function value is readonly unless it is declared `writable`, and a parameter borrows its function value unless it is declared `take`. This error means the function value is used in a way that declaration does not allow.

A readonly variable cannot be assigned a new function value. A `function writable(...)` value cannot be called through a readonly variable or passed from one to a `writable` parameter. A `function once(...)` value cannot be called through a parameter that only borrows it.

## Fix

Declare the variable `writable`, as in `let writable $next = function (): int with (writable $count) { ... };`.

To call a `function once(...)` parameter, declare the parameter `take`: `take function once(): Report $release`.

## Example

```doria
function run(writable function writable(): int $next): void
{
    echo $next();
}

function main(): void
{
    let writable $count = 0;
    let $next = function (): int with (writable $count) {
        $count += 1;
        return $count;
    };
    run($next);
}
```
