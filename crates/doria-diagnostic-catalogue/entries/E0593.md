# Match Arm Has No Value

Title: fixed
Family: enums

## Explanation

`match` is an expression, and every arm produces a value. This error means the expression of an arm has type `void`, usually because it calls a function that returns nothing.

## Fix

If the arm is meant to produce a value, write the value or call a function that returns one.

For branches that only perform actions, use `if` and `else`.

## Example

```doria
function announce(string $text): void
{
    echo $text;
}

function main(): void
{
    let $count = 1;
    string $label = match ($count) {
        1 => "single",
        default => announce("many"),
    };
    echo $label;
}
```
