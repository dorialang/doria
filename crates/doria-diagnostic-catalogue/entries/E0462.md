# Class Value Cannot Be Displayed

Title: varies
Family: strings

## Explanation

`echo`, string interpolation, the `.` operator and the `%s` format conversion turn a value into text. A class value can be displayed only when its class implements `Displayable`. This error means the class does not. A `toString` method counts only when the class also declares `implements Displayable`.

The same code is raised when `print` is called inside an expression. Doria writes output with `echo`.

## Fix

Add `implements Displayable` to the class and declare `function toString(): string` in it. To show one part of the value, display a property, as in `echo $origin->x;`.

Replace a `print(...)` call with an `echo` statement.

## Example

```doria
class Point
{
    function __construct(int $x, int $y)
    {
    }
}

function main(): void
{
    let $origin = new Point(0, 0);
    echo $origin;
}
```
