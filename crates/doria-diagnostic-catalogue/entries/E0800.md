# Pointer Operation Needs A Pointee With A Size

Title: fixed
Family: unsafe

## Explanation

Reading through a pointer, writing through one and moving it by elements with `offset` all use the size of the type it points to. `Pointer<Opaque>` and `WritablePointer<Opaque>`, C's `const void *` and `void *`, point to no type, and a foreign struct declared without fields, such as `extern "C" struct Stream;`, has no size. A pointer to either has no `read`, `readUnaligned`, `write`, `writeUnaligned` or `offset`.

## Fix

Convert an untyped pointer to a pointer of the C type it addresses before reading through it: `Pointer<uint8> $bytes = Pointer::cast($pointer);`. Move any pointer by bytes with `byteOffset`. Pass a pointer to a struct declared without fields to the C functions that use it, or declare the struct's fields.

## Example

```doria
use Doria\Std\Ffi\{Opaque, WritablePointer};

extern "C"
{
    /** @safety The result points to memory the library owns. */
    function sharedBuffer(): WritablePointer<Opaque>;
}

function main(): void
{
    unsafe {
        let $buffer = sharedBuffer();
        let $first = $buffer->read();
    }
}
```
