# Enum Value Is Readonly

Title: fixed
Family: enums

## Explanation

The program assigns to a property of an enum value. An enum value cannot be changed through its properties. The `value` property of a backed enum is readonly, and each case keeps the backing value its declaration gives it.

## Fix

To hold a different case, declare the variable `writable` and assign the case to it: `$priority = Priority::High;`.

To change the backing value of a case, change it in the enum declaration.

## Example

```doria
enum Priority: int
{
    case Low = 1;
    case High = 10;
}

function main(): void
{
    writable Priority $priority = Priority::Low;
    $priority->value = 10;
    echo $priority->value;
}
```
