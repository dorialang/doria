# Type Cannot Be Used For A Constant

Title: varies
Family: classes

## Explanation

The value of a constant is worked out when the program is compiled. A constant can therefore hold a number, a `bool`, a `string`, an enum value, or the nullable form of one of these. This error means a constant is declared with another type, such as a class or a collection.

## Fix

Declare the constant with one of those types, or leave the type out and let the initializer decide it, as in `const RETRY_LIMIT = 3;`.

For a collection or an object, write a function that builds the value and returns it, such as `function weekend(): List<string>`, and call it where the value is needed.

## Example

```doria
const List<string> WEEKEND = ["Saturday", "Sunday"];

function main(): void
{
    echo WEEKEND->count;
}
```
