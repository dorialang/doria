# Non-Exhaustive Match

Title: fixed
Family: enums

## Explanation

A `match` has an arm for every value the matched expression can have. This error means some value has no arm. The message lists what is missing.

An enum needs every case, and a `bool` needs `true` and `false`. A nullable value also needs `null`. Types with an open set of values, such as `int`, `float`, `string` and `mixed`, need a final `default` arm, and so does `match (true)`.

An arm with an `if` guard does not cover its pattern, because the guard may be false.

## Fix

Add an arm for each missing value, or add `default => value` as the last arm.

## Example

```doria
enum Status
{
    case Draft;
    case Published;
}

function label(Status $status): string
{
    return match ($status) {
        Status::Draft => "draft",
    };
}

function main(): void
{
    echo label(Status::Published);
}
```
