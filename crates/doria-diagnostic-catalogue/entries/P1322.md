# Mixed Ownership Clone Failed

Title: fixed
Family: runtime

## Explanation

An owning binding such as `mixed $item = $items[$index]` gives `$item` a box and a claim of its own on the element and leaves the element in the collection. This panic means the runtime could not get the memory for that box.

The program was out of memory at that statement. The memory is usually held elsewhere.

## Fix

Reduce the memory the program holds at one time. Let collections and objects that are no longer needed go out of scope, and work through large inputs in parts.

A test on the element in place, as in `if ($items[$index] is string)`, borrows the element and acquires no ownership.

## Example

No program raises this code on demand: the panic needs the machine to refuse a small allocation, which depends on the memory that is free at that moment. A program meets it at an owning `mixed` binding of a collection element while memory is exhausted.
