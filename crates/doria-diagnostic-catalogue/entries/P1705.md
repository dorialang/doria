# Text For C Contains NUL

Title: fixed
Family: runtime

## Explanation

`CString::from` and `Utf16String::from` copy a string into a buffer that ends with NUL, the end marker of C text. A Doria string may contain NUL, and C would read such text only up to its first NUL, so the conversion panics instead of passing C a shorter string.

## Fix

Use `CString::tryFrom` or `Utf16String::tryFrom`, which return `null` for text that contains NUL, and handle that case. When the text comes from input, remove or reject NUL before the conversion. A C function that takes a pointer and a length accepts any bytes through `$text->byteRegion->pointer`.

## Example

```doria
use Doria\Std\Ffi\CString;

function main(): void
{
    let $zeros = Bytes::allocate(3);
    let $text = String::fromBytes($zeros) ?? "";
    let $name = CString::from($text);
}
```
