# Readonly Variable Cannot Be Reinitialized

Title: varies
Family: ownership

## Explanation

A move value, such as a class instance or a collection, has one owner. A variable that gives its value away, for example to a `take` parameter, no longer holds a value. A variable declared `writable` can then be assigned a new value, which it owns.

This error means the program assigns a new value to a readonly variable whose value was given away. A readonly variable is initialized once and is never assigned again.

## Fix

Declare the variable `writable`, as in `let writable $counter = new Counter(1);`, when it is meant to hold a new value after the first one is given away.

Otherwise declare a second variable for the new value.

## Example

No program shows this code on its own: the assignment is always reported first as E0201, because it assigns to a readonly variable, and this code follows at the same assignment when the variable's value was given away earlier.
