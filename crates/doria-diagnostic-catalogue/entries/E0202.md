# Cannot Write To Readonly Property

Title: varies

## Explanation

Properties are readonly unless they are declared `writable`. A readonly property gets its value from its declaration or from the constructor and keeps it. This error means the program assigns to a readonly property somewhere else. Static properties follow the same rule.

## Fix

Mark the property `writable` in its class, as in `writable int $x = 0;`. If the property should stay readonly, set its value in the constructor, or create a new object that holds the new value.

## Example

```doria
class Point
{
    int $x = 0;
}

function main(): void
{
    let writable $point = new Point();
    $point->x = 5;
    echo $point->x;
}
```
