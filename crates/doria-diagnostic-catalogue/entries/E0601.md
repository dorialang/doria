# Match Guard Is Redundant

Title: fixed
Family: enums

## Explanation

An arm guard is written `Pattern if condition => value`. The guard runs after the pattern succeeds, and the arm is selected only when the guard is `true`.

This error means the guard is the literal `true` or a constant whose value is `true`. It never changes which arm is selected.

## Fix

Remove `if` and its condition from the arm. An editor offers the removal as a quick fix.

If the arm is meant to be conditional, write a guard that depends on a value known only when the program runs, such as a payload binding or a variable.

## Example

```doria
enum State
{
    case Ready;
    case Waiting;
}

function main(): void
{
    State $state = State::Ready;
    string $label = match ($state) {
        State::Ready if true => "ready",
        State::Waiting => "waiting",
    };
    echo $label;
}
```
