# Dictionary Key Was Not Found

Title: fixed
Family: runtime

## Explanation

`$dictionary[$key]` read a key that the dictionary does not contain. An indexed read asserts that the key is present and panics when it is missing; it does not produce `null`. `Dictionary<K, V>` and `SortedDictionary<K, V>` behave the same way.

## Fix

To read a key that may be missing, use `get`, which returns `null` for a missing key: `$stock->get("pears") ?? 0`.

To test first, call `containsKey`: `if ($stock->containsKey("pears"))`. To add the key, assign to it through a writable dictionary, as in `$stock["pears"] = 0`, or call `set`.

## Example

```doria
function main(): void
{
    Dictionary<string, int> $stock = ["apples" => 4];
    echo $stock["pears"];
}
```
