# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

The compiler could not give a closure the concrete form that checking recorded for it. This code covers anonymous functions and arrow functions, the variables they capture, and calls of a function value. It means that the function type of a closure or of a called value has no compiled form or differs from the closure itself, or that a captured variable has no compiled type.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the closure, the captured variable or the call, so keep that closure and the declarations it uses, and remove the code around them.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that creates closures or calls function values.
