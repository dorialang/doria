# Range Endpoint Is Not An Integer

Title: varies
Family: types

## Explanation

A range such as `1..10` or `0..<10` counts from its start to its end, so both endpoints must be integers of the same type. This error means an endpoint has another type, such as `string` or `float`.

## Fix

Give both endpoints integer values. Parse text with `Int::parse($text)`, which gives `?int`, and supply a fallback with `??`. Convert a `float` with `Float::toInt($value)`.

## Example

```doria
function main(): void
{
    let $limit = "5";
    foreach (1..$limit as int $index) {
        echo $index;
    }
}
```
