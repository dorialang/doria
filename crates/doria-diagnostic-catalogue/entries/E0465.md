# Lifecycle Method Cannot Be Static

Title: varies
Family: classes

## Explanation

`__construct` and `__destruct` are the lifecycle methods of a class. `new` calls `__construct` on the instance it creates, and `__destruct` runs when an instance is destroyed. Each works on one instance, so neither can be declared `static`.

## Fix

Remove `static` from the declaration.

To create instances through a named static method, declare a separate `static function`, such as `static function create(): Counter`, that returns `new Counter()`.

## Example

```doria
class Counter
{
    writable int $count = 0;

    static function __construct()
    {
    }
}

function main(): void
{
    let $counter = new Counter();
    echo $counter->count;
}
```
