# Match Pattern Is Not Constant

Title: fixed
Family: enums

## Explanation

A value pattern in a `match` is known during compilation: a literal, a constant, or an enum case. This error means the pattern is an expression that is evaluated when the program runs, such as a function call or a variable.

## Fix

Use a literal, a constant declared with `const`, or an enum case as the pattern.

To test against a value computed at run time, use `match (true)`, whose arms are conditions: `$count == limit() => "full"`.

## Example

```doria
function limit(): int
{
    return 100;
}

function label(int $count): string
{
    return match ($count) {
        limit() => "full",
        default => "open",
    };
}

function main(): void
{
    echo label(100);
}
```
