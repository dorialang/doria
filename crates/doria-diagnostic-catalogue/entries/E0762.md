# Value Cannot Outlive Borrowed Source

Title: fixed
Family: ownership

## Explanation

Some values are views of another value and own nothing themselves. A `ByteRegion` is a view of the `Bytes` it came from, and an object built through a `borrow` constructor parameter is bound to the value it was given. Such a value is usable only while its source exists.

This error means a view would still be reachable after its source is destroyed. The usual case is a function that creates the source in a local variable and returns a view of it: the local is destroyed when the function returns. Storing a view in a property, or assigning it to a variable declared outside the block that declares the source, is rejected for the same reason. A pointer formed with `Pointer::to` or `WritablePointer::to` is valid until its unsafe context ends, so its place cannot be a local of a block that ends sooner.

## Fix

Let the caller own the source. Take the source as a parameter and return the view of it, as in `function firstBytes(Bytes $bytes): ByteRegion`, so the view is bound to a value that outlives the call.

Otherwise return or store the owner, for example the `Bytes` value, and create the view where it is used.

## Example

```doria
use Doria\Std\Io\ByteRegion;

function firstBytes(): ByteRegion
{
    let $bytes = Bytes::allocate(4);
    return $bytes->getRegion(0, 2);
}

function main(): void
{
    let $view = firstBytes();
    echo $view[0];
}
```
