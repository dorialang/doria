# Closure Capture Conflicts With Another Use

Title: varies
Family: functions

## Explanation

A closure that captures with `with ($value)` or `with (writable $value)` keeps that variable in use from the point where the closure is created until the last use of the closure. While a readonly capture is live, the variable can be read and cannot be changed or given away. While a writable capture is live, the variable cannot be used at all.

This error means the program uses a captured variable in a way its live capture forbids. It is also reported when a new closure asks for a capture that conflicts with an earlier closure or borrow that is still in use, for example a `writable` capture of a variable that an earlier closure still reads.

## Fix

Finish with the closure first: move the conflicting statement below the last call of the closure, or create the closure after it.

When the closure only needs the value as it was at creation, capture it with `take`. A Copy value such as an `int` is copied into the closure, and the variable stays free to change.

## Example

```doria
function main(): void
{
    let writable $total = 10;
    let $read = fn() with ($total) => $total;
    $total = 20;
    echo $read();
}
```
