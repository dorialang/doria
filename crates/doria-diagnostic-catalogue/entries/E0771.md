# Pending Transfer Phase May Block

Title: fixed
Family: io

## Explanation

A class that implements `PendingReadableStream` or `PendingWritableStream` takes part in a transfer group through two phases. `prepareRead` or `prepareWrite` configures one transfer, and `completeRead` or `completeWrite` reports its outcome. The group does the waiting, so both phases must finish without waiting.

This error means one of those methods performs input or output that can wait, such as `echo`, `read_line`, or a wait on a transfer group. The rule follows calls into functions and callbacks, and it covers the destructors of values the method creates. Catching the `IoError` does not change this.

## Fix

Remove the blocking work from the phase. In preparation, forward to the `prepareRead` or `prepareWrite` of the stream the class wraps, or call `$request->complete(...)` with an outcome that is already known. In completion, return the wrapped stream's result or `$request->outcome`.

Do logging and other input or output in the code that drives the transfer group.

## Example

```doria
use Doria\Std\Io\{PendingReadableStream, ReadableFile, ReadRequest, ReadOutcome,
    ReadinessSource, WritableByteRegion, IoError};

class TracedFile implements PendingReadableStream
{
    internal writable ReadableFile $file;

    function __construct(parameter take ReadableFile $file)
    {
        $this->file = $file;
    }

    ReadinessSource $readinessSource {
        borrowed get => $this->file->readinessSource;
    }

    writable function read(writable WritableByteRegion $destination): ReadOutcome throws IoError
    {
        return $this->file->read($destination);
    }

    writable function prepareRead(writable ReadRequest $request, writable WritableByteRegion $destination): void throws IoError
    {
        echo "preparing a read\n";
        $this->file->prepareRead($request, $destination);
    }

    writable function completeRead(ReadRequest $request, writable WritableByteRegion $destination): ?ReadOutcome throws IoError
    {
        return $this->file->completeRead($request, $destination);
    }
}

function main(): void
{
}
```
