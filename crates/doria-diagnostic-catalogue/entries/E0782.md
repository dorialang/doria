# Null-Coalescing Operand Is Never Null

Title: fixed

## Explanation

`??` uses its right operand only when its left operand is `null`. This error means the left operand has a type that cannot be `null`, so the fallback could never run.

The usual cause is an index read. `$list[$index]` and `$dictionary[$key]` have the element type and panic when the element is missing; they do not produce `null`. A call or a property whose type is not nullable is rejected for the same reason.

A binding declared `?T` or `mixed` may still be coalesced after flow analysis has narrowed it.

## Fix

To fall back when an element may be missing, read it with `get`, which returns `null` for a missing element: `$lines->get($index) ?? ""`. Dictionaries have the same member: `$counts->get($key) ?? 0`.

Otherwise remove `??` and its fallback, or make the left operand nullable.

## Example

```doria
function main(): void
{
    List<string> $lines = ["first"];
    let $line = $lines[3] ?? "";
    echo $line;
}
```
