# AssertionError Cannot Be Constructed Directly

Title: fixed
Family: testing

Example source: development

## Explanation

`AssertionError` from `Doria\Std\Test` is the error that a failed expectation throws. The testing module creates it, together with the details that `baton test` reports, such as the matcher and the expected and actual values.

This error means the program creates one itself with `new AssertionError(...)`. The type may still be named in a `catch` clause or as a parameter type.

## Fix

To fail a test with a message, call `fail("the name is empty");`. To fail it on a condition, state the condition as an expectation, such as `expect($name)->not->toBeEmpty();`.

For an error of your own, declare a class that implements `Error` and throw that.

## Example

```doria
use Doria\Std\Test\{it, AssertionError};

it("rejects an empty name", function (): void {
    let $name = "";
    if ($name == "") {
        throw new AssertionError("the name is empty");
    }
});
```
