# Constant Or Static Initializer Type Mismatch

Title: varies
Family: types

## Explanation

A constant or a static property declares a type, and its initializer evaluates to a value of a different type. Doria performs no implicit conversions, so a `string` cannot initialize an `int`, and an `int` cannot initialize a `float`.

## Fix

Write an initializer of the declared type, or change the declared type. For a `float`, write the literal with a decimal point: `const float RATE = 1.0;`.

A constant may also leave the type out and take it from the initializer: `const RETRY_LIMIT = 3;`.

## Example

```doria
const int RETRY_LIMIT = "3";

function main(): void
{
    echo RETRY_LIMIT;
}
```
