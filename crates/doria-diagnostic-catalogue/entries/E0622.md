# Destructors Cannot Throw Checked Errors

Title: fixed
Family: errors

## Explanation

`__destruct` runs when a value is destroyed and is never called directly. It cannot declare `throws`, and no checked error may leave its body.

This error means `__destruct` has a `throws` clause.

## Fix

Remove the `throws` clause, and handle every checked error inside the destructor with `try` and `catch`. `catch (Error)` handles any checked error.

## Example

```doria
class CloseError implements Error
{
    function __construct(string $message)
    {
    }
}

class Connection
{
    function __destruct(): void throws CloseError
    {
    }
}

function main(): void
{
    let $connection = new Connection();
}
```
