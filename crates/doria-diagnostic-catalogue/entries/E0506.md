# Member Access On A Possibly-Null Value

Title: varies
Family: nullability

## Explanation

The program reads a property, writes a property or calls a method with `->` on a value whose type is nullable, such as `?Token`. The value may be `null` at that point, and `null` has no members.

A nullable value keeps its nullable type until a test proves that it is present. Inside `if ($token != null) { ... }` the value is known to be non-null.

## Fix

Test for `null` first and use `->` inside the branch: `if ($token != null) { echo $token->value; }`.

To read through a value that may be missing, use `?->`, which gives `null` when the receiver is `null`, and supply a fallback with `??`: `$token?->value ?? "none"`.

## Example

```doria
class Token
{
    function __construct(string $value) {}
}

function find(bool $present): ?Token
{
    if ($present) {
        return new Token("found");
    }
    return null;
}

function main(): void
{
    let $token = find(true);
    echo $token->value;
}
```
