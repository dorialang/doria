# Writable Parameter Cannot Have A Default

Title: fixed
Family: ownership

## Explanation

A `writable` parameter lends the caller's own variable or property to the function, so every change the function makes reaches the caller. A call that leaves the argument out has no storage to lend, so a `writable` parameter has no default value.

A promoted constructor parameter is different: there `writable` makes the new property writable, and the argument is copied into it, so `function __construct(writable int $count = 0)` keeps its default.

## Fix

Remove the default and pass a writable variable at every call, as in `bump($count)` after `let writable $count = 0;`.

When callers should not have to supply storage, drop `writable` and return the new value instead: `function bump(int $count = 0): int { return $count + 1; }`.

## Example

```doria
function bump(writable int $count = 0): void
{
    $count += 1;
}

function main(): void
{
    let writable $count = 1;
    bump($count);
    echo $count;
}
```
