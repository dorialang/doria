# Constant Name Must Use `SCREAMING_SNAKE_CASE`

Title: varies
Family: names

## Explanation

Top-level and class constants are named in `SCREAMING_SNAKE_CASE`: uppercase letters, digits and underscores, beginning with a letter. This error means a constant is declared with a name in another form, such as `pageSize` or `Page_Size`.

## Fix

Rename the constant in its declaration and wherever it is used: `pageSize` becomes `PAGE_SIZE`.

## Example

```doria
const pageSize = 25;

function main(): void
{
    echo pageSize;
}
```
