# String Allocation Failed

Title: fixed
Family: runtime

## Explanation

The runtime asked the operating system for memory to hold a string and was refused. The program cannot continue without the value, so it panics and exits with status 101.

This happens when the machine or the process has run out of memory. It is raised when a line read from standard input, or the contents of a file, cannot be held in memory.

## Fix

Lower the amount of text the program holds at once. When input arrives on standard input, process it one line at a time with `read_line`.

If the machine has free memory, check the memory limit set for the process.

## Example

No program raises this code on demand: it is raised only when the operating system refuses memory, which depends on the machine and on what else is running. A user meets it in a program that reads very large input or keeps a large amount of text in memory.
