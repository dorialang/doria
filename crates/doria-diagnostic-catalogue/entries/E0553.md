# Grouped Declarations Use One Shared Initializer

Title: fixed
Family: names

## Explanation

A grouped declaration names several variables and gives all of them one starting value, as in `let $width, $height = 0;`. This error means a comma follows the initializer, as if each variable had its own value.

## Fix

Write a separate declaration for each variable whose starting value differs: `let $width = 4;` and `let $height = 3;`.

## Example

```doria
function main(): void
{
    let $width, $height = 4, 3;
    echo $width * $height;
}
```
