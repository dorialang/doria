# Constant Initialization Cycle

Title: varies
Family: classes

## Explanation

Constants and static properties may refer to each other in their initializers in any order, including to one declared later. This error means the references form a loop: the value of a constant depends on itself, directly or through other constants. The message lists the chain.

## Fix

Give one constant in the chain a value that does not refer to the others, such as a literal. The rest can then be computed from it.

## Example

```doria
const PAGE_SIZE = ROW_LIMIT / 4;
const ROW_LIMIT = PAGE_SIZE * 4;

function main(): void
{
    echo PAGE_SIZE;
}
```
