# Readonly Value Cannot Be Used As Writable

Title: varies
Family: ownership

## Explanation

A `writable` parameter changes the caller's value, so its argument must be something the caller may change. This error means the argument is readonly at some point along its path: a variable or a parameter declared without `writable`, or a property declared without `writable`.

## Fix

Declare the variable `writable`, as in `writable List<string> $guests = ["Ada"];`. For a parameter, write `writable` before its type.

When the argument is a property, such as `$box->items`, both the variable and the property must be `writable`.

## Example

```doria
function addGuest(writable List<string> $guests): void
{
    $guests->add("Grace");
}

function main(): void
{
    List<string> $guests = ["Ada"];
    addGuest($guests);
    echo $guests->count;
}
```
