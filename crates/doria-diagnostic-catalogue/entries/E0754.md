# Interface Implementation Is Missing

Title: fixed
Family: interfaces

## Explanation

A class that names an interface after `implements` provides every requirement of that interface and of the interfaces it extends. This error means the class lacks a required method, getter or setter.

A member under a different name does not count, and a stored property without accessors does not satisfy a required getter or setter.

## Fix

Declare the missing member in the class with the signature the interface gives. For a property requirement, declare the property with the required `get` or `set` accessor.

A method composed from a trait with `uses` also satisfies a method requirement.

## Example

```doria
interface Renderable
{
    function render(): string;
}

class Report implements Renderable
{
}

function main(): void
{
    let $report = new Report();
}
```
