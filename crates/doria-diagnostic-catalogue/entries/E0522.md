# Readonly Or Foreach-Only Iteration

Title: varies
Family: collections

## Explanation

The `keys` and `values` of a dictionary are projections for `foreach`, as in `foreach ($stock->keys as string $name)`. This error means the program stores a projection in a variable, passes it to a call, or uses it as a value in some other way.

The code is also raised when a `foreach` declares a `writable` value binding where the elements are readonly: over `keys` or `values`, and over a value that is iterated through the `Iterable` interface.

## Fix

Iterate the projection directly with `foreach`. To keep the keys or the values, add each one to a `List` inside the loop.

To change the values of a dictionary in place, iterate the dictionary itself: `foreach ($stock as string $name => writable int $amount)`. Remove `writable` from a binding over `keys`, `values` or an `Iterable`.

## Example

```doria
function main(): void
{
    Dictionary<string, int> $stock = ["apples" => 3];
    let $names = $stock->keys;
}
```
