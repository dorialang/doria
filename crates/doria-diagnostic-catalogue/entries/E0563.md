# Enum Name Must Use PascalCase

Title: fixed
Family: names

## Explanation

Type names in Doria use PascalCase, and an enum is a type. This error means the name of an enum does not begin with an uppercase letter.

## Fix

Rename the enum so that it begins with an uppercase letter, as in `Status`, and update the places that refer to it. An editor offers the rename as a quick fix when the new name is free.

## Example

```doria
enum status
{
    case Draft;
    case Published;
}

function main(): void
{
    status $current = status::Draft;
}
```
