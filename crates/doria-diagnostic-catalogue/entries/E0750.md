# Class, Interface Or Trait Used In The Wrong Role

Title: varies
Family: interfaces

## Explanation

Classes, interfaces and traits have different roles. A class is constructed with `new`. An interface is named after `implements`, after `extends` in another interface, and as a type. A trait is named after `uses`. This error means a name of one kind appears where another kind is required.

Common cases are `new` applied to an interface or a trait, a class or an undeclared name after `implements`, an interface after `uses`, and a trait written as the type of a variable, parameter or property.

## Fix

Construct a class that implements the interface, and use the interface as the type: `Renderable $page = new Page();`.

After `implements`, name a declared interface. To inherit from a class, use `extends`. After `uses`, name a trait.

## Example

```doria
interface Renderable
{
    function render(): string;
}

function main(): void
{
    let $page = new Renderable();
    echo $page->render();
}
```
