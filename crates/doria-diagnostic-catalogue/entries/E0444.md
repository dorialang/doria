# Float Literal Is Out Of Range

Title: varies
Family: types

## Explanation

A float literal must be a finite value of its type. This error means the literal is larger than the type can hold, so it would become infinity. `float32` has a smaller range than `float`.

## Fix

Write a value within the range of the type. A literal that is too large for `float32` may fit `float`, so declare the wider type when the value is correct.

## Example

```doria
function main(): void
{
    float32 $distance = 500000000000000000000000000000000000000.0;
    echo $distance;
}
```
