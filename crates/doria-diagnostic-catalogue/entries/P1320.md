# Mixed Value Allocation Failed

Title: fixed
Family: runtime

## Explanation

A value stored in `mixed` is boxed: the runtime allocates a small box that records the value and its type. This panic means the runtime could not get the memory for that box.

The program was out of memory when it converted a value to `mixed`. The statement the panic points at is where the shortage was noticed, and the memory is usually held elsewhere.

## Fix

Reduce the memory the program holds at one time. Let collections and objects that are no longer needed go out of scope, and work through large inputs in parts.

If the program boxes values into `mixed` inside a loop that never ends, correct the loop.

## Example

No program raises this code on demand: the panic needs the machine to refuse a small allocation, which depends on the memory that is free at that moment. A program meets it where a value becomes `mixed` while memory is exhausted.
