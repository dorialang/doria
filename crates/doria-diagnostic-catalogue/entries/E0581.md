# Recursive Inline Enum Layout

Title: fixed
Family: enums

## Explanation

An enum value stores the payload fields of its active case inside itself. This error means a payload field has the type of the enum that declares it, directly or through other enums. A value of that enum would contain a whole value of its own type, so it would have no finite size.

A nullable field such as `?Node` is stored the same way and is rejected for the same reason.

## Fix

Hold the recursive value in a collection or a class. Both live outside the enum value, so the enum keeps a fixed size. For a tree, give the case a list of children: `case Branch(List<Node> $children);`.

A class with a `?Node` property serves when there is one child at most.

## Example

```doria
enum Node
{
    case Leaf(int $value);
    case Branch(Node $next);
}

function main(): void
{
    Node $node = Node::Leaf(1);
    echo match ($node) {
        Node::Leaf($value) => $value,
        Node::Branch => 0,
    };
}
```
