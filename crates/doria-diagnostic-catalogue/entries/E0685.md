# Executable Target Is Required

Title: fixed
Family: projects

## Explanation

A project declares its targets in `Baton.toml`. A binary target has an entry file and compiles to an executable. A library target has no entry file and no executable. This error means the compiler was asked to produce an executable for a library target.

Baton does not make that request. `baton build --library` checks the library and writes no executable, and `baton run` refuses a library with an error of its own. The code appears when the build plan of a library, the JSON file that Baton writes to describe a project to the compiler, is passed to `doriac compile --build-plan`.

## Fix

To produce an executable, give the project a binary target: `kind = "binary"` and `entry = "src/main.doria"` under `[package]`, or a `[[targets.binary]]` table with a `name` and an `entry`. Build it with `baton build`, adding `--binary <name>` when the project has several targets.

To check a library, use `baton check --library`, or `doriac check --build-plan` with the same plan.

## Example

No single source file raises this code: it is reported only for a build plan whose selected target is a library, when that plan is passed to `doriac compile --build-plan`. A project built through Baton does not meet it, because Baton produces no executable for a library.
