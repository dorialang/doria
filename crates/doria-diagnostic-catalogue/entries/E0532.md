# Type Parameter Inferred As Two Types

Title: varies
Family: generics

## Explanation

A type parameter stands for one type in each call. This error means two arguments give the same type parameter different types. With `function larger<T>(T $first, T $second)`, the call `larger(1, "two")` makes `T` an `int` from the first argument and a `string` from the second. Doria performs no implicit conversions, so the two cannot be reconciled.

## Fix

Pass arguments of the same type wherever parameters share a type parameter. Convert one of the values first if that is what the call means.

If the two values are meant to differ in type, declare a second type parameter, as in `function pair<T, U>(T $left, U $right)`.

## Example

```doria
function larger<T>(T $first, T $second): T
{
    return $first;
}

function main(): void
{
    echo larger(1, "two");
}
```
