# Unknown Method

Title: varies

## Explanation

The program calls a method that the value's type does not have. A class value has the methods its class declares, and a value typed as an interface has the methods that interface requires.

Strings, numbers and booleans have their own rule. String operations are members of the `String` companion and take the string as an argument, so `$name->trim()` is written `String::trim($name)`. Values of type `int`, `float` and `bool` have no instance methods.

## Fix

Check the spelling and the case of the method name. If the class should have the method, declare it.

For a string operation, call the `String` companion, as in `String::trim($name)` or `String::lower($name)`. For a number or a boolean, write the operation with operators, or pass the value to a function that performs it.

## Example

```doria
class Greeter
{
    function greet(): void
    {
        echo "Hello";
    }
}

function main(): void
{
    let $greeter = new Greeter();
    $greeter->wave();
}
```
