# Value Is Not Callable

Title: fixed
Family: functions

## Explanation

Parentheses after a value call it, and only a value of a function type can be called. This error means the value before the parentheses has another type, such as `int`, `string` or a collection.

## Fix

To read an element of a list or dictionary, use square brackets: `$names[0]`. To call a method, name it after `->`. To call a top-level function, write its name without `$`.

If the variable was meant to hold a closure, check its declaration and its type.

## Example

```doria
function main(): void
{
    let $names = ["Ada", "Grace"];
    echo $names(0);
}
```
