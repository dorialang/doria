# Invalid Call Of A Callable Property

Title: varies
Family: functions

## Explanation

A property whose type is a function type is called like a method: `$formatter->format(82)`. Two forms of method call do not apply to it.

A function type carries no parameter names, so the call takes positional arguments only. A null-safe call with `?->` cannot invoke a callable property.

## Fix

Remove the argument names and pass the arguments in the order the function type lists them.

When the object may be `null`, test it first, as in `if ($formatter != null) { ... }`, and call the property with `->` inside the test.

## Example

```doria
class Formatter
{
    function __construct(take function(int): string $format)
    {
    }
}

function main(): void
{
    let $formatter = new Formatter(fn(int $score) => "score: {$score}");
    echo $formatter->format(score: 82);
}
```
