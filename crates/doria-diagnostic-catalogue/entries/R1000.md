# Unhandled Error

Title: varies
Family: runtime

## Explanation

A checked Error was thrown and nothing caught it, so it left `main` and ended the program. The title of the report is `Unhandled` followed by the class of the Error, the text under `Why` is the Error's `message`, and the marked location is where the Error was first thrown. The process exits with status 70.

I/O is a common source. `read_file`, `read_line`, `echo` and the other I/O functions throw `Doria\Std\Io\IoError` or `Doria\Std\Io\InvalidUtf8Error` without a `throws` clause, so a missing file ends a program this way when nothing catches the error.

## Fix

Catch the Error where the program can recover: wrap the call in `try` and add a `catch` for its class, as in `catch (OrderError $error)`, then use `$error->message`.

When the program has no way to recover, correct the cause that the message names, such as a wrong path or an invalid argument.

## Example

```doria
class OrderError implements Error
{
    function __construct(string $message) {}
}

function placeOrder(int $quantity): void throws OrderError
{
    if ($quantity < 1) {
        throw new OrderError("quantity must be at least 1");
    }
}

function main(): void throws OrderError
{
    placeOrder(0);
}
```
