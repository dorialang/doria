# Function Is Already Declared

Title: varies

## Explanation

Two function declarations use the same name. A function name can be declared once. The second declaration is rejected even when its parameters differ from the first, and the compiler points to the first declaration.

## Fix

Rename one of the functions, or remove the one that is not needed. To let callers leave an argument out, keep one function and give that parameter a default value.

## Example

```doria
function greet(): void
{
    echo "Hello";
}

function greet(): void
{
    echo "Hi";
}

function main(): void
{
    greet();
}
```
