# Internal Compiler Error

Title: fixed
Family: compiler

## Explanation

The type the compiler recorded for an expression during checking differs from the type of the code it then produced for that expression. This code covers integer expressions and the values that pass through calls: an integer literal or variable, the two ends of a range in `foreach`, a conversion such as `Int8::from`, a `String::` companion call and its result, an argument and the parameter it is passed to, and a `return` value and the declared return type.

This is a defect in the compiler. No mistake in the source of a program produces it.

## Fix

Report it to the Doria project. Run the command again with `--diagnostic-format json` and include the output: the `developerDetails` field holds the compiler's own description of the failure, and the notes give the toolchain version and build commit.

Send the smallest program that still shows the error. The report marks the expression the compiler was working on, so start there and remove the code around it.

## Example

No program raises this code on demand: it appears only when the compiler reaches a state that a correct compiler never reaches, so a program that raises it today stops raising it once the defect is corrected. A user meets it when compiling or running a program that uses integer arithmetic, `String::` companion calls, or calls and returns that carry such values.
