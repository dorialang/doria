# Unknown Function

Title: varies

## Explanation

The program calls a function that does not exist under that name. No function with this name is declared in the file, imported with `use`, or available in the current namespace or the prelude.

## Fix

Check the spelling and the case of the name. If the function lives in another namespace, import it with `use` or call it by its full name. If it has not been written yet, declare it.

Built-in free functions use `snake_case`, such as `read_line`. Operations on a type are members of its companion, such as `String::trim($text)`.

## Example

```doria
function main(): void
{
    greet("Doria");
}
```
