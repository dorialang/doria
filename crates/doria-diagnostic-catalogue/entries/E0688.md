# Attribute Marker Is Only Valid On A Class

Title: fixed
Family: projects

## Explanation

`#[Attribute]` turns a class into an attribute class, whose constructor parameters describe the values an application supplies. This error means the marker is written on a declaration that is not a class, such as a function, an enum or a method.

## Fix

Remove `#[Attribute]` from the declaration. To attach metadata to a function, declare an attribute class, mark that class with `#[Attribute]`, and apply it to the function by name, as in `#[Route]`.

## Example

```doria
#[Attribute]
function route(): void
{
}

function main(): void
{
    route();
}
```
