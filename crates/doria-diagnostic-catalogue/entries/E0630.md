# Checked Errors Are Not Handled

Title: fixed
Family: errors

## Explanation

A checked error is caught where it can occur, or declared by the function it leaves. This error means a statement at the top level of the file, outside every function, can throw a checked error that nothing catches. Top-level statements have no `throws` clause to declare it.

The I/O errors of built-in operations such as `echo` need no handling here.

## Fix

Wrap the statement in `try` and add a `catch` clause for each error the message names.

Or move the statement into a function. A function declares the error in its `throws` clause, and `main` may let it leave without one.

## Example

```doria
class ParseError implements Error
{
    function __construct(string $message)
    {
    }
}

function parse(string $text): int throws ParseError
{
    if ($text == "") {
        throw new ParseError("empty input");
    }
    return $text->length;
}

echo parse("abc");
```
